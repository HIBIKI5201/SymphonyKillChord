追加すべき項目 (新版で判明):
- **攻撃時は移動不可 / 移動中に攻撃入力で移動キャンセル**（GS-10）

- 視点操作: スマホ = 画面左半分のスワイプ / パッド = 右スティック / キーマウ = マウス、上下・左右反転はコンフィグ

|---|---|---|

**新版で判明した実装事実** (`042-セーブ` モジュール設計書、2026-08-23 時点で「実装済み」):

- 保存対象に **チュートリアル完了状態 (`TutorialData.IsTutorialCompleted`)** が含まれる。
  Title が初回起動判定に使う
- 保存は **JSON ファイル**、型ごとのキャッシュと排他制御を持つ。入口は SymphonyFrameWork の
  `SaveStore` 静的 API
- **セーブデータリセット後に初期スキルの再補完が走る** (`InitialSkillLoadoutService`)。
  → シート 2-4 のリセット確認時に「**リセット後にスキル 0/13 が戻っているか**」を見る項目が要る
- クリア確定時の保存は `StageProgressSaveDataService.SaveClearAsync`

## §11 中断・回復 / §12 性能

## §0-2 ビルド範囲

仕様本体にステージ構成の記載は見つからなかった。`EditorBuildSettings.asset` の 7 シーンが
引き続き唯一の根拠。ただし `体験版仕様` (TGS 版) は **導入ストーリーとチュートリアルのみ、
プレイ時間 5 分、終了後は QR コード画面へ遷移**という別構成を定義しているので、
**CBT ビルドと TGS ビルドの範囲を取り違えないこと**。
