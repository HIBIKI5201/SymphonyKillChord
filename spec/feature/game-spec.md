## GS-01 リズム判定

- **出典:** 攻撃と回避の入力がリズムを刻み、判定されたタイミングを「ノーツ」として記録する。判定された拍種に応じてノーツの種類が変わる (2拍子判定なら 2ノーツ)。
- **出典:** 判定する拍種は **1 / 2 / 3 / 4 / 6 / 8 の 6 種**。旧版で矛盾としていた 12拍・16拍の記述は現行の `コアメカニクスについて` から消えており、**この矛盾は解消した**。
- **出典:** 前回入力と今回入力の時間差から拍種を判定し、時間差の計算に BPM が影響する。例: BPM 75 のとき 4拍子の 1拍は 0.8 秒、入力間隔 0.4 秒なら 8拍子と判定する。
- **出典:** 実際の拍のタイミングと一致した入力は **Just 判定**になる。
- **出典:** 拍種を判定できない入力は 3 条件 — (a) 前回入力が無い、(b) 前回入力から 1.5 小節以上離れている (**リズムタイムアウト**)、(c) 被弾直後。これらは **All ノーツ**として扱い、**コマンドの先頭でのみ使用できる**。
- **出典:** 攻撃には **硬直時間 0.56 秒**があり、その間は入力を受け付けず攻撃も発動しない。
- **出典:** 判定は **4 小節前まで蓄積**され、蓄積された並びが特定パターンと一致するとキルコードが発動する。

## GS-02 リズムコマンド戦闘

- **出典:** 攻撃操作は 1 つだけで、PC が敵に向けて射撃する。射撃する武器がリズムによって変わる (2拍子=ショットガン / 4拍子=ハンドガン / 8拍子=サブマシンガン)。
- **出典:** 攻撃は **ロックオン対象へ自動的に命中**する。PC と対象の間に障害物が無ければ必ず当たる。
- **出典:** 対象がいない場合は進行方向へ攻撃が発生するが敵に Hit しない。それ以外の挙動は対象がいる場合と変わらない。
- **出典:** すべてのキャラクターは体力を持ち、0 以下で死亡して消滅する。プレイヤーの死亡は戦闘終了となる。
- **出典 (プレイヤー→敵のダメージ式):**
  `基礎ダメージ量 × Justダメージ倍率 ÷ (1 + 攻撃力バフ% - 攻撃力デバフ%) × クリティカルダメージ倍率 × (1 + 防御力バフ% - 防御力デバフ%) = ダメージ`
- **出典 (敵→プレイヤーのダメージ式):**
  `攻撃力 × (1 + 攻撃力バフ% - 攻撃力デバフ%) × (1 + 防御力バフ% - 防御力デバフ%) = ダメージ`
  敵にはリズム入力精度の評価が無いため **Just ダメージ倍率の項が存在しない** (常に 100% 扱い)。防御力バフ・デバフは被弾側 (プレイヤー) の値を参照する。
- **矛盾:** 上の 2 式で **攻撃力バフの扱いが逆**になっている (プレイヤー式は除算、敵式は乗算)。`攻撃アクション` ページは「ダメージ計算の統一式に準拠する」と書いているので、統一式の所有元を決めて片方を直す必要がある。
- **出典:** クリティカルは **プレイヤーのクリティカル率 %** の確率で発生する。
- **出典:** ステータスは 体力 / 攻撃力 / 防御力 / クリティカル率 / クリティカル倍率 を持ち、バフと成長で変化する。
- **出典 (コンボ):** 敵に攻撃を与えると 1 コンボ。**被弾するとコンボは 0 に戻る**。コンボ値はリザルトの最大コンボ表示、現在コンボ表示、ランク評価、**スキルの発動条件**で参照される。

## GS-03 キルコードと編成

- **出典:** キルコード (スキル) は特定条件を満たすと発動し、強力な攻撃または強化状態を付与する。条件は **リズムパターン** と **アクション種別** から成る。例: `4 → 4 → 8 → 8` のリズム、`最後は回避` のアクション種別。
- **出典:** 一部のスキルはさらに **自身の HP が〇% 以下 (一度のみ)**、**命中した敵の数**を条件にする。
- **出典:** スキル効果のジャンルは 3 種 — 攻撃 (単体強撃 / 多段 / 着弾後半径〇m 範囲)、バフ (n秒間 攻撃力上昇 / 与ダメージの〇% を HP 回復・上限あり)、デバフ (n秒間 攻撃力減少 / m秒間 被ダメージ 1.〇倍)。
- **出典:** 初期所持は **スキル 0 と スキル 13** の 2 種。チュートリアルの研究画面パートで **スキル 1** の解放が誘導される (通常のポイント消費解放を使った誘導であり例外付与ではない)。チュートリアル終了時点で **0 / 13 / 1 の 3 種**を所持する。
- **出典:** スキルツリーの配置順は「4 や 8 など打ちやすいもの → 3 / 6 / 1 など打ちにくいもの」「効果が単調なもの → 複雑なもの」。
- **出典:** 初期の編成枠は **2**。研究 (スキルツリー) を進め **6 個解放後の特別なノード**を取得すると **3** になる。
- **出典:** **コマンド末尾のノーツが共通するスキルは同時装備できない。** (例: `A A B B` と `A C B` は不可、`A C C` と `A C B` は可)
- **出典:** スキルはレベルアップでき、上限はスキルごとに異なる。強化は編成 (改造) 画面で行う。

## GS-04 音楽と遭遇の同期

- **出典:** 戦闘中は必ず戦闘音楽が流れ、プレイヤーは音楽に合わせると有利な効果を得る。敵は音楽の拍タイミングに合わせて行動する。
- **出典:** BGM は **イントロ 4小節 (約10.6秒) / ループ 16小節 (約42.2秒) / アウトロ 4小節 (約10.6秒)**。インゲーム開始時にイントロ、戦闘中はループを繰り返し、**戦闘終了後のリザルト演出中にアウトロへ移行**する。
- **出典:** ループは **2 小節を 1 ブロック**として分割し、CRI により動的に組み替える (例: `A B A C` の 2小節目を D、4小節目を B に置換して `A D A B`)。
- **出典:** 差し替えるフレーズは**スキルの末尾の拍種**によって決まる。組み替えの契機は研究で装備したスキル。
- **出典:** 2 種装備時は `原曲 → スキル1 → 原曲 → スキル2`、3 種装備時は `原曲 → スキル1 → スキル2 → スキル3` の順で再生する。
- **出典:** 現在流れている BGM がどの要素を含むかを示す UI をインゲームに表示する。
- **出典 (意図):** BGM 組み替えは**スキル発動の入力難易度を下げるためのガイド**であり、聴覚だけでは要素が分かりにくいため視覚的な提示も併せて行う。

## GS-05 ステージ、ミッション、リザルト

- **出典:** 1 ステージ **約 2 分**を目標とし、クリア条件は戦闘に関するものにする。
- **出典:** ミッションはステージ開始時に与えられ、**メインミッション** (クリア可否) と **サブミッション** (質の評価) を完全に独立した項目として定義する。
- **出典:** メインの成功条件例 — 敵を n 体討伐 / n 秒間生存 / ボスを討伐。失敗条件例 — n 秒以内にクリアできない / 死亡する。
- **出典:** サブミッションは **重複ありで 3 つ**課される。例 — n ダメージ以内でクリア / n 種類以上の銃を使用 / n 分以内にメイン条件達成 / n 回コンボ達成。
- **出典 (ランク式・旧版で未取得だった項目):** サブミッションの達成数でランクが 1 段ずつ上がる。**メインのみ = C / +1 = B / +2 = A / +3 = S。**
- **出典:** ステージ開始でプレイヤーは全操作が可能になる。成功条件を満たすとインゲームが終了しリザルトを表示する。失敗条件を満たすと演出を経てインゲームが終了する。
- **出典:** 勝利リザルトの表示項目 — ステージ名 / ポーズを取ったキャラクター / メインミッション / サブミッション / 戦闘時間 / 最大コンボ数 / 完了 / 再出撃。敗北リザルトは サブミッションの代わりに **Tips (攻略アドバイス)** を表示し、完了と再出撃を持つ。
- **矛盾 (未解消):** リザルト完了後の戻り先。`リザルト` ページは「完了 = ホーム画面に移動」で統一されているが、`ステージルール` ページには「ホームに戻る」と「作戦画面に戻る」が併記されたままである。
- **出典:** チュートリアルは **ステージ 0** として初回起動時にタイトル後、自動で開始される。リズムアクション説明・雑魚戦・ボス戦をプレビューできる。

## GS-06 アウトゲームと成長

- **出典 (New Game):** タイトル「始めから」→ ストーリー第一話 → バトルチュートリアル → ホームチュートリアル → ホーム画面。
- **出典 (Continue):** タイトル「続きから」→ ホーム画面 → 作戦画面 (ステージまたはストーリーを選択) → ミッションをクリア。
- **出典:** ホーム画面がアウトゲームの中心で、そこから各画面へアクセスする。
- **出典:** アウトゲームの各画面は初回起動時に個別のチュートリアルを行う — ホーム (各ボタン説明) / 作戦 (ステージ解放と報酬) / 改造 (キルコードの付け替え) / 研究 (スキルツリー解放方法とポイント入手方法)。
- **出典:** シーンは インゲーム (チュートリアル / シナリオ / バトル)、アウトゲーム (タイトル / ミッションセレクト / 収集リスト / 編成)、グローバル (コンフィグ) に分かれる。
- **未解決:** 「収集リスト (スキル図鑑・収集率)」はシーン定義に現れるが、専用の仕様ページが無い。

## GS-09 導線、ガイダンス、回復

- **出典:** ホームはアウトゲームの hub であり、作戦 / 研究 / 改造・編成 / 設定へアクセスできる。
- **出典:** 作戦画面は battle と scenario のノードを左→右の解放ツリーで示す。battle detail はミッション条件・報酬・過去の進捗を表示し、選択後は出撃前の編成確認を開く。
- **出典:** 改造画面はスキルのフィルタ、効果・コマンド・レベル詳細、プレビュー、drag-and-drop または click 置換、明示的な保存、未保存離脱時の保存/破棄の判断を提供する。
- **出典:** 研究ツリーは現在パラメータ・コスト・解放可能/locked を表示し、リセットを提供する。入力が苦手なプレイヤーの救済経路として明記されている。
- **出典 (コンフィグの分割):** 時間のかかる設定 (言語 / 画質プリセット / 画面の明るさ) はアウトゲームへ集約し、短時間で調整できる設定はインゲームでも変更可能にする。
- **出典 (インゲーム側の設定項目):** カメラ感度 (1〜10段階) / カメラ操作反転 / オートロックオン有効・無効 / マニュアルロックオン時の追従速度 / Master Volume / BGM / SE / ボイス、および **判定調整機能**。
- **出典:** 設定はシーン遷移ではなくオーバーレイで開き、決定/取消を提供する。タイトルは音量・クレジット・セーブデータリセットを公開する。
- **出典:** β版指針は pause、時間停止、resume countdown、rhythm/skill/mission HUD、敵攻撃の予告、ロード進捗、コントローラナビゲーション、モバイル向け操作を要求する。
- **未解決:** data reset の確認、音 cue の accessibility 代替、キーリマップの範囲、フォント/可読性目標、チュートリアル完了基準。

## GS-10 プレイヤーの移動と回避

- **出典 (移動):** スマホは移動スティック、PC は WASD。**基本移動はダッシュ**で、**ジャンプはできない**。マップ範囲外へは出られない。
- **出典 (移動の制約):** **攻撃時は移動不可**。移動中に攻撃入力を行うと移動がキャンセルされる。**移動しながらの攻撃はできない。**
- **出典 (意図):** 移動とリズム合わせを同時に行うと脳のリソースを取られるため、常にどちらか一方のみを行わせる。
- **出典 (回避):** スマホは移動スティックのフリック方向へ、PC は既定で右クリック (コンフィグで変更可)。
- **出典 (回避の性能):** 入力から **0.x 秒間**、敵の攻撃を受けなくなる。直前の移動入力方向 (無ければ正面) へ **0.x m** 移動する。回避中の回避入力は無効。
- **出典 (回避の衝突):** 障害物はすり抜けない。敵はすり抜けてよく、回避後に座標が重なった場合は重ならない位置まで移動する。
- **未解決:** 回避の無敵時間・移動距離が `0.x` のまま。用語ページに `DodgeDuration` / `DodgeCooldown` が定義されているが、**値が未定**。
- **出典 (パラメータ表記):** `n`, `m` のようなアルファベット 1 文字の変数は現在未定義で、実装後にプランナーが変更できるようにする。

## GS-11 敵と遭遇

- **出典:** 敵の種類は **歩兵 / 砲兵 / ボス** の 3 種。
- **出典:** 敵はステージ開始時、敵を倒し切った時、時間経過のいずれかで出現する。
- **出典:** 敵は基本的に銃火器による遠距離攻撃を行う。**プレイヤーが感知射程内に入ると射撃体勢に入る。**
- **出典:** 敵の攻撃は BGM・拍数に同期し、攻撃前に**攻撃予測線または攻撃予測範囲**をプレイヤーに表示する。
- **出典:** 敵は HP が 0 で死亡する。死亡時はボイスとモーションを再生し、**アニメーション終了の 2〜3 秒後**に死体消滅アニメーションを再生する。
- **出典:** 死亡した瞬間に敵としての判定 (当たり判定 / ロックオン対象 / 攻撃対象 / ステージ上の敵カウント) を失い、**死体の上は透過して走行できる**。
- **出典 (意図):** 攻撃前に範囲を提示することで会心率などのランダム要素を削減する。遠距離単一対象だけでなく遠距離範囲攻撃の敵も実装し作業感を避ける。
- **未解決:** ボスの固有仕様。`ボス戦闘` ページは見出しのみで本文が空。歩兵・砲兵の個別パラメータも未記載。

## GS-12 ターゲットとカメラ

- **出典:** インゲームは **3人称視点**で進行し、画面手前に PC が存在する。カメラ操作は基本的にプレイヤーが行う。
- **出典 (オートロックオン):** 攻撃時にロックオン対象が定まっておらず視点内に敵がいる場合、**強制的に近くの対象へロックオン**する。視点は攻撃時のみ対象方向へ移動する。対象は**ダメージを与えた敵**。ロックオンが無い場合は **Symphony の直線状に銃弾が飛ぶ**。**視点操作または移動操作を行うと解除**される。
- **出典 (マニュアルロックオン):** 専用ボタンで発動。常に画面範囲内に対象を捉え続けるよう視点が移動する。対象は**視界範囲内で最も HP が低い or 距離が近い敵**。対象がいなくなった場合も同じ規則で再選択する。再度ボタンを押すと解除。
- **出典 (優先):** **マニュアルロックオンが優先**され、発動中はオートロックオンは発動しない。
- **出典 (視点操作):** スマホ = 画面左半分のどこをスワイプしても視点移動 / ゲームパッド = 右スティック / キーマウ = マウス。上下反転・左右反転はコンフィグで変更可能。
- **出典 (コンフィグ):** オートロックオンの有効/無効、マニュアルロックオン時の追従速度、カメラ感度 (1〜10)、カメラ操作反転をプレイヤーが設定できる。
- **コード:** ロックオン対象の登録・選択・現在位置取得は独立した Target モジュールが一元管理し、Camera / Player / Enemy / UI / Skill から参照される (旧 Camera モジュールから分離、2026-08-17 時点で実装済み)。
- **未解決:** マニュアルロックオンの対象選択が「**最も HP が低い or 距離が近い**」と **or のまま**で、どちらを優先するかが決まっていない。同じ入力で結果が変わりうる。

## GS-13 レベルデザインと難易度対応

- **出典:** リズムに乗らなくてもクリアできないわけではない。どのタイミングでもアクションはできるが、**キルコードが発動しないため不利になる**。
- **出典:** チュートリアルから序盤は **4 拍子と 8 拍子**のキルコードを設定し、中盤から 3 拍子や入力種別が複雑なキルコードを入手できるようにする。
- **出典:** 上級者向けに 上級者向けキルコード と **エンドレスのミッション**を用意する。
- **出典 (意図):** 初心者はコアメカニクスを理解しなくても進行でき、理解して使い倒したい上級者向けエンドコンテンツを主軸とする。

## GS-14 表現レーティング (ゴア表現)

- **出典:** リリース版は血の表現を強くする — ヒット時にキャラクターの体へ血が付着し地面に血だまりを作る、血の色は生々しい鮮血、死体の配置あり。
- **出典:** TGS 版は表現を抑える — ヒット時に血が少し舞う程度、血の色は暗い赤。
- **注記:** ストア提出の年齢レーティング (IARC) 申告はこの節を根拠にする。**リリース版と TGS 版でレーティング申告が変わりうる。**

## GS-15 体験版 (TGS)

- **出典:** 回転率のためプレイ時間 **5 分**を目安とし、導入ストーリーとチュートリアルのみを体験させる。
- **出典:** タイトル画面を開いた状態で待機し、押せるボタンは「始める」のみ。想定端末は PC とモバイルを 1 台ずつ。
- **出典:** 始めると通常版と同じ導入ストーリー → バトルチュートリアル。終了後は暗転し、**ストアページへの QR コードを表示する専用画面**へ遷移する。時間経過かつ入力でタイトル画面へ戻る。
- **出典 (チュートリアル内容):** 4 拍子と 8 拍子を中心に行う。キルコードの装備はチュートリアルステージ中のみ固定のもの (スキル 0 と 13) に上書きされる。**チュートリアルの敵の攻撃力は 0**。戦闘音楽は 4 拍子メインで裏打ちがあるもの、拍子ごとの攻撃 (2) のみ 3 拍子メインの BGM を流す。
- **出典 (チュートリアルフロー):** 移動 → 攻撃 (ロックオン確認 / 1・2・4・8 拍子 / 3・6 拍子) → 回避 (敵攻撃の確認と回避) → キルコードの確認 → 敵の撃破。
- **出典:** 説明は Triad の無線越しの口頭、テキストのポップアップ、ミッション確認画面での提示の 3 経路で行う。
- **出典:** インゲームのチュートリアルは**再度プレイできるようにする** (友人に勧められるように)。
