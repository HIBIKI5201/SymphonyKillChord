# 仕様書 ライティング規則

正本はNotionの[仕様書 ライティング規則](https://app.notion.com/p/2ae7c2c6cc02806cac67fa2af79e2a99)。
ミラーは `Docs/NotionSpecifications/Symphony Kill Chord/仕様書 ガイド/仕様書 ライティング規則.md`。
ここはその要約であり、食い違ったらNotion側が正しい。

仕様書のページを書くとき、および既存ページを更新するときに従う。

| 項目 | 規則 |
| --- | --- |
| 口調 | である調。「〜します」「〜です」は使わない |
| 句読点 | 文末に「。」。ただしリストの項目と括弧内の文章には付けない |
| 改行 | 文中で改行する場合はブロックを分けない（`<br>`を使う） |
| 見出し | H1には背景色を設定する（`# 見出し {color="gray_bg"}`） |
| 参考画像 | トグルリストへ入れる。1トグルに画像1枚、題名は「作品名：概要説明」 |

## 口調の変換

既存の文書をである調へ揃えるときは `scripts/notion/apply_writing_rules.py` を使う。
口調の変換に加えて、リストと括弧内の句点も落とす。

```bash
python scripts/notion/apply_writing_rules.py <対象.md> [<対象.md> ...]
```

**変換後は必ず目視で確認する。** 機械変換のため、次の取りこぼしが起きうる。

- 漢字のサ変複合語が五段動詞の規則に巻き込まれる（`反映します` → `反映す`）。
  スクリプト側で保護しているが、保護対象は `出 示 映 移 戻 直` の6語だけである。
- 「〜てください」のような依頼形は文脈によって訳し分けが要る。
