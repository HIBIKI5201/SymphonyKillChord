# 研究画面 ドラッグスクロール機能 引継ぎ資料

作成日: 2026-09-08
対象ブランチ: `feature/demo/level-design/master`

## 1. 経緯

研究画面(SkillTree)で「左クリックのホールド中にマウスを動かした方向へスクロールしたい」という要望があり、汎用のドラッグスクロール用マニピュレータを実装した。その後、同じ画面のスキル詳細パネルの「スキル効果」説明文にも同機能を適用し、さらに他のアウトゲーム画面(横スクロールの一覧など)でも再利用できるよう、縦専用/横専用を選択できる形に拡張した。

## 2. 実装内容

### `ScrollViewDragManipulator`(新規)

- 場所: `Assets/Scripts/Runtime/4.View/OutGame/SkillTree/ScrollViewDragManipulator.cs`
- 名前空間: `KillChord.Runtime.View.OutGame.SkillTree`
- `UnityEngine.UIElements.ScrollView` を渡すと、その `ScrollView` に対して「左クリックホールド+マウス移動でスクロール」を付与する汎用マニピュレータ。
- ノードのような `Button` 等のクリック可能な子要素の上から操作を始めても、移動量が閾値(10px)を超えるまではドラッグとみなさず、通常のクリックとして扱う(`TrickleDown` で先取りしつつ、閾値未満なら伝播を止めない)。
- コンストラクタ: `ScrollViewDragManipulator(ScrollView scrollView, ScrollDragAxis axis = ScrollDragAxis.Vertical)`
  - `ScrollDragAxis.Vertical`(既定): 縦方向のみドラッグでスクロール。
  - `ScrollDragAxis.Horizontal`: 横方向のみドラッグでスクロール。
- 使い方:
  ```csharp
  using KillChord.Runtime.View.OutGame.SkillTree;
  ...
  _dragScrollManipulator = new ScrollViewDragManipulator(対象のScrollView, ScrollDragAxis.Horizontal);
  // 画面Dispose時:
  _dragScrollManipulator.target = null;
  ```

### 適用済みの画面

- `Assets/Scripts/Runtime/4.View/OutGame/Screen/SkillTreeScreenView.cs`: `SkillTreeContainer`(スキルツリー本体、縦)に適用。
- `Assets/Scripts/Runtime/4.View/OutGame/SkillTree/SkillDetailScreenView.cs`: `SkillDetailScrollView`(スキル効果説明文、縦)に適用。あわせて `Assets/Level/Scenes/Develop/OutGameTest/SkillTree/UIToolkit/SkillDetail.uxml` の同ScrollViewに `vertical-scroller-visibility="Hidden"` を設定し、スクロールバー自体を非表示にした(ドラッグ/ホイールでのスクロールには影響なし)。

## 3. 注意: このセッションの後に外部でファイルが更新されている

`ScrollViewDragManipulator.cs` は、このセッションで最後に編集した後、**別セッションの作業により以下の変更が加わっている**ことをディスクの変更通知で確認した(このセッションで行った変更ではない):

- `DragStarted` イベント(`public event Action DragStarted;`)が追加され、ドラッグが確定した瞬間(閾値超過時)に発火するようになっている。
- `ApplyScroll` のクランプ範囲が、`contentContainer`/`contentViewport` のレイアウト差分ではなく、`ScrollView.verticalScroller.lowValue/highValue`(横方向は `horizontalScroller`)から取得する方式に変更されている。

これはおそらく改造画面(SkillBuild)側でこのクラスを流用する作業(`Assets/Scripts/Runtime/4.View/OutGame/SkillBuild/` 配下の複数ファイルが同時に更新されている形跡あり: `SkillBuildScreenView.cs`, `SkillBuildSlotLayout.cs`, `SkillElementControllerEquipController.cs`, `SkillElementDragAndDropManipulator.cs`, `SkillElementView.cs`, `SkillListView.cs`, および新規 `SkillGenreFilterBarView.cs`)によるものと推測される。**これらの変更内容はこのセッションでは未確認・未検証**。次のチャットで改造画面側の作業を引き継ぐ場合は、まずこれらのファイルの現状を読み直すことを推奨する。

## 4. 検証状況

- 研究画面側(`SkillTreeScreenView`・`SkillDetailScreenView`、縦スクロール)は、このセッション内で `uloop-compile` によりエラー0件を都度確認済み。
- 横方向(`ScrollDragAxis.Horizontal`)の分岐、および上記の外部変更(`DragStarted`・スクローラーベースのクランプ)は、このセッションでは動作検証していない。
