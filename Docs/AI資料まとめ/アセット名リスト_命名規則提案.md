# アセット名リスト（命名規則提案）

## 背景・目的

`Docs/NotionSpecifications/Symphony Kill Chord/ステータスリスト/管理用アセットリスト/マスターアセットリスト/` には、仕様書上で管理されているアセット項目が107件登録されています(2026-07-19時点)。これらを実際にUnityへ取り込む際、統一された命名規則がないままだと、既存プロジェクトで見られるような表記ゆれが今後も増えていくおそれがあります。

現状のプロジェクトで実際に確認できた表記ゆれの例:

- `Assets/Arts/Models/Symphony`, `Symphony_0304`, `Symphony_0312`, `Symphony_0319`, `Symphony_0402`, `Symphony_0404`, `Symphony_0404_2` … 日付サフィックスでモデルフォルダが並存
- `Assets/Arts/VFX/Prefabs_Hidan/Bakuhatu.prefab`, `Hidan_Hiban01.prefab`（爆破＝Bakuhatu、被弾＝Hidanのローマ字表記）
- `Assets/Arts/Models/Backgrounds/BuildingParts/Prefabs/building_06 1.prefab`（英字ケースの不統一、ファイル名中の半角スペース）

これらを踏まえ、仕様書の「マスターアセットリスト」に載っている全107項目について、カテゴリ別プレフィックス付きの英語アセット名を提案します。あくまで**命名の提案リスト**であり、本ドキュメント作成時点で実ファイルのリネームは行っていません。

## 命名規則の方針

1. `カテゴリプレフィックス_パスカルケース名` を基本形とする（例: `VFX_Explosion`）。
2. 日本語の固有名詞は英訳またはヘボン式ローマ字とし、ローマ字化する場合は仕様書中の英字表記があればそれを優先する（例: 「キルコード」→ 内部呼称の `Skill` を採用）。
3. 実銃モデル名（M82、AK-74等）は開発時の参考名であり、`プレイヤー武器.md` に「実銃を使うと銃器メーカーの権利関係があるため架空銃に改変する」と明記されている。最終的な実装アセットは拍子ベースの武器クラス名（例: `AntiMaterielRifle`）を主identifierとし、実銃名はコメント／備考欄に参考情報として留める。
4. 日付・バージョン番号をアセット名やフォルダ名に含めない。バージョン管理はGitに任せ、フォルダ名は最新版のみを保持する（既存の `Symphony_0304` 等の整理は別タスクとして検討）。
5. ファイル名に半角スペースを使わない。単語区切りは アンダースコア `_` を使用する。
6. 同一の日本語名で内容が異なるアセット（例: エフェクトの「攻撃」とモーションの「攻撃」）は、プレフィックスで種別を分けることで名前の衝突を回避する。

## 名称衝突に関する注意点

仕様書のマスターアセットリストには、**同じ日本語タイトルで内容（種別）が異なるページ**が複数存在します。Unity側でアセット化する際は必ずプレフィックスで区別してください。

| 日本語タイトル | 実体1 | 実体2 |
|---|---|---|
| 攻撃 | `VFX_Attack`（発砲エフェクト、役職:エフェクト） | `MOT_Attack`（構え・反動モーション、役職:キャラモデラ―） |
| ノックバック | `VFX_Knockback`（Symphonyノックバック時エフェクト） | `SE_Knockback`（金属が弾けるような高音SE） |
| 設定ボタン | `UI_SettingsButton_OutGame`（タイトル/ホーム画面用） | `UI_SettingsButton_InGameScenario`（シナリオパート用） |

## 今後の検討事項

- 既存プロジェクトの `Assets/Arts/Models/Symphony_03xx` 系フォルダや `Bakuhatu.prefab` 等、本提案の命名規則に沿っていない既存アセットのリネームは本ドキュメントの範囲外です。実施する場合は参照切れが起きないよう別タスクとして計画してください。
- 「タイトル音」と「ゲーム開始音」、「6拍子武器のジャンル名」など、仕様書内で表記に軽微な揺れがある項目は、命名確定前に仕様書側（Notion）での用語統一を推奨します（[用語集_追加候補.md](用語集_追加候補.md) にも同様の指摘あり）。
