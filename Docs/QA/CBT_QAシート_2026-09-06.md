## 0. CBTの範囲 (このシートが対象とする範囲)

### 0-1. CBTの定義

本CBTは **Google Play の「クローズドテスト」トラック** を指す。2023-11-13 以降に作成した
**個人デベロッパーアカウント** には、本番アクセス申請の前提として
**12人以上が連続14日間オプトインした状態** が課される。日数は作業量では短縮できない。

| 項目 | 値 | 出所 |
|---|---|---|
| トラック | Google Play クローズドテスト | ストア仮登録資料 §2-1 |
| 必要テスター数 | 12人以上 (実機Android + Googleアカウント) | 同上 |
| 必要期間 | 連続14日間のオプトイン維持 | 同上 |
| プラットフォーム | Android のみ (ARM64 / IL2CPP) | `ProjectSettings.asset` |
| Target SDK | API 36 (Android 16) | 同上 |
| パッケージ名 | `jp.sinfoniastudio.symphonykillchord` | 2026-08-14 確定 |
| デベロッパー名 | Sinfonia Studio | 2026-08-14 確定 |
| リリース目標 | 2026-10-31 | 声優契約条件 (A1) |

> 「オプトイン」= テスターが招待を承諾し、**そのGoogleアカウントで実際にインストールした**状態。
> 招待しただけ・未インストールの人は12人にカウントされない。

### 0-2. ビルドに含まれるシーン (= プレイ可能範囲の上限)

`EditorBuildSettings.asset` に登録され、有効化されているシーンは以下の7本のみ。

| # | シーン | 役割 |
|---|---|---|
| 1 | `Master/Persistent.unity` | 常駐 (段階的初期化・逆順shutdown) |
| 2 | `Master/Title.unity` | タイトル |
| 3 | `Master/OutGame.unity` | Home / 作戦 / 研究 / 改造・編成 / 設定 |
| 4 | `Master/InGame.unity` | 戦闘の共通土台 |
| 5 | `Master/Scenario.unity` | シナリオ再生 |
| 6 | `Master/Stages/Stage_01.unity` | 戦闘ステージ 1 |
| 7 | `Master/Stages/Stage_02.unity` | 戦闘ステージ 2 |

`InGameDodgeTest.unity` は `enabled: 0` (ビルド対象外)。

### 0-3. 範囲内 / 範囲外

**範囲内 (CBTでテスターに触らせる)**

- タイトル → New Game / Continue の導線
- チュートリアル (ステージ0相当) — リズムアクション / 通常戦闘の予告
- 戦闘ステージ **2本** (Stage_01 / Stage_02)、1ステージ約2分想定 (GS-05)
- リズム判定と武器選択 (2拍=ショットガン / 4拍=ハンドガン / 8拍=サブマシンガン, GS-01/GS-02)
- キルコード成立とスキル効果 (GS-03)
- リザルト表示・ランク・報酬受領 (GS-05/GS-06)
- スキル装備 (初期2枠) / スキルツリー解放 / 研究 (GS-03/GS-06/GS-09)
- 設定オーバーレイ・ポーズ・セーブ復帰 (GS-07/GS-09)
- Android 30 FPS / ロード3秒 / 15分連続無エラー (GS-08)

**範囲外 (CBTでは評価しない・見せない)**

- Stage_03 以降。`StageBind_B02.S03` 〜 `StageBind_S11.S12` のマスタデータは存在するが、
  対応するステージシーンが存在せず、ビルドにも含まれていない。**選択できてしまう場合は不具合として報告する。**
- PC (Windows / Steam) ビルド。CBTはAndroidのみ。
- ARMv7 (32bit) 端末。ARM64単独ビルドのため動作対象外。
- 本番セリフ・本番BGMの完成度評価 (差し替え中の可能性がある)。
- 課金・オンライン・アカウント連携 (実装対象外)。
