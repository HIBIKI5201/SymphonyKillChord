## 適用する本文

英名: EnemyWave
ステージ内の敵出現単位。1 Wave ごとに、出現する敵の種類と数、制限時間（WaveDuration）、スポーン候補、ステージ演出を設定する。
場の敵の生存数と入場待ちの数がともに 0 になるか、WaveDuration が経過すると次の Wave へ進む。時間経過で進んだ場合は、前の Wave の残りと重なって出現する。ループ設定があるときは、最後の Wave の後にループ開始位置の Wave へ戻る。
仕様概要の「フェーズ」と同じ概念である。コード・マスターデータ・システム概要は「Wave」、仕様概要は「フェーズ」と呼んでいる。
