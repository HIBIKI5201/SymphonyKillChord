## 適用する本文

英名: RhythmGuide
直前の入力からの経過を示し、拍子ごとの入力範囲とタイミングを視覚的に表示するHUD。画面の中央から左右対称に伸びる横長のゲージで、全長はリズムタイムアウトと同じ2小節である。拍子ごとに範囲を武器の色で色分けし（1拍 = 紫（スナイパー）、2拍 = 青（ショットガン）、3拍 = 水色（リボルバー）、4拍 = 緑（アサルト）、6拍 = 黄（ハンドガン）、8拍 = オレンジ（SMG））、Just判定のタイミングを黄色の帯で示す。Just判定の帯は、判定幅に関係なく一定の太さ（現在の見た目の太さ）で描く。攻撃硬直で入力できない範囲は、ゲージを灰色にする。ロックオン対象がいないときも、ゲージは半透明にしない。
※色の対応と帯の太さ、灰色の表示は未実装（現行は 1拍 = オレンジ … 8拍 = 紫の順で、帯は判定幅の 1/3 の太さで描いている）。
