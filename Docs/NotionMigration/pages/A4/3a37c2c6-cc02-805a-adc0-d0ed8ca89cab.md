## 適用する本文

英名: RhythmGuide
直前の入力からの経過を示し、拍子ごとの入力範囲とタイミングを視覚的に表示するHUD。画面の中央から左右対称に伸びる横長のゲージで、全長はリズムタイムアウトと同じ2小節である。拍子ごとに範囲を色分けし（1拍 = オレンジ、2拍 = 黄、3拍 = 緑、4拍 = シアン、6拍 = 青、8拍 = 紫）、Just判定のタイミングを黄色の帯で示す。
