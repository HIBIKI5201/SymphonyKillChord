## 領域全体で見つかった矛盾（重大な順）

1. **リズムタイムアウトは 2 小節**（用語は 1.5 小節）。`RhythmJudgmentDefinition.cs:32` `TIMEOUT_BAR_COUNT = 2f`、PR #1896。仕様概要 / リズム判定 も同じ誤り（BT-05）
2. **Just ダメージ倍率が全武器 1.0**（仕様 200%）で、Just によるダメージ増加が無い。判定幅も ±0.1 秒ではなく 1 小節の 0.03125（BPM84 で約 89ms、TGS で 1.25 倍に緩和）（BT-01 / BT-02、要企画確認）
3. **マニュアル／オートロックオンの対象選定が HP・視界を見ていない**。カメラ正面方向の内積最大、全員背面なら最寄り。オートの解除に移動操作は含まれない（CM-01 / CM-02）
