## 適用する本文

英名: ScreenTransitionType
アウトゲームの画面を切り替えるときの方式。Replace / Overlay / Reset の 3 種があり、画面ごとに遷移ルール（ScreenRuleData）で指定する。
- Replace: 前の画面を隠して切り替える
- Overlay: 前の画面を残したまま、上に重ねて表示する
- Reset: 画面の履歴を消してから表示する

Replace と Overlay では、ルールで「履歴に残す」が指定されていれば前の画面を履歴に積む。「戻る」は履歴を 1 つ戻る。履歴が空なら何もしない。ルールが未定義の画面は表示できない（エラーになる）。

| 画面 | 遷移種別 | 設定アセット |
| --- | --- | --- |
| ホーム（Home） | Reset | OutGameScreenRuleData |
| 作戦（StageSelect）・研究（SkillTree）・改造（SkillBuild） | Replace | OutGameScreenRuleData |
| 設定（Setting） | Overlay | OutGameScreenRuleData |
| タイトル（Title） | Reset | TitleScreenRuleData |
| タイトルのメニュー（Menu） | Overlay | TitleScreenRuleData |
| クレジット（Credit） | Replace | TitleScreenRuleData |
