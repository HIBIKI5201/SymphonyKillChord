## 適用する本文

敵を撃破しクリア条件が満たされると、評価結果が生成・保存され、リザルト画面へ反映される。撃破数はHPが0になった瞬間に通知されるため、撃破数を数えるミッションは死亡演出の途中でもクリアしうる。一方、最終ウェーブまでの全敵撃破（`AllEnemyWavesClearCondition`）は、生存数が減る死亡演出の完了後に`MissionWaveController`から通知される。どの通知でも、目標ステップを進めてから失敗→クリアの順に判定する。
キル数の計上とウェーブの全滅判定は、同じタイミングで行う。上記の時間差は現状の実装であり、修正が必要である。どちらのタイミングに揃えるかは【要確認: HP0 の瞬間と死亡演出の完了後のどちらに揃えるかを企画に】。

```mermaid
sequenceDiagram
    autonumber
    participant Enemy as EnemyLifeCycle / BossLifeCycle
    participant MWave as MissionWaveController
    participant EventCtrl as MissionEventController
    participant Runtime as MissionRuntimeService
    participant Seq as SequenceInitializationModule
    participant SaveSvc as StageProgressSaveDataService
    participant Director as InGameSequenceDirector
    participant Result as StageResultPresenter

    alt 撃破数の条件
        Enemy ->> EventCtrl: NotifyEnemyKilled(enemyMissionKey)（HP0の瞬間）
        EventCtrl ->> Runtime: OnEnemyKilled
    else 全ウェーブ撃破の条件
        MWave ->> Runtime: OnEnemyWavesCleared（最終ウェーブの死亡演出完了後）
    end
    Runtime ->> Runtime: 目標ステップを進める（CheckObjectiveStepChanged）
    Runtime ->> Runtime: MissionRuleRunner.Evaluate（失敗判定→クリア判定）
    alt クリア条件を満たす
        Runtime ->> Runtime: MissionProgress.Finish(Clear)
        Runtime -->> Seq: OnMissionFinished(Clear)
        Seq ->> Runtime: BuildEvaluationResult()
        Runtime -->> Seq: MissionEvaluationResult
        Seq ->> SaveSvc: SaveClearAsync(stageId, firstClearReward, clearReward, evaluationResult, isTutorial)
        Seq ->> Director: ClearAsync(evaluationResult)
        Director ->> Director: ゲームプレイ停止・クリア演出（Timeline）・クリアボイス
        Director ->> Result: PresentVictory(evaluationResult)
        Result ->> Result: StageRankCalculator.Calculate(AchievedCount)
    else 失敗条件を満たす
        Runtime -->> Seq: OnMissionFinished(Fail)
        Seq ->> Director: GameOverAsync
    end
```
