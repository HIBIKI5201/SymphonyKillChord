## 適用する本文

戦闘ポーズには、プレイヤーの入力による通常ポーズと、シナリオ再生に伴うポーズの2系統がある。両者は同じ`BattlePauseController`が扱うが、通常ポーズ中にシナリオが始まった場合、シナリオ終了時に通常ポーズを解除してはならないため、状態を区別して保持する。

通常ポーズはオプション入力（キーボード Esc / ゲームパッド Start。入力マップ Common の Option）で切り替える。開始演出の再生中と、戦闘終了からリザルト表示までの間は受け付けない。

```Mermaid
sequenceDiagram
    autonumber
    actor Player as プレイヤー
    participant Input as PlayerInputView
    participant Init as SequenceInitializationModule
    participant Ctrl as BattlePauseController
    participant Module as BattlePauseModule
    participant Music as MusicPlayer
    participant PauseUI as PauseWindowInitializer / PauseWindowView (UIモジュール)
    participant Mission as MissionDialogueController / MissionScenarioController (Missionモジュール)

    Player ->> Input: オプション入力（Esc / Start）
    Input -->> Init: OnOptionInput（Startedのみ処理）
    Init ->> Init: 開始演出中・リザルト表示中なら無視
    Init ->> Ctrl: Toggle()
    Note over Ctrl: シナリオポーズ中はToggleを無視する
    Ctrl ->> Module: TryPause()
    Module ->> Module: 入力マップをCommonのみに切替
    Module ->> Music: PauseBGM()
    Module ->> Module: Time.timeScale = 0
    Module -->> Ctrl: true
    Ctrl -->> PauseUI: OnPaused
    PauseUI ->> PauseUI: ポーズウィンドウを表示（初期選択はリスタート）

    alt 再開（UIの取消。もう一度Optionを押した場合はInitがToggle()を呼ぶ）
        PauseUI ->> Ctrl: Resume()
        Ctrl ->> Module: Resume()（ResumeBGM・InGame+Commonを有効化・timeScale = 1）
        Ctrl -->> PauseUI: OnResumed（ウィンドウを閉じる）
    else リスタート
        PauseUI ->> Ctrl: Resume()
        PauseUI ->> PauseUI: StageResultController.RetryAsync()（失敗したらポーズへ戻す）
    else タイトルへ戻る
        PauseUI ->> PauseUI: 「③ タイトル復帰フロー（ポーズ画面）」へ
    end

    Note over Mission: 会話・シナリオ再生はIScenarioBattlePauseControllerとして呼ぶ
    Mission ->> Ctrl: BeginScenarioPause()
    Ctrl ->> Ctrl: 通常ポーズ中だったかを記録し、そうでなければPause()
    Ctrl -->> Mission: OnScenarioPauseStarted
    Mission ->> Ctrl: EndScenarioPause()
    Ctrl ->> Ctrl: 通常ポーズ中だった場合はポーズを維持し、そうでなければResume()
    Ctrl -->> PauseUI: OnScenarioPauseEnded
    PauseUI ->> PauseUI: 通常ポーズが続いていれば、入力マップを再びCommonのみに戻す
```

ポーズウィンドウは次のとおりである。

- ボタンは「リスタート」（表示時の初期選択）と「タイトルへ戻る」の2つ
- UIの取消入力（Cancel）、またはもう一度オプション入力で閉じて再開する
- ポーズ中もインゲームHUDは表示したままで、その上にウィンドウを重ねる
- HUD上のポーズボタン、オプション、ミッション表示、再開時のカウントダウンは未実装である（議事録「インゲームUI会議」とβ版指針にある要素。未実装として残す）
