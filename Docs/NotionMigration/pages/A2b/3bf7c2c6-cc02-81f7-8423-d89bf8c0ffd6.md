## 適用する本文

戦闘中にポーズ画面を開き、「タイトルへ戻る」を選ぶと、リザルトを経由せずタイトルシーンへ戻る。

```Mermaid
sequenceDiagram
    autonumber
    actor Player as プレイヤー
    participant View as PauseWindowView (UIモジュール)
    participant Init as PauseWindowInitializer (UIモジュール)
    participant Pause as BattlePauseController
    participant Ctrl as ReturnToTitleController
    participant SceneUC as SceneTransitionUsecase

    Player ->> View: 「タイトルへ戻る」ボタン
    View -->> Init: OnReturnToTitleRequested
    Init ->> View: ボタン操作を無効化（多重実行防止）
    Init ->> Pause: Resume()（timeScaleとBGMを通常状態へ戻す）
    Init ->> Ctrl: ReturnToTitleAsync(現在のシーン名, token)
    alt バトルステージを選択中
        Ctrl ->> SceneUC: UnloadThenChangeSceneAsync(battleScene, inGameScene, "Title")
    else 未選択（チュートリアル直起動など）
        Ctrl ->> SceneUC: ChangeSceneAsync(現在のシーン, "Title")
    end
    alt 成功
        Ctrl ->> Ctrl: SelectedBattleStageState / SelectedMissionStateをクリア
    else 失敗
        Ctrl -->> Init: false
        Init ->> Pause: Pause()（ポーズ画面を再表示し、操作を戻す）
    end
```

> 以前は「プレイ中に ESC を長押しするとタイトルへ戻る」方式だったが、2026-09-05 にポーズ画面のボタンへ置き換えた。
