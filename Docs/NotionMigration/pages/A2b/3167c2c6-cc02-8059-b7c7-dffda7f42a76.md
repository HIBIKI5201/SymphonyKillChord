## 実装（SilToon）
研究の成果は、キャラクター用シェーダー **SilToon** として実装されている。プレイヤーのモデルが使っている。

| シェーダー | 場所 | 用途 |
| --- | --- | --- |
| `Custom/SilToon/Base` | `Assets/Scripts/Shaders/SilToon/SilToon.shader` | 本体・髪・肌・目など |
| `Custom/SilToon/FaceOverlay` | `Assets/Scripts/Shaders/SilToon/SilToonFaceOverlay.shader` | 目・眉のオーバーレイ（半透明で重ねる） |

処理は `Assets/Scripts/Shaders/SilToon/HLSL/` 以下の HLSL に分かれている（Fragment / OutLine / FakeShadow / PerspectiveRemoval / Dither など）。マテリアルは `Assets/DevelopProducts/Research/ToonShader/Materials/Symphony/SilToon/` にある。

### パス構成
| Pass | 内容 |
| --- | --- |
| MAIN | 3 階調のトゥーン陰影に、リムライト・PBR・SSS を重ねる本体の描画 |
| OUTLINE | 背面法のアウトライン（`Cull Front`） |
| FAKE_SHADOW | 髪が顔に落とす疑似影。URP の RenderObjects 機能で不透明描画の後に実行する |
| ShadowCaster | URP 標準の影の書き込み |

キャラクター専用のセルフシャドウは、`SilToonShadowCaster`（キャラクターのルートに付けるコンポーネント）と `SilToonShadowFeature` / `SilToonShadowRenderPass`（URP のレンダラー機能）が描く。

### プロパティのグループ
| グループ | 主なプロパティ |
| --- | --- |
| 基本 | `_BaseMap`、3 階調の色 `_ColorLit` / `_ColorMiddle` / `_ColorShadow`、顔用の切り替え `_IsForFace` と `_FaceUp`、セルフシャドウ `_CharShadowOn`、フェード `_FadeOn` / `_FadeAlpha` |
| Normal | `_NormalMap`、`_NormalMapIntensity` |
| Fresnel | `_FresnelBackLight`（既定 8）、`_FresnelFrontRimLight`（既定 4）、`_FresnelBackRimLight`（既定 0.5） |
| PBR | `_PBROn`、`_MetallicMap` / `_Metallic`、`_RoughnessMap` / `_Roughness`、`_SpecularIntensity`、`_EnvReflectionIntensity` |
| SSS | `_SSSOn`、`_SSSColor`、`_SSSWrap`、`_SSSIntensity`、`_SSSThickness`、`_SSSTransmissionPower` |
| OutLine | `_OutlineColor`、`_ZOffset`、`_IsSmoothNormal`、`_OutlineWidthLit` / `_OutlineWidthShadow` |
| Smears | 残像 `_SmearsOn`、`_SmearsPower`、`_SmearsDirection` |
| PerspectiveRemoval | `_PerspectiveRemovalRatio`、`_PerspectiveRemovalRadius`、`_Head` |
| FakeShadow | `_FakeShadowOn`、`_FakeShadowColor`、`_FakeShadowOffset`、`_FakeShadowDepthBias` |
| RenderState | ステンシル `_StencilRef` / `_StencilReadMask` / `_StencilWriteMask` / `_StencilComp` / `_StencilPass` / `_StencilFail`。ビットの用途は bit0 = 目の透け、bit1 = 顔領域（FakeShadow 用）、bit2 = FakeShadow の描画済みマーク |

各プロパティの推奨値と意図は【要確認: 担当のテクニカルアーティストに確認】。

### 研究ページとの対応
| 研究ページ | SilToon での実装 |
| --- | --- |
| 背面法を利用したアウトラインの作成 | OUTLINE パス。頂点を法線方向に押し出し、表面を描かない（`Cull Front`） |
| ハードエッジ問題 | `_IsSmoothNormal` をオンにすると、UV4（シェーダーでは TEXCOORD3）に焼き込んだスムーズノーマルでアウトラインを押し出す |
| アウトラインの太さを制御したい | 光の当たり具合で `_OutlineWidthShadow`（暗い面）と `_OutlineWidthLit`（明るい面）の間を補間する |
| アウトラインもカラフルにしたい | 未実装。アウトラインの色は `_OutlineColor` の単色である |
| 顔だけアウトライン処理を変えたい(簡略化) | `_ZOffset` でアウトラインの頂点をカメラから遠ざけ、細かいパーツの線を本体に埋める |

### 関連ツール
- スムーズノーマルの焼き込み: メニュー「Tools/MeshAssetTool/①Generate Mesh Assets」「②Apply Mesh Assets」、またはメッシュの Inspector 上部の「BakeSmoothNormals」ボタン（`Assets/DevelopProducts/Research/ToonShader/Scripts/Editor/`）
- マテリアルの Inspector: `SilToonGUI` / `SilToonFaceOverlayGUI`

## 揺れ物
キャラクターの揺れ物はハイブリッドにする。チェーン型（髪など）は軽量な SpringBone、布型（服など）は正確な Magica Cloth 2 を使う。負荷のベンチマークは今後測る（Issue 化予定）。

| 仕組み | 対象 | 導入状況 |
| --- | --- | --- |
| SpringBone | チェーン型（髪など） | 導入済み。パッケージ `com.unity.springbone`（UnityChanSpringBone 1.2、`Packages/manifest.json`）。研究用のプレハブが `Assets/DevelopProducts/Research/SpringBone/` にある |
| Magica Cloth 2 | 布型（服など） | 未導入 |

併用するときは次の点に気をつける。
- 同じボーンを両方で動かさない
- コライダーが二重になる
- スローモーション時の時間倍率を両方で揃える
- 瞬間移動したときに揺れをリセットする
- スマホでの負荷
