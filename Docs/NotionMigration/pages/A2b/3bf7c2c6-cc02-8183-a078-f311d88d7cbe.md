## 適用する本文

敵がスポーン（プールから有効化）した際、敵1体ごとの`EnemyLifeCycle` / `BossLifeCycle`が自身をターゲットシステムへ登録する。`TargetSystemController`は、`EnemyInitializer`がContainerから取り出して各LifeCycleへ渡している。敵が死亡すると登録を解除し、以後はロックオン・範囲判定の対象から外れる。

```Mermaid
sequenceDiagram
    autonumber
    participant EnemyComp as EnemyLifeCycle / BossLifeCycle
    participant Targetable as TransformTargetable
    participant Controller as TargetSystemController
    participant TSys as TargetingSystem
    participant Registry as TargetEntityRegistry

    EnemyComp ->> Targetable: 生成（敵ID・対象Transform・Colliderを渡す）
    EnemyComp ->> Controller: RegisterTarget(targetable, CharacterEntity)
    Controller ->> TSys: RegisterTarget(targetable)
    Controller ->> Registry: RegisterEntity(targetId, CharacterEntity)
    Note over EnemyComp: 死亡時
    EnemyComp ->> Controller: UnregisterTarget(targetable)
    Controller ->> TSys: UnregisterTarget(targetable)
    Controller ->> Registry: UnregisterEntity(targetId)
```
