## 適用する本文

次のWaveは、ウェーブ内の全敵の撃破、`WaveDuration`（秒）の経過、ミッションの目標ステップのいずれかを起点に生成され、Wave開始が他モジュールへ通知される。最初のWaveはゲームプレイ開始時（`EnemyWaveTimerView.StartGameplay`）に生成する。時間切れで進んだ場合、前のWaveの残りと重なって出現する。Wave列にループが設定されていれば、最後まで進んだあとループ開始位置へ戻る。

生成を始める前に、そのWaveの出現予定数を「入場待ち数」として予約し、敵が入場を終えるたびに生存数へ移す。全滅は生存数と入場待ち数がともに0になったときだけ成立する。生存数が減るのは敵の死亡演出が終わってからである（⑤）。

ミッションの目標シーケンスに`WaveStartClearCondition`を持つステップがある場合は、全滅と時間切れによる自動生成を止め、`MissionWaveController`が該当ステップの開始時に次のWaveを生成する。

```mermaid
sequenceDiagram
    autonumber
    participant EWTimerView as EnemyWaveTimerView
    participant MWave as MissionWaveController (Missionモジュール)
    participant EWState as EnemyWaveSpawnerState
    participant EWCont as EnemyWaveSpawnerController
    participant Spawner as EnemySpawnerRouter (IEnemySpawner)
    participant StageEffect as StageEffectInitializer (Stageモジュール)

    alt ゲームプレイ開始
        EWTimerView ->> EWCont: SpawnNextWave（Missionが制御する場合は呼ばない）
    else 全敵が撃破された（OnWaveCleared）
        EWState -->> EWCont: OnWaveCleared イベントコールバック (SpawnNextWave)（Missionが制御する場合は購読しない）
    else WaveDuration が経過した
        EWTimerView ->> EWCont: SpawnNextWave（Missionが制御する場合はタイマーを止めるだけ）
    else WaveStartClearCondition を持つ目標ステップが始まった
        MWave ->> EWCont: SpawnNextWave
    end
    EWCont ->> EWCont: 次の EnemyWaveDefinition を取得
    alt 次ウェーブが存在する
        EWCont ->> EWState: ReserveEnemySpawns（出現予定数を入場待ち数として予約）
        EWCont ->> EWState: SetLastWave（最終Waveの場合）
        EWCont ->> EWState: NotifyWaveStarted(waveIndex, definition)
        EWState -->> StageEffect: OnWaveStarted イベント発火（StageEffectIdsを含む）
        StageEffect ->> StageEffect: IDから自身のカタログを検索し、該当演出をBGM同期で再生
        EWCont ->> Spawner: 敵定義ID・数・スポーン候補を指定して生成指示（歩兵/砲兵のスポナーへ振り分け）
        Spawner -->> EWState: 入場に成功した敵ごとに AddEnemyCount（入場待ち数 → 生存数）
        EWCont ->> EWTimerView: ウェーブタイマー設定 (SetTimer: waveDuration)
    else 全ウェーブクリア
        EWCont ->> EWTimerView: タイマー停止 (StopTimer)
    end
    Note over EWState: 最終Waveで生存数・入場待ち数が0になると OnWaveAllCleared を発火し、MissionWaveController がミッションへ全Wave撃破を伝える
```
