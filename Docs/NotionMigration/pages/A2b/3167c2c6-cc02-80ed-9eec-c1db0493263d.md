## 現在の実装
現在は、キャラクター用シェーダー SilToon のアウトライン（`Assets/Scripts/Shaders/SilToon/HLSL/OutLine/`）で、この考え方を実装しています。
マテリアルでは、明るい面の幅を `_OutlineWidthLit`、暗い面の幅を `_OutlineWidthShadow` で設定します。
計算は次の手順です（`LuminanceToOutlineThickness.hlsl`）。
1. メインライトの向き（モデルからライトへ向かう向き）と、ワールド空間の法線の内積を取り、saturate で 0〜1 にする
2. メインライトの影の減衰（影の中なら 0 に近い）を掛ける
3. 0.5〜1 の範囲に寄せる（`結果 × 0.5 + 0.5`）
4. その値で `_OutlineWidthShadow` から `_OutlineWidthLit` へ補間した幅だけ、頂点を押し出す

手順 3 があるため、一番暗い面でも、太さは 2 つの幅のちょうど中間になります。【要確認: この寄せが意図どおりか、担当に確認】

現在のマテリアルの値は次のとおりです。

| マテリアル | `_OutlineWidthLit` | `_OutlineWidthShadow` |
| --- | --- | --- |
| SilToon.mat（体） | 0.001 | 0.002 |
| SilToonHair.mat（髪） | 0.0001 | 0.0005 |
| SilToonEye.mat（目） | 0.0005 | 0.0005 |
