## 適用する本文

InGameシーン起動直後、ロード画面の完了を待ってから開始演出を再生し、ゲームプレイを開放する。

```Mermaid
sequenceDiagram
    autonumber
    participant Init as SequenceInitializationModule (Ready)
    participant Loading as LoadingScreenController (Persistent)
    participant Director as InGamePlayDirector
    participant SeqDirector as InGameSequenceDirector
    participant SeqView as StageSequenceView
    participant Fade as StageStartFadeView
    participant Hud as InGameHudVisibilityView
    participant Amb as AmbienceSoundView

    Init ->> Director: StopGameplay()（ゲームプレイを凍結した状態で開始）
    alt ロード中
        Init ->> Loading: LoadingCompletedを購読
        Loading -->> Init: LoadingCompleted(isSuccess)
    end
    alt ロード成功（またはロード中でない）
        Init ->> SeqDirector: Start()
        SeqDirector ->> Director: StopGameplay()
        SeqDirector ->> Fade: ShowBlackImmediate()
        SeqDirector ->> Hud: Hide()
        SeqDirector ->> Amb: PlayAmbience()
        SeqDirector ->> SeqView: PlayStageStart(完了コールバック)
        SeqDirector ->> Fade: PlayFadeOut()
        SeqView -->> SeqDirector: 開始Timelineの停止（完了コールバック）
        SeqDirector ->> Amb: StopAmbience()
        SeqDirector ->> Director: StartGameplay()
        Note over Director: 登録済み全IGameplayControllableへ一斉伝播（Enemy/Player/Music/Input等）
        SeqDirector ->> Hud: Show()
    else ロード失敗
        Init ->> Fade: ShowBlackImmediate()（黒画面のまま）
        Init ->> Init: StageResultController.CompleteAsync()でOutGameへ戻る（専用出撃ならPersistentに任せる）
    end
```

開始演出の時系列と値は次のとおりである。

| 名前 | 値 | 単位 | 正本 |
|---|---|---|---|
| 黒画面の保持 | 0.2 | 秒 | `Assets/Level/Data/Master/InGame/StageStartSequenceConfig.asset`（`_blackholdDuration`） |
| フェードアウト | 0.4 | 秒 | 同上（`_fadeOutDuration`） |
| 開始Timelineの長さ | 約8 | 秒 | `Assets/Arts/Animation/Timelines/StageStart.playable`（Animation Track 1〜7.98秒） |
| 黒帯の表示 | 0秒（1フレーム目）に表示、7秒から1秒かけて解除 | 秒 | `StageStart.playable`、黒帯のアスペクト 4.7:1 は`LetterBoxAnimationGUI` |

- 開始ボイス`VOICE_Battlestart`は、Timeline の Signal から再生する
- 開始演出中は環境音`SE_Ambience_Ingame`を鳴らし、ゲームプレイ開始時と演出の中断時に止める
- 開始演出の再生中はポーズを受け付けない
- 演出を調整する場所は、`StageStartSequenceConfig`（黒画面・フェード）、`StageStart.playable`（カメラ・黒帯・Signal）、Timeline の Signal を受ける SignalReceiver である
