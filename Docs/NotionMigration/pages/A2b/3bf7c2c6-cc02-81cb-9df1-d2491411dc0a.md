## 適用する本文

アウトゲームで選択したミッションが、インゲーム側で構築される。アウトゲームからは`MissionId`だけを渡し、ミッション定義はインゲームの初期化でリポジトリから作る。初期化はResourceLoadAsync→Build→Readyのフェーズ順に、全モジュールをOrder順で実行する。

```mermaid
sequenceDiagram
    autonumber
    participant Sortie as BattleSortieSelectionService
    participant OutGame as OutGameMissionSelectController
    participant State as SelectedMissionState
    participant Init as InGameMissionInitializer (Order 600)
    participant Repo as MissionDefinitionRepository
    participant Runtime as MissionRuntimeService
    participant Recorder as MissionProgressRecorderController

    Sortie ->> OutGame: Select(BattleStageDefinition.MissionId)
    OutGame ->> State: SelectMission(missionId)
    Note over Init: InGameシーン読み込み後、ResourceLoadAsync フェーズ
    Init ->> State: CurrentMissionId を取得
    Init ->> Repo: Addressablesでロードし TryCreateMissionDefinition(missionId, EnemyMissionKeyRepository)
    Repo -->> Init: MissionDefinition
    Init ->> Init: シナリオ再生条件があればシナリオ用カタログもロード
    Note over Init: Build フェーズ
    Init ->> Runtime: MissionProgress 生成 + 各Usecase/Runnerを構成
    Init ->> Init: MissionHud・MissionEventController を構築し、生の型でも ServiceLocator へ登録
    Init ->> Init: MissionModuleContainer を ServiceLocator へ登録
    Note over Init: Ready() フェーズ
    Init ->> Recorder: Bind(PlayerEntity, PlayerController, PlayerAttackController, SkillController, TargetSystemController, MusicSyncService)
    Init ->> Init: ポップアップ・バフ・進入時アクション・会話・シナリオ再生・チュートリアルの成功表示を構築
```
