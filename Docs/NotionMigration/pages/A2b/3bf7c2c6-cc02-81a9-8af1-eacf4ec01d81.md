## 適用する本文

Enemyモジュールから通知されたウェーブ開始をきっかけに、そのウェーブへ設定された演出を、音楽の拍に合わせて再生する。

```Mermaid
sequenceDiagram
    autonumber
    participant Spawner as EnemyWaveSpawnerState (Enemyモジュール)
    participant Init as StageEffectInitializer
    participant Scheduler as MusicSchedulerAdaptor (Musicモジュール)
    participant Presenter as StageEffectPresenter
    participant VM as StageEffectViewModel
    participant View as StageEffectView
    participant Effect as IOneShotVisualEffect 実装

    Spawner -->> Init: OnWaveStarted(waveIndex, waveDefinition)
    loop waveDefinition.StageEffectIds の各ID
        Init ->> Init: 演出カタログからIDで定義を引く
        alt 見つからない
            Init ->> Init: 警告を出して次のIDへ
        else 見つかった
            Init ->> Scheduler: Schedule(定義の音楽同期値, 実行処理)
            Scheduler -->> Init: 指定の小節・拍で実行
            Init ->> Presenter: Present(定義)
            Presenter ->> VM: Apply(演出ID, 演出種類)
            VM ->> View: 再生要求
            View ->> Effect: 演出IDと種類が一致するワンショット演出を再生
        end
    end
```
