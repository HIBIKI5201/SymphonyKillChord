## 現在の実装
現在は、キャラクター用シェーダー SilToon（`Assets/Scripts/Shaders/SilToon/SilToon.shader`）の OUTLINE パスで背面法を実装しています。
ShaderGraph の「表示面(RenderFace)を裏面(Back)にする」設定は、SilToon では `Cull Front` で同じことをしています。
頂点シェーダー（`HLSL/OutLine/OutLine.hlsl`）では、次の順に処理します。
1. 押し出しに使う法線を選ぶ（`_IsSmoothNormal` がオンならスムーズノーマル。「ハードエッジ問題」を参照）
2. 法線のカメラ奥向きの成分を 0 にする（カメラの奥側へ押し出さないため）
3. 明るさに応じたアウトライン幅で、法線方向に押し出す（「アウトラインの太さを制御したい」を参照）
4. PerspectiveRemoval・Smears（残像）が有効なら適用する
5. `_ZOffset` の分だけカメラから遠ざける（「顔だけアウトライン処理を変えたい(簡略化)」を参照）

アウトラインの色は `_OutlineColor` の単色です。
