## 判定

- 信頼性: 一部古い — 分岐が 2 つ（ロックオン中 / なし）になっているが、実装は 3 つ（ロック中 / 候補 / 非表示）。`HUDEnemyHealthDTO` の引数も `isLockon` ではなく `LockOnDisplayState`。PR #1434 で、ロック中の表示が体力割合の画像からレティクル＋体力バーに変わった。確認は 73fefeb45
- 整合性: 実装との矛盾（上記。`HUDEnemyHealthPresenter.cs:36-63`）。「その他の敵」のマーカーはレティクル（3bf7c2c6-cc02-81b8-ad8c-cc400c63704e）の担当
- 変更点:
  - 図: 旧: `alt ロックオン中 / else ロックオン対象なし` → 新: `alt ロック中 / else 候補あり / else 対象なし` の 3 分岐。DTO の引数を `LockOnDisplayState` に修正
  - 図: 呼び出し名を `Update()` に修正（`HUDEnemyHealthInitializer` が `OnUpdate` に `Presenter.Update` を登録）
  - 図: View 側の表示（レティクル＋体力バー / 黄色の点 / 非表示）を追加
- 織り込んだ反映項目: HD-09、CM-14（システム概要側）
- 出典: `Runtime/3.Adaptor/InGame/UI/HUDEnemyHealthPresenter.cs`、`Runtime/4.View/InGame/UI/HUDEnemyHealthView.cs:25-50,79-81,103-117`、`Runtime/6.Composition/InGame/UI/HUDEnemyHealthInitializer.cs:54-55`、PR #1434
- 要確認: 候補の点の色・サイズ（黄色 (1, 0.85, 0.2)・12px）は 20_ 文書の `InGameCanvas.prefab:623-624` による。本文には「黄色の点」とだけ書いた
