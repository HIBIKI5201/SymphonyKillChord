## 適用する本文

Timelineのクリップ区間がタレットへコマンドを送り、ECSが弾の生成と更新を担う。弾はプレイヤーへの当たり判定を持たない見た目だけの演出で、Stage_01（`Barrage_01.unity`）だけに配置している。タレットと弾の数値は親ページの「🎯 弾幕システム」を参照する。

```Mermaid
sequenceDiagram
    autonumber
    participant Clip as BarrageFireClip / BarrageFireBehaviour
    participant Routing as TurretRequestRoutingSystem
    participant Fire as TurretFireSystem
    participant Update as BulletUpdateSystem
    participant Job as BulletUpdateJob
    participant Pause as PauseManager (SymphonyFrameWork)
    participant Bridge as BarragePauseBridge
    participant Group as BarrageSystemGroup

    Clip ->> Routing: 発射コマンド（TurretId 付き）
    Routing ->> Fire: 対応するタレットへ振り分け
    loop 設定間隔ごと
        Fire ->> Fire: 弾のEntityを1発生成
    end
    Update ->> Job: 移動と寿命処理を並列でスケジュール
    Pause -->> Bridge: Pause() / Resume()
    Bridge ->> Group: 更新の停止・再開
    Bridge ->> Bridge: 弾幕のPlayableDirectorを停止・再開
```
