## 各パラメーターの意味
旧 StageNodeAsset は、次のアセットに分かれました。
- BattleStageAsset: バトルステージ 1 つ分の設定
- ScenarioStageAsset: シナリオステージ 1 つ分の設定
- StageBindAsset: 2 つのステージの接続と、接続元をクリアした後の進み方
- StageTreeAsset: ゲームで使うステージと接続の一覧

「基本情報」「UI 情報」「シーン遷移」「クリア報酬」は、バトルとシナリオの両方にある項目です（共通の基底クラス StageAssetBase が持ちます）。

### 基本情報

#### Stage ID 
ステージの ID を設定します。
ドロップダウンから DataID（文字列の ID。例: stage_01、scenario_stage_01）を選んでください。
ほかのステージと重複させないでください。未設定のままだと、ゲームの起動時にエラーになります。
作戦画面のノードはステージツリーから自動で作られるため、UIToolkit 上のノード名と合わせる必要はありません。

#### StageType
ステージのタイプは、項目ではなくアセットの種類（BattleStageAsset / ScenarioStageAsset）で決まります。
タイプによって異なる処理が行われます。
- シナリオの場合
→ ステージノードが選択された時に表示される、ステージ詳細画面の出撃ボタンを押した時に 後述する TargetSceneName に直接遷移し、後述する ScenarioId のシナリオを再生します。
- バトルの場合
→ステージノードが選択された時に表示される、ステージ詳細画面の出撃ボタンを押した時に、そのままバトルを開始します。
戦闘準備画面は廃止されたため、経由しません。
バトルの舞台になるステージシーンは、後述する EnemyWaveDefinitionId の敵 Wave 定義から決まります。
- IsInitiallyUnlocked
ステージのノードを最初から解放済みにするかどうかを設定します。
現在の製品版データでは、シナリオステージ 12 件すべてとチュートリアル（stage_Tutorial）がオンになっています。

### シーン遷移

#### TargetSceneName
そのステージノードがどこのシーンに遷移したいのかを設定するためのものです。
ドロップダウンからシーン名を選びます。現在のデータでは、バトルは InGame、シナリオは Scenario を設定しています。

### クリア報酬

#### 初回クリア報酬・成功報酬（毎回）
ステージノードが選択された時に表示されるステージをクリアした時の報酬を設定します。
リソースの ID と数量を 1 行ずつ設定します。ID が未設定、または数量が 0 の行は無視されます。
- 初回クリア報酬: 初めてクリアしたときだけ付与します。
- 成功報酬（毎回）: クリアするたびに付与します。初回クリア時は初回クリア報酬と合わせて付与します。
（既存の画像を残す）

#### RewardSkillBuildPoint・RewardSkillUnlockPoint
旧形式の初回クリア報酬です。Inspector では「旧形式の初回クリア報酬（移行用）」の下に表示されます。
上の「初回クリア報酬」が空のときだけ使われ、改造ポイント（RewardSkillBuildPoint）と研究ポイント（RewardSkillUnlockPoint）として付与されます。
初回クリア報酬を無しにしたい場合は、この 2 項目を 0 にしてください。

### バトル情報
BattleStageAsset だけにある項目です。

#### IsTutorial
初回起動時に自動で出撃するチュートリアルステージの場合にオンにします。
ステージツリーの中で 1 つだけにしてください。

#### EnemyWaveDefinitionId
バトルで使う敵 Wave 定義の DataID を設定します。
バトルの舞台になるステージシーン名も、この定義から決まります。

#### MissionDefinitionId
バトルのミッションの DataID（例: AllKill）を設定します。
旧 StageNodeAsset の MissionDefinitionAsset（アセットの参照）は、この項目に置き換わりました。
未設定のままだと、ゲームの起動時にエラーになります。

### シナリオ情報
ScenarioStageAsset だけにある項目です。

#### ScenarioId
シナリオパートで再生するシナリオの ID（例: Episode_1_first(edit)）を設定します。

## ステージのつなぎ方（StageBindAsset）
ステージ同士のつながりは、StageBindAsset で 1 本ずつ設定します。
バトル同士、シナリオ同士を含め、どの種類のステージ同士でもつなげられます。

#### FromStageId・ToStageId
接続元と接続先のステージの DataID を設定します。

#### AdvanceMode
接続元をクリアした後の進み方を設定します。
- ManualSelection: 作戦画面でプレイヤーが次のステージを選びます。
- AutoAdvance: 作戦画面を挟まず、次のステージを開始します。

例: 製品版データの StageBind_S01.B00 は、第 1 話（scenario_stage_01）からチュートリアル（stage_Tutorial）へ AutoAdvance でつないでいます。

## ステージツリー（StageTreeAsset）
作ったステージと StageBindAsset は、StageTreeAsset の「ステージ一覧」「接続一覧」に登録しないとゲームに出ません。
作戦画面のノードの位置は、接続の順番から自動で左から右へ並びます。StageTreeAsset の Inspector には、ステージと接続のグラフが表示されます。
Inspector で値を変えると次の内容が検証され、問題があれば Console にエラーが出ます。
- Stage ID の未設定・重複
- チュートリアルが 2 つ以上ある
- 接続元・接続先が未設定、またはツリーに無いステージを指している
- 同じ接続の重複
- 同じ接続元から AutoAdvance が 2 本以上出ている
- 起点（どこからも接続されていないステージ）が無い、または接続が循環している
- 起点が 2 つ以上ある（警告。作戦画面の左端に複数並びます）

Planner Master Data ウィンドウからも、ステージとステージツリーを編集できます。
