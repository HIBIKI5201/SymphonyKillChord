## 概要
> 💡 **モジュール概要**
> ステージ開始演出→ゲームプレイ開始、およびミッション終了（クリア/ゲームオーバー）時の演出→リザルト表示という、InGame全体の進行を統括するオーケストレーターモジュールである。自身はドメイン状態を持たず、`IGameplayControllable`という共通契約を介してEnemy/Player/Music/Input等の毎フレーム処理を一斉に開始・停止させる。戦闘ポーズの状態も本モジュールが持つ。

| 項目 | 内容 |
|---|---|
| **モジュール名** | Sequence |
| **カテゴリ** | InGame |
| **ステータス** | 実装済み |
| **最終更新日** | 2026-09-22 |

### 🏗️ クラス

| クラス名 | レイヤー | 役割・機能 |
|---|---|---|
| `**ReturnToTitleController**` | Adaptor | インゲームからタイトルシーンへ復帰するシーン遷移を実行。バトル選択中ならBattle/InGameシーンをアンロードしてタイトルへ、未選択（チュートリアル直起動など）なら現在のシーンから遷移し、成功後に選択状態をクリアする。生成して呼ぶのはUIモジュールの`PauseWindowInitializer`（ポーズ画面の「タイトルへ戻る」） |
| `**BattlePauseController**` | Adaptor | 戦闘ポーズの状態を持つController。`Toggle`による通常ポーズと、シナリオ用ポーズを区別して扱い、ポーズ開始・解除・シナリオ開始・シナリオ終了の4イベントを公開する |
| `**IBattlePauseModule**` | Adaptor | 実際に戦闘を止める処理の契約（`TryPause`/`Resume`） |
| `**IBattlePausable**` | Adaptor | ポーズ対象側が実装する契約（`PauseBattle`/`ResumeBattle`）。現在は実装・参照ともに無い |
| `**IScenarioBattlePauseController**` | Adaptor | シナリオ再生中のポーズ制御の契約。通常ポーズ中に始まったシナリオでは、終了時に通常ポーズを解除しない |
| `**IGameplayControllable**` | View | `StartGameplay()`/`StopGameplay()`の2メソッドのみを持つ契約。Enemy/Player/Music/Input/Mission等、多数のクラスがこれを実装する |
| `**StageSequenceView**` | View | 開始/クリア/ゲームオーバーの3つの`PlayableDirector`（Timeline）を保持し、再生完了を待機する。クリア演出用の`StageClearCameraView`と黒帯（`LetterBoxAnimationGUI`）も参照する |
| `**StageSequenceMessageView**` | View | 「Mission Start!」「Stage Clear!」「Game Over!」等の一時的なメッセージ表示を担当。文言は英語固定のSerializeFieldで、Localizationを参照しない |
| `**StageSequenceVoiceView**` | View | 開始・クリア・ゲームオーバーのボイス再生。Playerは動的生成されるため`PlayerModuleContainer`から`PlayerView`を受け取る。クリアボイスは達成度で3段階に分ける |
| `**StageSequenceMusicView**` | View | ステージクリア時のBGMを`IBgmCuePlayer`経由で再生する（Cueは1つ。ゲームオーバーBGMは持たない） |
| `**StageSequenceSoundEffectView**` | View | クリアTimeline・ゲームオーバーTimelineのSignalから`SE_Gameclear`/`SE_Gameover`を再生する |
| `**AmbienceSoundView**` | View | 開始演出中の環境音`SE_Ambience_Ingame`を再生し、ゲームプレイ開始時と開始演出の中断時に止める。未配置でもシーケンスは起動する（警告のみ） |
| `**StageClearCameraView**` | View | クリアTimelineのSignalで、戦闘カメラより優先度の高いクリア専用CinemachineCameraへ切り替え、プレイヤー正面へ移動する |
| `**InGameHudVisibilityView**` | View | 開始演出中にインゲームHUDのCanvas群をまとめて非表示にし、演出後に戻す |
| `**StageStartFadeView**` | View | ステージ開始時の黒画面とフェードアウト表示 |
| `**StageStartConstraintView**` | View | 開始演出のDollyCameraが向く方向を提供 |
| `**StageStartSequenceConfig**` | View | 開始演出の設定（黒画面の保持時間・フェード時間）を保持するScriptableObject |
| `**InGamePlayDirector**` | Composition | 登録された`IGameplayControllable`群へ`StartGameplay`/`StopGameplay`を一斉に伝播するファンアウト役。登録はInspectorの配列と、`AddGamePlayControllable`による実行時追加の2通り。自身も`IGameplayControllable`を実装する |
| `**InGameSequenceDirector**` | Composition | 演出＋ゲームプレイ制御＋リザルト表示までを統括する実際のオーケストレーター（プレーンC#クラス） |
| `**InputGamePlayControllable**` | Composition | `IGameplayControllable`実装。入力マップを`InGame`/`Common`間で切り替える |
| `**SequenceInitializationModule**` | Composition | 上記全ての構築・結線、ミッション終了イベントとポーズ入力の購読、ロード完了待ちを行う |
| `**BattlePauseModule**` | Composition | `IBattlePauseModule`実装。入力マップを`Common`のみへ切り替え、`MusicPlayer`のBGMを一時停止し、`Time.timeScale`を0にして戦闘を止める。再開時は元へ戻す |
| `**SequenceModuleContainer**` | Composition | `InGameSequenceDirector`と`BattlePauseController`をServiceLocatorへ公開するContainer |

#### 📥 依存しているもの

- `**Mission**`
  - *依存箇所*: `MissionModuleContainer.MissionRuntimeService`, `MissionRuntimeService.OnMissionFinished`
  - *詳細*: ミッション終了イベントを購読し、`BuildEvaluationResult()`で評価結果を取得する
- `**Result**`
  - *依存箇所*: `StageResultModuleContainer.Presenter`, `StageResultModuleContainer.Controller`, 自ら`FindFirstObjectByType`する`StageResultView`
  - *詳細*: クリア/ゲームオーバー演出の最後に`PresentVictory`/`PresentDefeat`を呼び、`StageResultView.Show()`でリザルト画面へ切り替える。ステージのロードに失敗したときは、黒画面のまま`Controller.CompleteAsync()`でOutGameへ戻す
- `**Player**`
  - *依存箇所*: `PlayerModuleContainer.PlayerView`
  - *詳細*: ボイス再生（`StageSequenceVoiceView`）、クリアカメラの追従対象（`StageClearCameraView`）、開始演出のカメラが向く先（`StageStartConstraintView`）に使う
- `**Persistent/Savedata**`
  - *依存箇所*: `StageProgressSaveDataService`
  - *詳細*: クリア確定時に`SaveClearAsync(StageId, FirstClearReward, ClearReward, evaluationResult, IsTutorial)`で評価結果を保存する（保存はリザルト表示より前に行われる）。保存で例外が起きてもログを出してクリア演出を続ける
- `**StageSelect**`
  - *依存箇所*: `SelectedBattleStageState`, `PendingNodeTransitionState`
  - *詳細*: `CurrentStageDefinition`の`StageId`/`FirstClearReward`/`ClearReward`/`IsTutorial`を保存呼び出しに使用する。保存に成功したら`PendingNodeTransitionState.MarkCompleted(stageId)`を呼ぶ
- `**Persistent/Load**`
  - *依存箇所*: `LoadingScreenController`
  - *詳細*: ロード画面の完了（`LoadingCompleted`）を待ってから開始演出を始める。ロード中でなければすぐに始める
- `**Persistent/SceneManagement**`
  - *依存箇所*: `SceneTransitionController`
  - *詳細*: ロード失敗時に、シナリオバトルの専用出撃であれば`StopScenarioBattleInitialization()`でPersistent側に処理を任せる
- `**Input**`

## 詳細

### 🧅レイヤー情報

#### ① Domain

当モジュールでは使用していない。

#### ② Application

当モジュールでは使用していない。

#### ③ Adaptor

`BattlePauseController`が戦闘ポーズの状態（通常ポーズとシナリオ用ポーズ）を持つ。`ReturnToTitleController`はインゲームからタイトルシーンへの復帰を実行し、ポーズ画面（UIモジュール）から使われる。

#### ④ View

`IGameplayControllable`という共通契約、演出再生（`StageSequenceView`）とメッセージ表示（`StageSequenceMessageView`）を担当する。開始演出はフェード（`StageStartFadeView`）・ボイス（`StageSequenceVoiceView`）・カメラ方向（`StageStartConstraintView`）・環境音（`AmbienceSoundView`）へ分かれ、設定は`StageStartSequenceConfig`が持つ。クリア演出は`StageClearCameraView`（正面カメラ）と黒帯を使う。

HUDの表示・非表示は次のとおりである。

| 状態 | インゲームHUD | 制御しているクラス |
|---|---|---|
| 開始演出中 | 非表示（Canvasを`enabled=false`） | `InGameHudVisibilityView`（`InGameSequenceDirector.Start`で隠し、ゲームプレイ開始時に戻す） |
| 戦闘中 | 表示 | — |
| ポーズ中 | 表示したまま、ポーズウィンドウを重ねる | UIモジュールの`PauseWindowView` |
| リザルト表示 | 非表示（Canvas群のGameObjectを無効化） | Resultモジュールの`StageResultView.Show` |

クリア/ゲームオーバー演出中のHUDの見え方は【要確認: 実機で確認する】。

クリア/ゲームオーバー時の音は次のとおりである。

| 音 | 鳴らすクラス | 現在の設定 |
|---|---|---|
| クリアボイス（Perfect／Good／Bad） | `StageSequenceVoiceView` → `PlayerView.PlayStageClearVoice`。全達成または評価0件=Perfect、一部達成=Good、未達成=Bad | `Player.prefab`のCueNameが空のため鳴らない |
| ゲームオーバーボイス | `StageSequenceVoiceView` | CueNameが空のため鳴らない |
| クリアBGM | `StageSequenceMusicView` | `InGame.unity`の`_stageClearCueName`が空のため鳴らない（警告ログのみ） |
| クリアSE／ゲームオーバーSE | `StageSequenceSoundEffectView`（Timeline Signal） | `SE_Gameclear`／`SE_Gameover` |

【要確認: ボイスとクリアBGMを未設定のまま出すかを企画・サウンド担当に】

演出メッセージ（Mission Start! 等）は英語固定である。【要確認: 英語固定のままにするか、ローカライズ対象にするかを企画に】

#### ⑤ Infrastructure

当モジュールでは使用していない。

#### ⑥ Composition

`SequenceInitializationModule`（Order 1000）が全体を構築し、`InGameSequenceDirector`（実際のオーケストレーター）・`InGamePlayDirector`（ゲームプレイ一斉制御）・`InputGamePlayControllable`（入力マップ切替）・`BattlePauseModule`（戦闘ポーズ）を結線する。Readyの最後にゲームプレイを止め、ロード画面の完了を待ってから開始演出を始める。ポーズ入力は、開始演出の再生中と、戦闘終了からリザルト表示中は受け付けない。

### 🔌 拡張ポイント

> 新しい「毎フレーム処理をステージ進行に合わせて開始/停止したいシステム」を追加する場合は、対象クラスに`IGameplayControllable`を実装させ、シーン内の`InGamePlayDirector`のInspectorへ手動でドラッグ登録するか、自モジュールのInitializerから`InGamePlayDirector.AddGamePlayControllable`で登録する（動的に生成するオブジェクトは後者）。**自動検出ではない**。登録を忘れても起動時エラーにはならず、単にそのシステムがステージ開始演出中も動き続けてしまう（サイレントな不具合）ため注意が必要である。
