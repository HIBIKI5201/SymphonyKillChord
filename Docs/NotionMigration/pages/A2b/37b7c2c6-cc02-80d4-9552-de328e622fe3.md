## 用語解説

#### オフセット

画面中央からどれだけずらしているかを表す。
０から値が増えることで画面中央からズレていく。
０に近くづくことでより画面中央に近づく。

## 一覧

| パラメーター名 | 調整目的 | 値を上げるとどうなるか | 値を下げるとどうなるか |
|---|---|---|---|
| `_cameraOffset` | 追従先（プレイヤーの足元）から、カメラの回転の中心をどれだけずらすかを決める | 回転の中心が高く（該当軸の正方向へ）なる | 回転の中心が低く（該当軸の負方向へ）なる |
| `_characterCenterOffset` | キャラクターモデルの中心位置を補正する | 補正量が増える | 補正量が減る |
| `_distance` | 追従先からカメラまでの通常時の距離を決める。壁がある場合はこれより短くなる | カメラが遠ざかり、周囲が広く映る | カメラが近づき、プレイヤーが大きく映る |
| `_followOffsetPower` | プレイヤーの移動中に進行方向とは逆に画面中央からどれだけずらすかの位置を決める | ズレる量の最大値が増える。 | 画面中央に近づいていきます。 |
| `_followLerpSpeed` | オフセットへの追従速度を決める。 | 素早くオフセット位置に移動する。 | 滑らか（ゆっくり）にオフセット位置に移動する。 ０の場合はカメラが追従オフセットを持たない状態で固定。 |
| `_boneRotateSpeed` | ロックオン中にカメラが敵の方向に向く最大速度を決める。角度差が `_lockOnRotationSpeedAngleRange` 以上のときにこの速度になり、角度差が小さいほど `_lockOnRotationMinSpeed` に近づく | 敵の方向に素早く向きやすくなる。 | 敵の方向にゆったりと向きやすくなる。 |
| `_lockOnRotationMinSpeed` | ロックオン中のカメラ回転速度の下限を決める | 角度差が小さいときも速く追従する | 角度差が小さいときにゆっくり寄っていく |
| `_lockOnRotationSpeedAngleRange` | 回転速度が最大（`_boneRotateSpeed`）に達する角度差を決める | 大きくずれるまで最大速度にならず、全体に穏やかになる | 小さなずれでも最大速度で向き直る |
| `_lockOnAngleMargin`  | プレイヤーモデルを画面に収めるために敵方向から何度ずらすかを決める。 | プレイヤーが映るよう、敵からずらしていく。 敵画面中央からズレやすい | 敵をより画面中央寄りに捉えやすくなる。プレイヤーが画面端に追いやられやすくなる。 |
| `_followRotationSpeed` | 非ロックオン時の視点操作の速度を決める。 | 視点操作が早くなります。 | 視点操作が遅くなります。 |
| `_moveFollowRotationSpeed` | 非ロックオン時、移動入力の横成分に比例してカメラを左右へ回す最大速度を決める | 横移動でカメラが大きく回り込む | 横移動してもカメラが回りにくくなる |
| `_moveFollowIdleLookThreshold` | 視点入力がこの大きさ以上のときは、移動入力によるカメラの回り込みを止める | 多少の視点入力があっても回り込みが続く | わずかな視点入力でも回り込みが止まる |
| `_lockOnLookAtRatio` | ロックオン中に、プレイヤーと敵のどちら寄りで注視するかを決める。1 で完全に敵を注視する | 敵寄りの構図になります。 | プレイヤー寄りの構図になります。 |
| `_lockOnRotationSpeed` | ロックオン中に、カメラ自体が注視点へ向く回転の速さを決める | 注視点へ素早く向く | 注視点へゆっくり向く |
| `_lockOnViewportMargin` | オートロックオンを維持できる画面の内側の余白を決める。対象がこの余白より外へ出るとオートロックオンが外れる | 対象が画面の端に寄っただけで外れやすくなる | 画面の端ぎりぎりまで外れにくくなる |
| `_lockOnBreakWindow` | 強い視点操作でオートロックオンを外す判定で、視点入力量を蓄積する時間幅を決める | 短い操作の積み重ねでも外れやすくなる | 一気に大きく操作したときだけ外れる |
| `_lockOnBreakThreshold` | 強い視点操作でオートロックオンを外すしきい値を決める | 大きく視点を動かさないと外れなくなる | 小さな視点操作でも外れやすくなる |
| `_autoLockOnReleaseDelay` | 最後に攻撃が命中してから（またはオートロックオンの開始から）、オートロックオンを外すまでの秒数を決める | ロックオンが長く続く | 攻撃を止めるとすぐ外れる |
| `_autoLockOnViewportGraceDuration` | 画面外の敵へオートロックオンした直後に、画面外判定による解除を待つ秒数を決める | 画面外の敵へ向き直るまでの猶予が長くなる | 向き直る前に外れやすくなる |
| `_collisionRadius` | 壁避けの判定に使う球の半径を決める | 壁の手前で早めにカメラが寄る | 壁ぎりぎりまでカメラが下がる |
| `_collisionMask` | 壁避けの判定の対象にするレイヤーを決める | — | — |
| `_pitchRange` | カメラを上下に動かせる範囲を決める。 | 範囲を広げると、見上げ・見下ろしできる範囲が広がる | 範囲を狭めると、極端な上下視点を防ぎやすくなる |
| `_invertVertical` | 視点操作の上下を反転するか決める | — | — |
| `_invertHorizontal` | 視点操作の左右を反転するか決める | — | — |
