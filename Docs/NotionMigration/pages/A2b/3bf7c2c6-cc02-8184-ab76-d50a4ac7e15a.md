## 適用する本文

`ObjectiveSequenceClearCondition`は目標を順番に達成させる。各ステップの条件はデコレータで包まれており、ステップ開始時の副作用はDomainではなくControllerが起こす。ステップを進めるのは`MissionRuntimeService`で、時間経過・撃破・行動・全Wave撃破・プレイヤー死亡のどの通知でも、まず現在のステップが達成されたかを確かめて次へ進め、変わったら`OnObjectiveStepChanged(stepIndex)`を発火する。このイベントは説明ポップアップ・敵Wave生成・バフ付与の各Controllerに加え、進入時アクション（⑤）・会話・シナリオ再生（⑥）のControllerも購読する。説明ポップアップは内側の条件（多くは攻撃1回）を満たすと閉じ、表示直後の1.5秒はプレイヤーの入力を受け付けない。

```mermaid
sequenceDiagram
    autonumber
    participant Runtime as MissionRuntimeService

    participant Wave as MissionWaveController

    Note over Runtime: 通知を受けるたび（Tick・撃破・行動 等）
    Runtime ->> Seq: TryAdvance（現在ステップの達成判定）
    Seq ->> Seq: 達成したら次ステップへ更新し、新ステップの Begin（基準値を記録）
    Runtime -->> Popup: OnObjectiveStepChanged(stepIndex)
    Runtime -->> Wave: OnObjectiveStepChanged(stepIndex)
    Runtime -->> Buff: OnObjectiveStepChanged(stepIndex)
    Popup ->> Popup: ClearConditionChain.Find で PopupClearCondition を検出し、説明ポップアップを表示（表示直後は入力を抑止）
    Wave ->> Wave: WaveStartClearCondition を検出し、次の敵Waveを生成
    Buff ->> Buff: PlayerBuffClearCondition を検出し、このステップの間だけバフを付与
    Runtime ->> Runner: Evaluate（失敗判定→全ステップを終えていればクリア）
```
