## 適用する本文

ミッションクリア確定から、評価結果の保存・クリア演出・リザルト表示までの流れである。

```Mermaid
sequenceDiagram
    autonumber
    participant Mission as MissionRuntimeService
    participant Init as SequenceInitializationModule
    participant SaveSvc as StageProgressSaveDataService
    participant Pending as PendingNodeTransitionState
    participant SeqDirector as InGameSequenceDirector
    participant SeqView as StageSequenceView
    participant Voice as StageSequenceVoiceView
    participant ResultPresenter as StageResultPresenter (Resultモジュール)
    participant ResultView as StageResultView (Resultモジュール)

    Mission -->> Init: OnMissionFinished(Clear)
    Init ->> Mission: BuildEvaluationResult()
    Mission -->> Init: MissionEvaluationResult
    Init ->> SaveSvc: SaveClearAsync(StageId, FirstClearReward, ClearReward, result, IsTutorial)
    alt 保存成功
        Init ->> Pending: MarkCompleted(StageId)
    else 例外
        Init ->> Init: ログのみ出してクリア演出を続行
    end
    Init ->> SeqDirector: ClearAsync(evaluationResult, token)
    SeqDirector ->> SeqDirector: 開始演出が残っていれば中断 / IsResultActive = true（以降ポーズ不可）
    SeqDirector ->> SeqDirector: StopGameplay → クリアメッセージ表示
    SeqDirector ->> SeqView: PlayStageClearAsync（StageClear Timelineの再生を待機）
    Note over SeqView: Timeline Signalで黒帯表示・StageClearCameraViewで正面へ移動・SE_Gameclear
    SeqDirector ->> Voice: PlayStageClearVoice(達成数, 総数)
    SeqDirector ->> ResultPresenter: PresentVictory(evaluationResult)
    SeqDirector ->> ResultView: Show()
    Note over ResultView: StageResultReveal Timelineで文字を上から表示 → 数値をカウントアップ
    Note over SeqDirector: ゲームプレイは再開されず、以降の操作はResultモジュールへ移る
    Note over Init: OnMissionFinished(Fail)の場合は保存せず、GameOverAsync → GameOver Timeline → PresentDefeat → Show()
```

クリア演出の値は次のとおりである。全面の暗転は使わず、開始演出と同じ黒帯を出してプレイヤー正面へカメラを移動する。

| 名前 | 値 | 単位 | 正本 |
|---|---|---|---|
| クリアTimelineの長さ | 1.8（固定長） | 秒 | `Assets/Arts/Animation/Timelines/StageClear.playable` |
| Signalの時刻 | 0.01 / 0.02 / 0.4 | 秒 | 同上【要確認: 各Signalと処理の対応を実機で】 |
| 黒帯の開閉時間 | 0.3 | 秒 | Timeline の Signal を受ける SignalReceiver 側の設定（PR #1807） |
| カメラ移動の時間 | 1 | 秒 | 同上 |
| クリア専用カメラの優先度 | 100 | — | クリア専用 CinemachineCamera（PR #1807） |
| 正面カメラの距離 | 2.5 | m | `InGame.unity`の`StageClearCameraView` |
| 正面カメラの高さ | 1.23 | m | 同上 |
| 注視点の高さ | 0.93 | m | 同上 |
| 画面内の水平位置 | 0.25 | — | `StageClearCameraView`のコード既定値 |
| 文字表示Timelineの長さ | 3（固定長） | 秒 | `Assets/Arts/Animation/Timelines/StageResultReveal.playable` |

- クリアボイスは達成度で分ける。全達成または評価0件は Perfect、一部達成は Good、未達成は Bad である
- 演出を調整する場所は、`StageClear.playable`、`StageResultReveal.playable`、`StageSequenceRoot`の SignalReceiver、`StageClearCameraView`である
