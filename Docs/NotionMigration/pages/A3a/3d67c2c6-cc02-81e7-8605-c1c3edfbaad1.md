## 適用する本文

`StageSelectInitializer`（Order 110）は`Ready()`で自動遷移フローを起動する。予約済みの通常ノード遷移（`PendingNodeTransitionState`、チュートリアル専用ではない汎用機構）を優先消化した後、`TutorialPhase`に応じたチュートリアル区間の自動開始を判定する。現状のswitch文で処理されるのは`OpeningScenarioCompleted`のみであり、それ以外のフェーズでは`TryStartTutorialSegment`は何もせず`false`を返す。出撃が塞がっている間（出撃要求中・シナリオからの戦闘出撃中・ロード中）は何もしない。
なお、第1話からチュートリアル戦闘への接続は遷移モードが `AutoAdvance` である。タイトルから始めたときは作戦画面の出撃ボタンを経由しない（遷移の予約が作られない）ため、第1話の後に OutGame を読み込んだ時点で、この分岐が同じ遷移を行う。
```Mermaid
sequenceDiagram
    autonumber
    participant Loading as LoadingScreenController
    participant Init as StageSelectInitializer (Order 110)
    participant Pending as PendingNodeTransitionState
    participant Save as SaveData.Tutorial (TutorialData)
    participant Tree as StageTree
    participant Sortie as BattleSortieSelectionService / OutGameSortieController

    Note over Init: Ready() 呼び出し時
    Init ->> Loading: IsLoading を確認（ロード中ならLoadingCompleted購読後に再入）
    Init ->> Init: ExecuteAutomaticTutorialFlow()（1フレーム待ち、ロード中なら購読し直す）
    Init ->> Pending: TryExecutePendingNodeTransitionAfterReturnAsync()
    alt 予約済み通常遷移がある
        Pending -->> Init: 消化して終了
    else 予約済み遷移がない
        Init ->> Init: TryStartTutorialSegment()
        alt 出撃が塞がっている（IsSortieBlocked）
            Note over Init: 何もしない（trueを返す）
        else 予約済み遷移が残っている
            Note over Init: 何もしない（falseを返す）
        else
            Init ->> Save: Tutorial.Phase を switch
            alt Phase == OpeningScenarioCompleted
                Init ->> Tree: TryGetTutorialNode() でチュートリアル戦闘ノードを取得
                Init ->> Sortie: TryPrepareBattleSortie(戦闘定義)
                Init ->> Init: SelectedScenarioState.Clear()
                Init ->> Sortie: RequestImmediateBattleSortie()
                Note over Init: 戦闘クリア後、SequenceInitializationModule が<br/>SaveClearAsync を通じて CompleteBattle() を呼ぶ
            else その他のPhase
                Note over Init: 何もしない（falseを返す）
            end
        end
    end
```
> `TutorialData.CompleteOpeningScenario()`は、冒頭のチュートリアルシナリオの再生完了（スキップを含む）時に`ScenarioCom`が`StageProgressSaveDataService.SaveClearAsync`を通じて呼ぶ。`TutorialData.CompleteBattle()`は、チュートリアル戦闘（`IsTutorial`が有効なバトルステージ）のクリア時に`SequenceInitializationModule`が`StageProgressSaveDataService.SaveClearAsync`を通じて呼ぶ。
