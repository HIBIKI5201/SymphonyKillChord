## 適用する本文

セーブデータに解放スキルまたは装備構成が無い場合、初期ロードアウトで補完する。解放スキルが空なら初期解放スキルを、装備が空なら初期装備スキルを設定し、どちらも設定済みなら何もしない。
補完は、起動時に常駐シーンの`InitialSkillLoadoutInitializer`が行い、セーブデータのリセット後と体験版終了後の再入場ではタイトルの`TitleSceneInitializer`が同じサービスを呼んで再補完する。
```Mermaid
sequenceDiagram
    autonumber
    participant Init as InitialSkillLoadoutInitializer (Savedataモジュール, Order 20)
    participant Title as TitleSceneInitializer (Title)
    participant Service as InitialSkillLoadoutService
    participant Asset as InitialSkillLoadoutAsset
    participant Store as SaveStore

    Note over Init: ResourceLoadAsync
    Init ->> Asset: 初期解放・初期装備スキルを取得
    Init ->> Service: サービスを生成
    Init ->> Service: TryApply(SaveData)
    Service ->> Service: 空の項目にだけ初期値を設定
    Service -->> Init: 更新したかどうか
    opt 更新した場合
        Init ->> Store: SaveAsync<SaveData>()（失敗したら補完前へ戻す）
    end
    Note over Init: Build でサービスを ServiceLocator へ登録する（再補完で使う）
    Note over Title: タイトルの読み込み・セーブデータリセット後・体験版終了後の再入場
    Title ->> Service: ServiceLocatorから取得して TryApply(SaveData)
    opt 更新した場合
        Title ->> Store: SaveAsync<SaveData>()（失敗したら補完前へ戻す）
    end
```
