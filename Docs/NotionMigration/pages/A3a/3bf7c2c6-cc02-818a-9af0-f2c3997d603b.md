## 概要
> 💡 **モジュール概要**
> アウトゲームから各ステージへ出撃する流れを制御するモジュールである。ステージ種別に応じて、バトルを直接開始するか、シナリオ再生へ切り替えるかを振り分ける。シナリオの終了後に、作戦画面へ戻らずそのままバトルへ出撃する経路も持つ。戦闘準備画面は廃止済みである（2026-09-18 PR #1839）。
| 項目 | 内容 |
|---|---|
| **モジュール名** | Sortie |
| **カテゴリ** | OutGame |
| **ステータス** | 実装済み |
| **最終更新日** | 2026-09-22 |
---

### 🏗️ クラス
| クラス名 | レイヤー | 役割・機能 |
|---|---|---|
| `**OutGameSortieUseCase**` | Application | 出撃の流れを制御する。バトルはバトル開始を要求し、シナリオはシナリオシーンを追加ロードする |
| `**IOutGameSortieOutputPort**` | Application | 出撃処理の出力ポート。バトル開始、シナリオ後のバトル出撃、ホーム画面の表示、シナリオ用のOutGame表示切り替えを要求する |
| `**ScenarioBattleSortieResult**` | Application | シナリオ後のバトル出撃の結果（`Started` / `PreparationFailed` / `Busy` / `Failed`）を表すenum |
| `**OutGameSortieController**` | Adaptor | 出撃要求をユースケースへ伝える薄いパススルー |
| `**OutGameSortieOutputPort**` | Composition | `IOutGameSortieOutputPort`実装。`OutGameUIEvent`と入力の両方に依存するためComposition層へ置く。シナリオ後のバトル出撃では、自動遷移の予約を消費し、シナリオとOutGameを閉じてからInGameをロードする |
| `**OutGameSortieInitializer**` | Composition | 出撃機能の初期化（Order 20） |
  `OutGameSortieUseCase`が公開する操作は4つである。
| 操作 | 用途 |
|---|---|
| `**RequestSortieAsync**` | ステージ選択からの通常の出撃。バトルなら戦闘準備画面を挟まずにバトルを開始し、シナリオならシナリオシーンを追加ロードする |
| `**RequestImmediateBattleSortie**` | ステージ種別を確認せずにバトルを開始する。チュートリアル戦闘への自動出撃と、戦闘後の自動遷移で使う |
| `**ReturnFromScenarioAsync**` | シナリオ再生から戻り、ホーム画面とOutGameの表示を復帰させる |
| `**RequestBattleSortieFromScenarioAsync**` | シナリオ終了後に、自動遷移の予約に従ってそのままバトルへ出撃する |

#### 🧩 Composition初期化情報
| 項目 | 内容 |
|---|---|
| **Initializerクラス** | `OutGameSortieInitializer` |
| **Order** | 20（OutGameシーン内。`ScreenInitializer`(100)より前） |
| **公開する ModuleContainer / ServiceLocator登録型** | 専用の`ModuleContainer`は無く、`OutGameSortieController`をServiceLocatorへ登録する |
出力ポートの実装をComposition層へ置いているのは、`OutGameUIEvent`と入力側の両方に依存するためである。Application層は`IOutGameSortieOutputPort`だけを知る。
Readyでは、StageSelectが公開した`PendingNodeTransitionState`と、`SelectedScenarioState`・`BattleSortieSelectionService`を出力ポートへ接続する（シナリオ後のバトル出撃で使う）。

#### 📥 依存しているもの
- `**StageSelect**`
  - *依存箇所*: `SelectedBattleStageState`, `StageDefinition`, `PendingNodeTransitionState`, `BattleSortieSelectionService`
  - *詳細*: 選択されたステージの種別と遷移先シーン名を参照して、出撃の分岐を決める。シナリオ後のバトル出撃では、自動遷移の予約を確認して消費し、バトルの選択状態を組み立てる
- `**Scenario**`
  - *依存箇所*: `SelectedScenarioState`
  - *詳細*: シナリオステージの場合、再生するシナリオIDを設定する。シナリオ後のバトル出撃が始まったら選択を整理する
- `**Persistent/SceneManagement**`
  - *依存箇所*: `SceneTransitionUsecase`, `SceneTransitionController`, `SceneTransitionInitializer`, `ILoadingOperationExecutor`
  - *詳細*: シナリオ再生や出撃に伴うシーン遷移に使用する。シナリオ後のバトル出撃は、常駐の寿命トークン付きの専用APIでシナリオとOutGameを閉じてからInGameをロードし、失敗時は常駐側の復帰画面へつなぐ

#### 📤 依存されているもの
- `**StageSelect**`
  - *参照箇所*: `OutGameSortieController`（`RequestSortieAsync`, `RequestImmediateBattleSortie`）
  - *詳細*: ステージ詳細画面の出撃ボタン、チュートリアル戦闘への自動出撃、戦闘後の自動遷移から呼ばれる
- `**Scenario**`
  - *参照箇所*: `OutGameSortieController`（`ReturnFromScenarioAsync`, `RequestBattleSortieFromScenarioAsync`）
  - *詳細*: `ScenarioCom`がシナリオ終了時に呼ぶ。自動遷移の予約先がバトルなら`NodeTransitionExecutor`経由でシナリオ後のバトル出撃を、それ以外はOutGameへの復帰を要求する
- `**Screen**`
  - *参照箇所*: `OutGameUIEvent.OnStartGame`
  - *詳細*: `ScreenInitializer`が受け取り、選択中バトルステージのInGameシーンへ遷移する

## 詳細

### 🧅レイヤー情報

#### ① Domain
当モジュールでは使用していない。ステージの定義はStageSelectモジュールのDomainを参照する。

#### ② Application
`OutGameSortieUseCase`が出撃の分岐を持つ。UI操作と入力への依存は`IOutGameSortieOutputPort`の先へ追い出している。

#### ③ Adaptor
`OutGameSortieController`が出撃要求をユースケースへ渡す。

#### ④ View
当モジュールでは使用していない。画面はStageSelectとScreenの各モジュールが持つ。

#### ⑤ Infrastructure
当モジュールでは使用していない。

#### ⑥ Composition
`OutGameSortieInitializer`（Order 20）が構築し、`OutGameSortieOutputPort`が出力ポートの実装を担う。

### 🔌 拡張ポイント
| 拡張したいこと | 実装する場所 | 追加登録の要否 |
|---|---|---|
| 新しいステージ種別の出撃を追加したい | `StageType`（StageSelectモジュールのDomain）へ値を追加し、`OutGameSortieUseCase`の分岐と`IOutGameSortieOutputPort`へ対応する出力を足す | 必要（分岐への追記漏れは、出撃ボタンを押しても何も起きない状態になる） |
