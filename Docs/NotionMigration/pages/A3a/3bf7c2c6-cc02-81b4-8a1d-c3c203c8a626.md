## 適用する本文

シナリオ再生が終わったら、OutGameの表示を戻す。シナリオのクリアを保存した後、自動遷移の予約先がバトルならOutGameへは戻らずそのままバトルへ出撃し、予約先がシナリオなら続けて再生する。予約が無ければホーム画面へ戻る。タイトルから直接開いたシナリオ（OutGameが未ロード）の場合は、OutGameを新しくロードする。
```Mermaid
sequenceDiagram
    autonumber
    participant Scenario as ScenarioCom（シナリオ再生完了）
    participant Exec as NodeTransitionExecutor
    participant UseCase as OutGameSortieUseCase
    participant Scene as SceneTransitionUsecase
    participant Port as OutGameSortieOutputPort

    alt 自動遷移の予約先がバトル
        Scenario ->> Exec: TryExecuteAsync(予約, シナリオシーン名, 選択の版)
        Exec ->> UseCase: RequestBattleSortieFromScenarioAsync
        UseCase ->> Port: StartBattleFromScenarioAsync
        Note over Port: 予約を消費し、シナリオとOutGameを閉じてからInGameをロードする
    else 予約なし
        Scenario ->> UseCase: ReturnFromScenarioAsync
        UseCase ->> Scene: シナリオシーンをアンロードし、OutGameをアクティブにする
        UseCase ->> Port: ShowHomeScreen()
        UseCase ->> Port: SetOutGameActiveForScenario(true)
        Note over Port: OutGameの画面と入力を再び有効にする
    end
```
