## 適用する本文

ホーム設定画面の音量ゲージの操作は、常駐シーンの共通音量設定を経由して各音量マネージャへすぐ反映され、セーブデータへ直列に保存される。タイトル画面の音量設定（`VolumeSettingsTabView`）も同じ経路を通る。
```Mermaid
sequenceDiagram
    autonumber
    actor Player as プレイヤー
    participant View as AudioSettingsView（タイトルは VolumeSettingsTabView）
    participant Command as IAudioSettingsCommand
    participant Ctrl as AudioSettingsController
    participant Volume as IVolumeManager（MusicPlayer / SoundEffectVolumeManager / VoiceVolumeManager）
    participant Service as AudioSettingsService
    participant Repo as AudioSettingsRepository
    participant Presenter as AudioSettingsPresenter
    participant VM as AudioSettingsViewModel

    Player ->> View: 音量ゲージを操作
    View ->> Command: 音量の変更を要求
    Command ->> Ctrl: 値を反映
    Ctrl ->> Volume: 対象の音量へ即時反映
    Ctrl ->> Service: 保存を要求（直列化）
    Service ->> Repo: SaveStoreへ書き込み
    Ctrl ->> Presenter: 変更後の設定を通知
    Presenter ->> VM: AudioSettingsViewDTO を反映
    VM -->> View: 表示を更新
```
