## 概要
> 💡 **モジュール概要**
> CSVで定義された線形の会話・カットシーン（テキスト・背景・立ち絵・アニメーション・フェード・レイヤー順）を再生するモジュールである。プレイヤーの選択による分岐はなく、テキスト表示中に文字位置・キーワードで副次イベントを差し込む「タイミングトリガー」のみを持つ。

|---|---|
| **モジュール名** | Scenario |
| **カテゴリ** | OutGame |
| **ステータス** | 実装済み |
| **最終更新日** | 2026-09-22 |

#### 📥 依存しているもの
- `**StageSelect**`
  - *依存箇所*: `SelectedScenarioState`、`PendingNodeTransitionState`、`NodeTransitionExecutor`
  - *詳細*: シナリオ種別ステージの出撃時に選択されたシナリオIDを、シナリオシーン側の`ScenarioCom.Ready()`が読み取る。再生完了後、ステージ間の自動遷移（AutoAdvance）の予約があれば、次のシナリオを続けて再生するか、バトルへ直接出撃する
- `**Persistent/Input**`
  - *依存箇所*: `PlayerInputView`
  - *詳細*: `ScenarioInputView`が進行・早送り・一時停止・スキップ・オート・UI非表示の各入力を購読する
- `**Sortie**`
  - *依存箇所*: `OutGameSortieController.ReturnFromScenarioAsync`
  - *詳細*: 再生完了後（自動遷移が無いとき）、シナリオシーンを閉じてOutGameへ戻り、Home画面を表示する
- `**Persistent/SceneManagement**`
  - *依存箇所*: `SceneTransitionController`
  - *詳細*: タイトルから冒頭シナリオを開いた場合はOutGameがロードされていないため、OutGameを追加ロードしてからシナリオシーンを閉じる

  - *依存箇所*: `StageProgressSaveDataService.SaveClearAsync`
  - *詳細*: 再生完了（スキップを含む）でシナリオステージのクリアを保存する。冒頭のチュートリアルシナリオのときはチュートリアルの進行段階も進める

## 詳細

### 🧅レイヤー情報

#### ① Domain
`IScenarioEvent`とその6種の具象（テキスト・立ち絵・背景・アニメーション・フェード・レイヤー順）、およびテキスト表示中に副次イベントを差し込む`TextTimingTrigger`を保持する。

#### ② Application
`ScenarioUsecase`を中心に、シナリオの取得・順次再生・イベントディスパッチ（`ScenarioHandlerRepo`）を実装する。

#### ③ Adaptor
イベント種別ごとの`*EventHandler`/`*Presenter`、それらを束ねる`ScenarioPresenterFacade`、プレイヤー入力待機の`ScenarioAdvanceGate`を定義する。

#### ④ View
`ScenarioView`（MonoBehaviour）がTextMeshPro・背景Image・Animationコンポーネント・立ち絵スロット・CanvasGroupフェードといった実際のUnity描画を担当し、`ScenarioInputView`が入力購読を担当する。
入力は Input Action の `Scenario` マップ（`Assets/Settings/Input/KillChordInputActioMap.inputactions`）で次のとおり割り当てている。

| 操作 | キーボード・マウス | ゲームパッド |
|---|---|---|
| Advance（送り） | 左クリック / Enter | 東（B） |
| FastForward（早送り） | 左 Shift | 南（A） |
| Pause | Space | Start |
| Skip | Esc | 北（Y） |
| Auto | Ctrl | 西（X） |
| HideUI | W | 右肩（RB） |

ツールバーには、アイコン・操作名（Skip / Auto / Log / Hide UI）・キーガイドの画像を並べる。Auto が有効な間は Auto ボタンを水色で強調する（`ScenarioAutoButtonView`）。スキップは確認ダイアログ（`Assets/Resources/Scenario/ScenarioSkipConfirmation.prefab`）を挟んでから実行する。

#### ⑤ Infrastructure
`ScenarioRepository`がCSVファイルを読み込みパースし、`AnimationRepository`/`BackgroundRepository`/`PortraitRepository`が各種カタログAssetからアセットキーを解決する。
CSV は `StreamingAssets/ScenarioAuthoring/<シナリオID>.events.csv` を先に探し、無ければ `StreamingAssets/Scenario/<シナリオID>.csv` を読む。1 行目の列名が `Type` で始まる正規化形式と、オーサリング形式の両方を読める。
再生の設定値は `ScenarioSettingsAsset` にある。

| 名前 | 値 | 単位 | 正本のアセット |
|---|---|---|---|
| 通常の文字送り間隔 | 0.03 | 秒 / 文字 | `Assets/Level/Data/Master/Scenario/ScenarioSettingsAsset.asset` |
| 早送りの文字送り間隔 | 0.025 | 秒 / 文字 | 同上 |
| オート再生の待機 | 2 | 秒 | 同上 |
| 再生完了からビューを閉じるまで | 5 | 秒 | 同上 |
| ポーズ中の確認間隔 | 0.05 | 秒 | 同上 |
| スキップ時にすぐ閉じる | 有効 | — | 同上 |
| 最後のテキストでも入力を待つ | 有効 | — | 同上 |
| レイヤーの重なり順（背面から） | Background, PortraitLeft, PortraitRight, PortraitCenter | — | 同上 |

【要確認: 早送りの値が通常とほとんど変わらない。見直すかをシナリオ担当に確認する】

#### ⑥ Composition
`ScenarioCom`がシナリオシーン内の全スタックを手動DIで構築し、`OutGameScenarioInitializer`がOutGameシーン側で`SelectedScenarioState`を登録する。

### 🔌 拡張ポイント
| 拡張したいこと | 実装する場所 | 追加登録の要否 |
|---|---|---|
| 新しいイベント種別を追加したい | `IScenarioEvent`（Domain）の実装クラスを追加し、対応する`IScenarioEventHandler<T>`（Adaptor）を実装する | 必要（`ScenarioHandlerRepo`への型登録を`ScenarioCom.Build()`に追記しないと、CSVにその種別が現れても処理されない） |
