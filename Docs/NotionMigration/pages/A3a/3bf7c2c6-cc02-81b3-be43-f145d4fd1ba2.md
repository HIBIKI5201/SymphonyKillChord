## 判定

- 信頼性: 一部古い — `isTutorial` のとき `TutorialData.Complete()` を呼ぶとしているが、現行は `CompleteBattle()`。`Complete()` はホームチュートリアルの終了時に呼ばれる。報酬（初回クリア報酬・成功報酬）の付与、変化が無いときは保存しない判定、保存失敗時の巻き戻し、シナリオクリアの経路も無い。末尾の `System ->> System`（参加者未定義）と「一時ファイル経由でアトミックに置換」は現行ローダーでは確認できない。根拠: `Assets/Scripts/Runtime/2.Application/Persistent/Savedata/StageProgressSaveDataService.cs:29-92,167-203`、`Assets/Scripts/Runtime/6.Composition/InGame/Sequence/SequenceInitializationModule.cs:404-416`、`Assets/Scripts/Runtime/6.Composition/OutGame/Scenario/ScenarioCom.cs:438`
- 整合性: 親ページ「セーブ」（39e7c2c6-cc02-80c6-a4e3-e064efa25c2c）の原稿、「Tutorial」ページの段階制と揃えた
- 変更点:
  - シーケンス図: 旧: `SaveClearAsync(stageId, evaluationResult, isTutorial)` → 新: `SaveClearAsync(stageId, firstClearReward, clearReward, result, isTutorial)`
  - シーケンス図: 旧: `TutorialData.Complete()` → 新: `TutorialData.CompleteBattle()`
  - シーケンス図: 初回クリア判定、報酬付与、変化なしなら保存しない分岐、保存失敗時の巻き戻しを追加
  - シーケンス図: 旧: `System ->> System: 書き込みロック取得 → WriteAsync（一時ファイル経由でアトミックに置換）` → 新: 削除（現行ローダーはフレームワーク側で、実装を確認できないため）
  - 末尾に「シナリオクリア時の違い」を追記
- 織り込んだ反映項目: OG-016
- 出典: 実装（上記ファイル）、PR #1818（30_ OG-016 の記載）
- 要確認: なし

## 適用する本文

バトルステージのクリアが確定したときに、Sequenceモジュールから呼ばれる。
```Mermaid
sequenceDiagram
    autonumber
    participant Seq as SequenceInitializationModule (Sequenceモジュール)
    participant Service as StageProgressSaveDataService
    participant Data as StageProgressData / TutorialData / ResourceInventoryData
    participant Store as SaveStore

    Seq ->> Service: SaveClearAsync(stageId, firstClearReward, clearReward, result, isTutorial)
    Service ->> Store: SaveData を取得（キャッシュ）
    Service ->> Service: 巻き戻し用のスナップショットを取る・初回クリアか判定
    Service ->> Data: StageProgressData.RecordClear(stageId, achievedEvaluationIds)
    alt isTutorial == true
        Service ->> Data: TutorialData.CompleteBattle()
    end
    alt 進行に変化が無く、初回クリアでもなく、成功報酬も空
        Service -->> Seq: false（保存しない）
    else それ以外
        opt 初回クリア
            Service ->> Data: 初回クリア報酬を ResourceInventoryData に加算
        end
        Service ->> Data: 成功報酬を ResourceInventoryData に加算（毎回）
        Service ->> Store: SaveAsync<SaveData>()
        alt 保存に失敗
            Service ->> Data: スナップショットで記録前の状態へ戻す
            Service -->> Seq: 例外を再送出
        else 成功
            Service -->> Seq: true
        end
    end
```
シナリオステージをクリア（スキップを含む）したときは、Scenarioモジュール（`ScenarioCom`）が評価結果を持たない版の`SaveClearAsync`を呼ぶ。流れは同じで、オープニングシナリオの場合は`CompleteBattle()`の代わりに`CompleteOpeningScenario()`を記録する（Phaseが NotStarted のときだけ）。
