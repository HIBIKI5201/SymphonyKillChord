## 判定

- 信頼性: 陳腐化 — バトルの分岐が「`ShowBattlePreparationScreen()` → 戦闘準備画面で装備を確認してから出撃」のまま。現在は `StartBattle()` → `OutGameUIEvent.OnStartGame` → `ScreenInitializer` が InGame シーンへ遷移する（OG-102）。導入文の「3通り」に対して図は 2 分岐しかない
- 整合性:
  - 実装: `OutGameSortieUseCase.cs:31-49`（バトルは `StartBattle()`）、`:51-78`（シナリオは `SetOutGameActiveForScenario(false)` → `LoadAdditiveAsync`。失敗時は表示を戻す）、`:85-89`（`RequestImmediateBattleSortie`）、`OutGameSortieOutputPort.cs:49-52,66-83`（`OnStartGame` 通知、入力マップを OutGame / Scenario に切り替え）
  - 出撃ボタンからの呼び出しは `StageDetailScreenView` から直接ではなく、`OutGameUIEvent.OnSortieRequested` を受けた `StageSelectInitializer.HandleSortieRequested` が `OutGameSortieController.RequestSortieAsync` を呼ぶ（`StageSelectInitializer.cs:643-745`）
- 変更点:
  - 導入文: 旧: 「ステージ種別に応じて3通りへ分かれる。」 → 新: 3 通り（出撃ボタンのバトル・シナリオ、即時出撃）を明記
  - シーケンス図: 呼び出し元を `StageSelectInitializer` に直し、バトルの分岐を `StartBattle()` → `OnStartGame` → `ScreenInitializer` の InGame 遷移に差し替え。シナリオの分岐に追加ロード失敗時の復帰を追加。`RequestImmediateBattleSortie` の経路を追加
- 織り込んだ反映項目: OG-102
- 出典: 上記の実装箇所、`Assets/Scripts/Runtime/6.Composition/OutGame/Screen/ScreenInitializer.cs:569-619`、PR #1839
- 要確認: なし

## 適用する本文

ステージ種別と呼び出し方に応じて3通りへ分かれる。出撃ボタンからはバトルかシナリオへ、チュートリアル戦闘への自動出撃と戦闘後の自動遷移からはステージ種別を確認せずにバトルへ進む。戦闘準備画面は廃止済みで、バトルは直接開始する。
```Mermaid
sequenceDiagram
    autonumber
    actor Player as プレイヤー
    participant Init as StageSelectInitializer (StageSelect)
    participant Ctrl as OutGameSortieController
    participant UseCase as OutGameSortieUseCase
    participant Port as OutGameSortieOutputPort
    participant Screen as ScreenInitializer (Screen)
    participant Scene as SceneTransitionUsecase

    alt 出撃ボタン
        Player ->> Init: 出撃ボタン（OnSortieRequested）
        Init ->> Ctrl: RequestSortieAsync(ステージ種別, 現在のシーン, 遷移先シーン)
        Ctrl ->> UseCase: RequestSortieAsync
        alt バトルステージ
            UseCase ->> Port: StartBattle()
            Port -->> Screen: OutGameUIEvent.OnStartGame
            Screen ->> Screen: 選択中バトルステージのInGameシーンへ遷移
        else シナリオステージ
            UseCase ->> Port: SetOutGameActiveForScenario(false)
            Note over Port: OutGameのUIを隠し、入力マップをScenarioへ切り替える
            UseCase ->> Scene: シナリオシーンを追加ロード
            opt ロードに失敗した場合
                UseCase ->> Port: SetOutGameActiveForScenario(true)
            end
        end
    else チュートリアル戦闘への自動出撃・戦闘後の自動遷移
        Init ->> Ctrl: RequestImmediateBattleSortie()
        Ctrl ->> UseCase: RequestImmediateBattleSortie
        UseCase ->> Port: StartBattle()
        Port -->> Screen: OutGameUIEvent.OnStartGame
    end
```
