## 概要
> 💡 **モジュール概要**
> タイトル画面の表示、チュートリアルの進行段階による開始遷移先の決定（未開始ならオープニングシナリオ、それ以外はホーム）、メニュー画面（音量設定・言語設定・セーブデータリセット・クレジット）、無操作時のPV演出を司るモジュールである。他モジュールから参照されることのない、アプリケーションの入口である。
| 項目 | 内容 |
|---|---|
| **モジュール名** | Title |
| **カテゴリ** | OutGame |
| **ステータス** | 実装済み |
| **最終更新日** | 2026-09-22 |
---

### 🏗️ クラス
| クラス名 | レイヤー | 役割・機能 |
|---|---|---|
| `**TitleStartController**` | Adaptor | `StartGameAsync`で遷移先シーンを追加ロードし、常駐シーンの寿命でTitleシーンをアンロードする。多重タップと、シナリオ戦闘出撃の進行中の開始を防止する |
| `**TitleSceneView**` | View | タイトル画面本体。タップ（PCは決定操作）でゲーム開始、オプションボタン（コントローラーはOptionsボタン）でメニュー画面表示 |
| `**MenuScreenView**` | View | メニュー画面（オプションウィンドウ）。音量・言語の設定項目、クレジットへの導線、データリセットボタンと確認ダイアログを持つ。確認ダイアログで消去を選ぶと`OutGameUIEvent.OnDataResetButtonClicked`を発火する |
| `**CreditScreenView**` | View | クレジット画面（制作メンバー一覧は「スクリーン」ページを参照する） |
| `**VolumeSettingsTabView**` | View | メニュー画面の音量設定項目を、共通音量設定（`IAudioSettingsViewModel`/`IAudioSettingsCommand`）へバインドする |
| `**LanguageSettingsTabView**` | View | メニュー画面の言語設定項目を、共通環境設定（`IEnvironmentSettingsViewModel`/`IEnvironmentSettingsCommand`）へバインドする。切り替えるたびに確定・保存する |
| `**TitleIdleVideoView**` | View | タイトル表示中に一定間隔で背景だけをPV（`StreamingAssets/Title/GamePV.mp4`）へ切り替え、BGMの音量演出と、動画中のタイトルロゴ・開始案内の表示切り替えを行う |
| `**TitleSceneInitializer**` | Composition | 開始遷移先の決定、各種View構築、イベント購読、データリセット処理を担当 |
| `**TitleScreenViewRegistry**` | Composition | `ScreenId`（Title/Menu/Credit）と各Viewの対応表 |
  > セーブデータリセット処理専用のクラスは存在せず、`TitleSceneInitializer`の私有メソッド（`HandleDataResetButtonClicked`）として実装されている。`ScreenId.Options`はenumに残っているが、どの対応表・ルールアセットにも登録されていない。

#### 🧩 Composition初期化情報
| 項目 | 内容 |
|---|---|
| **Initializerクラス** | `TitleSceneInitializer` |
| **Order** | 20（Titleシーン内。同じシーンの`OutGameSceneInitializer`（0）が`OutGameUIEvent`を先に登録する） |
| **公開する ModuleContainer / ServiceLocator登録型** | 専用の`ModuleContainer`は無し。開始遷移先がオープニングシナリオのときは`SelectedScenarioState`（未登録なら新規登録）にシナリオを設定し、遷移先シーンを`TitleSceneView`へ設定する |
| **ResourceLoadで読み込むもの** | 画面遷移ルール`TitleScreenRuleData`、`StageTreeAsset`、`EnemyWaveDefinitionRepository`（いずれもAddressables）、セーブデータ。読み込み後に初期スキルを補完して保存する |

#### 📥 依存しているもの
- `**Persistent/Savedata**`
  - *依存箇所*: `SaveData`, `TutorialData`, `TutorialPhase`
  - *詳細*: `SaveData.Tutorial.Phase`がNotStartedかどうかで開始遷移先を決める。読み書きはSymphonyFrameworkの`SaveStore`（`IsLoaded`/`Get`/`LoadAsync`/`SaveAsync`/`DeleteAsync`）で行う
- `**Persistent/Savedata**`**（初期スキル）**
  - *依存箇所*: `InitialSkillLoadoutService`
  - *詳細*: タイトルの読み込み時（体験版終了後の再入場を含む）とセーブデータ削除後に初期スキル構成を補完して保存する。これが無いとリセット直後にスキルが未装備のまま出撃できてしまう
- `**Persistent/Music**`** / **`**Persistent/Environment**`
  - *依存箇所*: `AudioSettingsModuleContainer`, `EnvironmentSettingsModuleContainer`
  - *詳細*: `VolumeSettingsTabView`/`LanguageSettingsTabView`が共通設定のViewModel/Commandへバインドする。リセット時は現在の音量をViewModelから退避し、リセット後に書き戻す。`TitleIdleVideoView`は`MusicPlayer`の音量を参照してPV中のBGMを調整する
- `**Persistent/SceneManagement**`
  - *依存箇所*: `SceneTransitionController`, `LoadingScreenController`, `EventNotificationView`
  - *詳細*: `TitleStartController.StartGameAsync`が追加ロード・アンロードに使用する（`ISceneInitializationReadiness`によるモジュール初期化完了待機の恩恵を受ける）。ロード中はタイトルの操作を止める。リセット成功時は中央通知「セーブデータをリセットしました。」を出す
- `**Persistent/Input**`
  - *依存箇所*: `PlayerInputView`
  - *詳細*: コントローラーのOptionsボタンでメニュー画面を開閉する。取得できない場合はOptionsボタンでの開閉だけが無効になる
- `**StageSelect**`** / **`**Scenario**`
  - *依存箇所*: `StageTreeAsset`, `EnemyWaveDefinitionRepository`, `ScenarioStageDefinition`, `SelectedScenarioState`
  - *詳細*: Phaseが NotStarted のとき、ステージツリーから前提ノードを持たない最初のシナリオノードをオープニングのチュートリアルシナリオとして選び、`SelectedScenarioState.SelectOpeningTutorialScenario`に登録して、そのシナリオのシーンを遷移先にする。NotStarted 以外のときは`SelectedScenarioState`をクリアし、遷移先をOutGameにする
- `**Screen**`
  - *依存箇所*: `OutGameUIEvent`, `ShowScreenUseCase`等の遷移スタック
  - *詳細*: Title/Menu/Creditの画面遷移に汎用Screenモジュールの仕組みを使う

#### 📤 依存されているもの
- なし
  - *詳細*: Titleはアプリケーションの入口であり、他モジュールから直接参照されることはない。オープニングシナリオの選択はTitle側で完結しており、Scenario側は`SelectedScenarioState`に設定された選択状態を読むだけである

## 詳細

### 🧅レイヤー情報

#### ① Domain
当モジュールでは使用していない。

#### ② Application
当モジュールでは使用していない（汎用Screenモジュールの`ShowScreenUseCase`等を利用するが、Title固有のApplication層クラスはない）。

#### ③ Adaptor
`TitleStartController`がシーン遷移を駆動し、多重タップを防止する。

#### ④ View
`TitleSceneView`/`MenuScreenView`/`CreditScreenView`という画面遷移チェーンと、`VolumeSettingsTabView`/`LanguageSettingsTabView`というメニュー内の設定項目、`TitleIdleVideoView`という無操作時の演出を担当する。

#### ⑤ Infrastructure
当モジュールでは使用していない。

#### ⑥ Composition
`TitleSceneInitializer`（Order 20）が、開始遷移先の決定・各View構築・イベント購読・データリセット処理を一手に担う。

### 🔌 拡張ポイント
> 現状、ポリモーフィックな拡張ポイント（`SubclassSelector`等）はない。メニュー画面に新しい設定項目を追加する場合は、`VolumeSettingsTabView`/`LanguageSettingsTabView`と同様の`IDisposable`実装クラスを追加して共通設定のViewModel/Commandへバインドし、`TitleSceneInitializer`に組み込む形になる。
