## 適用する本文

メニュー画面の「データリセット」から確認ダイアログを経てセーブデータを削除し、初回起動状態へ戻す。音量設定・言語・リズム判定オフセットはリセット前の値を維持する（言語とリズム判定オフセットの維持は未実装。現状は音量設定だけを維持する）。
```Mermaid
sequenceDiagram
    autonumber
    actor Player as プレイヤー
    participant Menu as MenuScreenView
    participant Init as TitleSceneInitializer
    participant Save as SaveStore
    participant View as TitleSceneView
    participant Notice as EventNotificationView

    Player ->> Menu: データリセットボタン押下
    Menu ->> Menu: 確認ダイアログを表示
    alt 「とじる」・キャンセル
        Menu ->> Menu: ダイアログを閉じる（何もしない）
    else 「消去する」
        Menu -->> Init: OutGameUIEvent.OnDataResetButtonClicked
        Init ->> Init: 操作を停止し、現在の音量（BGM・SE・ボイス）をViewModelから退避
        Init ->> Save: SaveStore.DeleteAsync<SaveData>()
        Init ->> Save: SaveStore.LoadAsync<SaveData>()（再読込）
        Init ->> Init: InitialSkillLoadoutService で初期スキルを補完して保存
        Init ->> View: ApplyStartDestination()（遷移先をオープニングシナリオに設定）
        alt 成功
            Init ->> Save: 退避した音量を書き戻して SaveAsync
            Init ->> Notice: ShowAsync("ui.notification.save_reset")（3秒表示＋0.5秒フェード）
            Init ->> Init: 操作を再開（ロード中でなければ）
        else 失敗
            Init ->> Init: セーブデータの再読込・初期スキル補完・遷移先の設定をやり直す
            alt 復旧できた
                Init ->> Save: 退避した音量を書き戻して SaveAsync
                Init ->> Init: 操作を再開（通知は出さない）
            else 復旧できない
                Init ->> Init: タイトルの操作を停止したままにする
            end
        end
    end
```
- リセットで元に戻らないのは音量（BGM・SE・ボイス）・言語・リズム判定オフセットである。画面・画質・明るさ・振動の環境設定は既定値に戻る。
- 現状は音量だけを退避して書き戻しており、言語とリズム判定オフセットも既定値に戻る（未実装）。図は現状の流れである。
- タイトルシーンが途中で破棄された場合は、通知と操作の再開を行わない。
- 戦闘側の装備は、出撃のたびにセーブデータから読み直す（PR #1801）。
