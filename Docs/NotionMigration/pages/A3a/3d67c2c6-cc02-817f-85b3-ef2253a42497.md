## 適用する本文

`BattleCompleted`以上かつ未完了の場合のみ、ホームチュートリアルが開始される。`RunHomeTutorialAsync`はHome画面のボタン（作戦・研究・改造・設定の4つ）を順にハイライトし、決定入力ごとに次の手順へ進む。強制完了の要求（体験版のホームタイマー満了）を受けると、残りの手順を打ち切って完了扱いにする。
```Mermaid
sequenceDiagram
    autonumber
    participant Loading as LoadingScreenController
    participant Init as OutGameTutorialInitializer (Order 150)
    participant Save as SaveData.Tutorial (TutorialData)
    participant UIEvent as OutGameUIEvent
    participant Home as HomeScreenView
    participant Overlay as TutorialOverlayView

    Note over Init: Ready() 呼び出し時
    Init ->> Loading: IsLoading を確認
    alt ロード中
        Init ->> Loading: LoadingCompleted を購読
        Loading -->> Init: HandleLoadingCompleted(isSuccess)
    end
    Init ->> Save: Phase < BattleCompleted または IsTutorialCompleted を判定
    alt 開始条件を満たさない
        Note over Init: 何もせず終了
    else 開始条件を満たす
        Init ->> Save: StartHome()（Phase→HomeStarted、変化時のみ）
        Init ->> Save: SaveAsync<SaveData>()
        Init ->> UIEvent: OnHomeTutorialStarted を発火
        loop 4つの手順（StageSelect / SkillTree / SkillBuild / OptionIcon）
            Init ->> Home: FindTutorialTarget(要素名)
            alt 対象が見つからない
                Note over Init: 警告を出してその手順を飛ばす
            else 対象が見つかった
                Init ->> Overlay: ShowStepAsync(対象, 文言)
                Overlay -->> Init: 決定入力（NavigationSubmit / クリック）で完了
            end
            opt 強制完了の要求を受けた（OnHomeTutorialForceCompleteRequested）
                Init ->> Overlay: ForceCompleteCurrentStep()
                Note over Init: 残りの手順を打ち切る
            end
        end
        Init ->> Overlay: HideAsync()
        Init ->> Save: Complete()（Phase→Completed）
        Init ->> Save: SaveAsync<SaveData>()
        Init ->> UIEvent: OnHomeTutorialCompleted を発火
    end
```
