## 概要
> 💡 **モジュール概要**
> アウトゲーム（ホーム）の設定画面（メニュー・音量設定パネル・環境設定パネル）を構築するモジュールである。ドメインロジックを持たない薄いUI構築層で、音量は常駐シーンの共通音量設定（`AudioSettingsModuleContainer`）へ、画面・言語・振動・リズム判定は常駐シーンの共通環境設定（`EnvironmentSettingsModuleContainer`）へバインドする。Titleシーンの音量・言語の設定UI（`VolumeSettingsTabView`/`LanguageSettingsTabView`）も同じ共通設定へバインドしており、どちらから変更しても同じ状態を見る。
| 項目 | 内容 |
|---|---|
| **モジュール名** | Setting |
| **カテゴリ** | OutGame |
| **ステータス** | 実装済み |
| **最終更新日** | 2026-09-22 |

## 詳細

### 🧅レイヤー情報

#### ① Domain
当モジュールでは使用していない（設定値のデータは「セーブ」ページの`AudioSettingsData`/`EnvironmentSettingsData`）。

#### ② Application
当モジュールでは使用していない。

#### ③ Adaptor
当モジュールでは使用していない。

#### ④ View
`SettingMenuView`がメニューと各パネルの切り替えを、`AudioSettingsView`が音量ゲージを、`EnvironmentSettingsView`が環境設定の各項目を担当する。

#### ⑤ Infrastructure
当モジュールでは使用していない。

#### ⑥ Composition
`SettingComposition`（Order 140）が共通音量設定・共通環境設定のContainerを`ServiceLocator`から取得し、3つのViewを構築する。構築に失敗した場合は作りかけのViewを破棄して`false`を返す。

### 🔌 拡張ポイント
> 現状、ポリモーフィックな拡張ポイント（`SubclassSelector`等）はない。新しい環境設定項目を追加する場合は、`EnvironmentSettingsData`へのフィールド追加、`IEnvironmentSettingsCommand`/`IEnvironmentSettingsViewModel`への操作・表示値の追加、適用先（`I*Applier`）の実装、`EnvironmentSettingsView`とUXMLへの項目追加が必要になる。

### 🔊 共通音量設定（Persistent/Music）
設定画面のスライダーが直接音量マネージャを叩くのではなく、常駐シーンに置かれた共通の音量設定を経由し、変更はセーブデータへ永続化される。設定画面・タイトル画面のどちらから変更しても同じ状態を見ることになる。
| クラス名 | レイヤー | 役割・機能 |
|---|---|---|
| `**AudioSettingsData**` | Domain | BGM・効果音・ボイスの音量を保持するセーブデータ |
| `**AudioSettingsService**` | Application | 音量設定を読み込み、変更要求を直列に保存するサービス |
| `**IAudioSettingsRepository**` | Application | 音量設定の永続化操作の契約 |
| `**AudioSettingsRepository**` | Infrastructure | `SaveStore`を使って音量設定を永続化する |
| `**AudioSettingsController**` | Adaptor | UIから受け取った値をDomainとBGM・SE・ボイスの各`IVolumeManager`へ反映する（`IAudioSettingsCommand`実装） |
| `**AudioSettingsPresenter**` | Adaptor | 音量設定を`AudioSettingsViewDTO`へ変換してViewModelへ反映する |
| `**IAudioSettingsViewModel**` / `**AudioSettingsViewDTO**` / `**IAudioSettingsCommand**` | Adaptor | UIへ公開するViewModel契約・表示データ・操作契約 |
| `**AudioSettingsViewModel**` | View | 音量設定の表示状態を`ReadOnlyReactiveProperty`として保持する |
| `**AudioSettingsInitializer**` | Composition (Persistent) | 共通音量設定を読み込み、常駐シーンへ公開する（Order 35） |
| `**AudioSettingsModuleContainer**` | Composition (Persistent) | 音量設定の公開物を保持するContainer |

### 🖥️ 共通環境設定（Persistent/Environment）
画面モード・解像度・画質・明るさ・言語・振動・リズム判定オフセットは、常駐シーンに置かれた共通の環境設定を経由する。ホームの環境設定パネルでは、変更はすぐプレビューに反映されるが、保存されるのは「設定を保存」（`ConfirmChanges`）を押したときだけで、保存せずにパネルを離れると破棄される（`CancelChanges`）。タイトルの言語設定は、切り替えるたびに確定・保存する。項目の選択肢・範囲・既定値は「仕様概要 / 設定画面」に書く。初回起動時の既定値は`Assets/EnvironmentSettingsDefaultAsset.asset`でプランナーが変更できる。
