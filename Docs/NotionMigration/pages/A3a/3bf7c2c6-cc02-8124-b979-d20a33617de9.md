## 適用する本文

解放済みノードを集計し、インゲームのプレイヤーへ補正として渡す。計算はInGameシーンの初期化で毎回行い、セーブデータの解放済みノードを読み直す。
```Mermaid
sequenceDiagram
    autonumber
    participant BonusInit as PlayerStatusBonusInitializer (Playerモジュール, Order 490)
    participant UseCase as LoadPlayerStatusBonusUseCase
    participant Repo as SavedataSkillUnlockRepository
    participant Calc as PlayerStatusBonusCalculator
    participant Container as PlayerStatusBonusModuleContainer
    participant PlayerInit as PlayerInitializer (Playerモジュール, Order 500)

    BonusInit ->> BonusInit: SkillNodeDataRepo を読み込み、Repo・Calculator・UseCase を生成
    BonusInit ->> UseCase: ExecuteAsync
    UseCase ->> Repo: 解放済みノードを取得
    Repo -->> UseCase: SkillNodeId の集合
    UseCase ->> Calc: 各ノードの IStatusBonusEffect を集計
    Calc -->> UseCase: PlayerStatusBonus（攻撃力倍率・最大HP倍率など）
    UseCase -->> BonusInit: PlayerStatusBonus
    BonusInit ->> Container: PlayerStatusBonusModuleContainer として ServiceLocator へ登録
    PlayerInit ->> Container: ServiceLocator から取得
    PlayerInit -->> PlayerInit: インゲームのプレイヤーへ適用
```
