## 適用する本文

セーブデータのチュートリアル進行段階（`TutorialData.Phase`）に応じて遷移先を決定する。未開始（NotStarted）ならオープニングのチュートリアルシナリオへ、それ以外はホーム（OutGameシーン）へ遷移する。オープニングシナリオをクリア（スキップを含む）すると、そのステージの接続（StageBindのAutoAdvance）によってチュートリアル戦闘へ進む（「シナリオシステム」ページを参照する）。
```Mermaid
sequenceDiagram
    autonumber
    participant Init as TitleSceneInitializer
    participant Save as SaveStore
    participant Tree as StageTreeAsset
    participant Scenario as SelectedScenarioState
    participant View as TitleSceneView
    actor Player as プレイヤー
    participant StartCtrl as TitleStartController
    participant Scene as SceneTransitionController

    Note over Init: ResourceLoadAsync
    Init ->> Save: SaveStore.IsLoaded<SaveData>()
    alt 読み込み済み
        Init ->> Save: SaveStore.Get<SaveData>()
    else 未読み込み
        Init ->> Save: SaveStore.LoadAsync<SaveData>()
    end
    Save -->> Init: SaveData（Tutorial.Phase含む）
    Init ->> Init: InitialSkillLoadoutService で初期スキルを補完（補完したら保存）
    Note over Init: Build（ApplyStartDestination）
    alt Phase != NotStarted
        Init ->> Scenario: 登録済みなら Clear()
        Init ->> View: SetTargetSceneName("OutGame")
    else Phase == NotStarted
        Init ->> Tree: 前提ノードを持たない最初のシナリオノードを取得
        Init ->> Scenario: SelectOpeningTutorialScenario(シナリオ)（未登録なら登録）
        Init ->> View: SetTargetSceneName(シナリオの対象シーン)
    end
    Player ->> View: 画面タップ（PCは決定操作）
    View ->> StartCtrl: StartGameAsync(currentScene, targetScene)
    StartCtrl ->> Scene: LoadAdditiveAsync(targetScene)（遷移先の初期化完了まで待機）
    StartCtrl ->> Scene: UnloadWithPersistentLifetimeAsync("Title")
```
