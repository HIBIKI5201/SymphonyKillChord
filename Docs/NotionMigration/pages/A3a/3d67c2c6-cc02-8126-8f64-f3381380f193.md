- 整合性:

  - 出撃先: 解放済みのバトルステージのうち、前提をたどった距離が最も長いもの（`DemoStageResultExitPolicy.cs:54-119`）
  - 作戦画面側: `StageSelectInitializer.TryForceBattleSortie` が対象を準備し、`StageSelectScreenView` と `StageDetailScreenView` を強制出撃モードにし、設定ボタンとステージマップを無効にする（`StageSelectInitializer.cs:320-375`）。戻る・装備変更・別ステージの選択もできない（#1635）
  - 保留: ロード中・シナリオからの戦闘出撃中・通知の表示中は処理しない。ロード後に最新の解放状態から選び直す（#1728）。全体の期限切れと重なったら全体を優先し、強制出撃を取り消す
  - ホームタイマーは OutGame に入るたびに 0 に戻り、強制出撃の準備済みフラグも戻る（`:421-437`）
  - 他ページ: `出撃`（3bf7c2c6-cc02-818a-9af0-f2c3997d603b）・`ステージセレクト`（39e7c2c6-cc02-80c3-b671-d3162c5f9d3b）の強制出撃の記述とそろえる。`Tutorial` の子ページ①（3d67c2c6-cc02-817f-85b3-ef2253a42497）の強制完了の分岐と対になる

## 適用する本文

OutGame滞在中にホーム制限時間を超えると、通知を出した後、ホームチュートリアルを強制完了させ、解放済みのバトルステージのうち前提をたどった距離が最も長いステージを作戦画面で選んだ状態にする。作戦画面では出撃以外の操作（戻る・装備変更・設定・ステージマップ・別ステージの選択）ができなくなる。ロード中・シナリオからの戦闘出撃中は保留し、ロード後に最新の解放状態から選び直す。全体の期限切れと重なった場合は全体を優先し、強制出撃は行わない。
```Mermaid
sequenceDiagram
    autonumber
    participant Boot as DemoRuntimeBootstrap
    participant Session as DemoSessionState
    participant Notice as EventNotificationView
    participant UIEvent as OutGameUIEvent
    participant Policy as DemoStageResultExitPolicy
    participant SS as StageSelectModuleContainer

    loop 毎フレーム (Update)
        Boot ->> Boot: OutGameへ入った直後ならホームタイマーを0に戻す
        Boot ->> Session: Tick(unscaledDeltaTime, isOutGameActive)
        Session -->> Boot: IsHomeTimeExpired
    end
    alt ホーム制限時間切れ かつ OutGame内（ロード中・通知中・シナリオ戦闘出撃中でない）
        Boot ->> Notice: ShowAsync("ui.notification.home_expired")
        Notice -->> Boot: 表示完了（3秒＋フェード0.5秒）
        alt 全体の期限切れ・タイトル復帰・別のOutGame滞在に変わった
            Note over Boot: 強制出撃を行わない
        else
            Boot ->> UIEvent: OnHomeTutorialForceCompleteRequested を発火
            Boot ->> Policy: TryGetLatestAvailableBattleStage(StageTree)
            Policy -->> Boot: 最も深い解放済みバトルステージ
            Boot ->> SS: TryForceBattleSortie(StageId)
            SS -->> Boot: 成否（作戦画面で対象を選択し、出撃以外を無効化）
        end
    end
```
