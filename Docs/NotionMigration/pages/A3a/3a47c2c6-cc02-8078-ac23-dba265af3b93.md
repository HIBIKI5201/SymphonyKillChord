## 説明

### デプロイ
本サイトはAstro製で、`HomePage`ディレクトリ配下に実装される。
GitHub Actions（`.github/workflows/HomePageDeploy.yml`）により、`main`ブランチへのpushをトリガーとしてビルドとGitHub Pagesへのデプロイが自動実行される。

### 参考資料
（既存のリンクを残す）

### 公開 URL
公開 URL は `https://hibiki5201.github.io/SymphonyKillChord/home/` である。ルート（`https://hibiki5201.github.io/SymphonyKillChord/`）にアクセスすると `home` ページへ転送する（`HomePage/astro.config.mjs`）。

### ページ構成
| ページ | パス | 内容 | 表示データ |
| --- | --- | --- | --- |
| ホーム | `home` | キービジュアル、お知らせ、SNS（YouTube・X）、ストアへのリンク、各ページへの導線 | `src/data/news.ts` |
| キャラクター | `character` | キャラクター紹介（Symphony / Triad / Prelude） | `src/data/characters.json` |
| ゲームプレイ | `gameplay` | ゲームの特徴の紹介、PV 動画 | `src/data/gameplayFeatures.json` |
| スキル | `skill` | スキルの紹介 | `src/data/skills.json` |
| お知らせ | `news` | お知らせの一覧 | `src/data/news.ts` |
| クレジット | `credit` | 制作クレジット | `src/data/credits.json` |
| プライバシーポリシー | `policy` | プライバシーポリシー | ページ内に直接記述 |

- 全ページのヘッダーに、感想募集フォーム（Google フォーム）へのリンクと Download ボタンを置く
- Download ボタンと Steam / Google Play のリンクは、URL を設定するまで押せない状態で表示する。URL を設定すると通常のリンクに切り替わる

### 表示データの更新
- 表示内容は `HomePage/src/data/` のファイルを書き換えて更新する。`main` へ反映するとデプロイされる
- お知らせは `src/data/news.ts` の `news` 配列に、日付・タイトル・リンク先を 1 件ずつ追加する。追加すると、ホームとお知らせ一覧の両方に新しい順で表示される
- サイトのクレジット（`credits.json`）は、ゲーム内のクレジット（`Assets/Level/Data/Master/OutGame/Screen/CreditMembers.csv`）とは別のデータである。名簿の正本はNotionの「クレジット」ページで、両方ともNotionに合わせる（#1971）

### 開発環境
- Node.js 22.12 以上が必要である
- Windows では `HomePage/dev.bat` を実行すると、開発サーバーがバックグラウンドで起動し、ブラウザでホームが開く。止めるときは `HomePage` で `npm run astro -- dev stop` を実行する
