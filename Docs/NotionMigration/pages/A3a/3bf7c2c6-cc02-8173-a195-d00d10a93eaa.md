## 適用する本文

シナリオシーンに遷移してから、CSVを読み込みイベントを順次再生し、再生完了後に次の遷移へ進むまでの流れである。
```Mermaid
sequenceDiagram
    autonumber
    participant Com as ScenarioCom (Ready)
    participant State as SelectedScenarioState
    participant Usecase as ScenarioUsecase
    participant Repo as ScenarioRepository
    participant HandlerRepo as ScenarioHandlerRepo
    participant Handler as TextEventHandler 等
    participant View as ScenarioView
    participant Gate as ScenarioAdvanceGate
    participant Facade as ScenarioPresenterFacade
    participant Save as StageProgressSaveDataService
    participant Sortie as OutGameSortieController

    Com ->> State: CurrentScenarioId を取得
    Com ->> Usecase: PlayScenario(scenarioId)
    Usecase ->> Usecase: 再生状態（Auto・ポーズ・早送り）をリセット
    Usecase ->> Repo: FindByIdAsync(scenarioId)
    Repo ->> Repo: CSVを読み込みパース（都度パース、キャッシュ無し）
    Repo -->> Usecase: ScenarioDefinition
    loop 各IScenarioEventを順に処理
        alt RequirePlayerAdvance == true（最後の行も入力を待つ設定）
            Usecase ->> Gate: WaitNextAsync を表示より先に開く
        end
        Usecase ->> HandlerRepo: HandleAsync(event)
        HandlerRepo ->> Handler: 種別ごとの処理を実行
        Handler ->> View: Presenter経由で描画反映
        alt RequirePlayerAdvance == true
            Usecase ->> Usecase: 送り入力 または Auto の待機のうち、先に来た1回で次へ
        end
    end
    Usecase ->> Facade: NotifyCompletedAsync(skipped)
    Facade ->> View: 完了表示（スキップ時はすぐ閉じる／通常は設定秒数後に閉じる）
    Usecase -->> Com: PlayScenario 完了
    Com ->> Save: SaveClearAsync（シナリオステージのクリアを保存）
    alt 次のシナリオへの自動遷移が予約されている
        Com ->> State: 次のシナリオを選択して再生へ戻る
    else バトルへの自動遷移が予約されている
        Com ->> Sortie: バトルへ直接出撃（シナリオシーンは破棄される）
    else 予約が無い（遷移モードが ManualSelection、またはタイトルから始めた第1話）
        alt OutGameがロード済み
            Com ->> Sortie: ReturnFromScenarioAsync（シナリオを閉じてHome表示）
        else タイトルから開いた（OutGameが無い）
            Com ->> Com: OutGameを追加ロードしてシナリオシーンを閉じる
        end
    end
```
※ タイトルから始めた第1話は出撃ボタンを経由しないため予約が無く、OutGame を読み込んだ後に `StageSelectInitializer.TryStartTutorialSegment` がチュートリアル戦闘へ出撃する（遷移の結果は `AutoAdvance` と同じ）。

### 送り入力の規則
- 文字送りの途中で送り入力をすると、次の行へは進まず、その行の全文を表示する。飛ばした位置のタイミングトリガーも順番に発火する
- 手動の送り・Auto の待機・モードの変更は 1 つの待機を共有し、先に来た 1 回だけ次へ進む。余った入力は次の行へ持ち越さない
- UI の上での抑止（ボタンの上をクリックしたときは送らない）は、ポインター入力だけにかける。キーボード・ゲームパッドの送りは止めない
- UI 非表示（HideUI）から戻るフレームでは送らない
- 送るときは UI の選択状態を外し、決定キーによるボタンの Submit と二重に処理されないようにする
- 再生の開始時と終了時に、Auto・ポーズ・早送り・UI 表示の状態をリセットする
