## 適用する本文

`PlayerView`が保持している移動入力を、カメラ正面方向を基準に補正して反映する。移動入力は`PlayerInputView.OnMoveInput`を受けるたびに`PlayerView`が保持する。

```mermaid
sequenceDiagram
    autonumber
    participant InputView as PlayerInputView
    participant View as PlayerView
    participant Controller as PlayerController
    participant App as PlayerApplication
    participant RB as Rigidbody

    InputView -->> View: OnMoveInput（移動入力を保持）
    Note over View: 毎フレームの Update ループ
    View ->> View: 攻撃クールダウンと多段ヒットを進める (PlayerAttackController.UpdateAttackCooldown)
    alt 攻撃中・入力抑止中
        View ->> View: 移動入力を 0 として扱う
    end
    View ->> View: カメラの Y 回転で入力方向を回す
    opt 回避要求がある
        View ->> Controller: TryDodge(回避方向, 時刻)
        Controller ->> App: TryDodge
        App -->> Controller: 成否（成功時は OnDodgeSucceeded を通知）
    end
    View ->> Controller: 移動更新 (Update: 回転, 入力, 時刻)
    Controller ->> App: Update（通常移動または回避中の移動を計算）
    App -->> Controller: 回転と速度を返却
    Controller -->> View: 回転と速度（入力があれば OnMoved を通知）
    View ->> View: アニメーション用の速度と足音を更新
    Note over View: FixedUpdate
    View ->> RB: 速度と回転を反映 (linearVelocity / MoveRotation)
```
