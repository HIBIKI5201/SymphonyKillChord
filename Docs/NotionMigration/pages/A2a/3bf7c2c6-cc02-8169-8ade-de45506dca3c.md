## 適用する本文

Unity Input Systemのイベントを`InputContext`へ包み、購読側へ配る。届くのは、その時点で有効な入力マップ（`UnityInputMapController`が切り替える）のアクションだけである。ロード中とイベント通知の表示中は、`InputComposition`が`PlayerInputView.SetInputEnabled(false)`で通知を止める。

```mermaid
sequenceDiagram
    autonumber
    actor Player as プレイヤー
    participant Unity as Unity Input System
    participant View as PlayerInputView
    participant Consumer as CameraSystemView / PlayerView / ScenarioInputView ほか

    Player ->> Unity: キー・スティック・タップ操作
    Unity ->> View: InputAction のコールバック
    alt 入力抑止中（ロード中・通知表示中）
        View ->> View: 何もしない
    else 通常時
        View ->> View: InputContext<T> を生成（種類・Phase・値・時刻を保持）
        View -->> Consumer: 対応するイベントを発火
    end
    Note over Consumer: 購読側は Phase を見て Started / Performed を判別する
```
