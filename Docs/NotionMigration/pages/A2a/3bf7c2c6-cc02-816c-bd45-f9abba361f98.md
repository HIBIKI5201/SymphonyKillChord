## 適用する本文

移動速度とBPMから、クリップのブレンド値と再生速度を決める。全クリップは初期化時に再生を始めて止めず、ウェイトだけを動かすため、ロコモーションは音楽の位相に同期する（クリップの表示時間 = 音楽時間 mod クリップ長）。ただし曲の途中で生成された敵は、生成時刻が起点になるため位相がずれる。

```mermaid
sequenceDiagram
    autonumber
    participant Owner as PlayerView / EnemyMoveView
    participant VM as CharacterAnimationViewModel
    participant View as CharacterAnimationView
    participant Calc as CharacterAnimationLocomotionCalculator
    participant Playable as PlayableAnimationController

    Owner ->> VM: 移動速度を通知
    View ->> Calc: ブレンド値と再生速度を計算（BPMを加味）
    Calc -->> View: ブレンド値・再生速度
    View ->> Playable: PlayableGraph のウェイトと速度を更新
    View ->> Playable: 再生中のワンショットがあれば、そのウェイトを重ねる
    Note over Calc: 基準は60BPM。曲が速いほど再生も速くなる<br>速度 0.1 未満は Idle、以上で Walk のウェイトが上がる
    Note over Playable: クリップは止めずにウェイトだけを動かす（位相同期のため）
```
