## 適用する本文

プレイヤーが攻撃入力を行った際に、現在のビートタイミングと照合して拍種とジャストかどうかを判定するフローである。判定は入力1回につき1回だけ行い、その結果を攻撃・スキル・多段ヒット・画面演出が共有する。判定の読み取りは状態を変えない。

```mermaid
sequenceDiagram
    autonumber
    participant Attack as PlayerAttackController
    participant MSService as IMusicSyncService
    participant Skill as SkillController
    participant Presenter as PlayerAttackPresenter
    participant Signal as IPlayerAttackSignal (PlayerAttackSignal)
    participant Feedback as 演出側 (全画面演出・ガイド成功演出・振動・チュートリアル判定表示)

    Attack ->> MSService: 現在の拍種とジャスト成否を取得 (GetCurrentBeatType: out isJustHit)
    Note over MSService: 直前の入力からの経過を小節長で割った値を<br>RhythmJudgmentDefinition のジャスト範囲・拍種範囲と照合する<br>入力履歴が無い・拍オフセット前は非ジャスト
    MSService -->> Attack: BeatType と isJustHit を返却
    Attack ->> Skill: スキル判定と入力履歴の登録 (TryExecuteSkill: Attack, BeatType, isJustHit)
    Skill ->> MSService: RegisterBattleActionHistory(Attack, BeatType)
    Attack ->> Presenter: 判定結果を表示へ渡す (Push: BeatType, isJustHit)
    Presenter ->> Signal: PlayerAttackDto を通知 (Push)
    Signal -->> Feedback: OnAttackExecuted(拍数, isJustHit)
    Attack ->> Attack: 同じ isJustHit でダメージを適用（多段ヒットの残りも同じ値を使う）
```
