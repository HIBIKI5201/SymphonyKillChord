## 適用する本文

`MusicPlayer`（CRI）の再生時間を元に、ゲームプレイ中だけ毎フレーム BPM・拍情報が更新される処理フローである。ゲームプレイの開始・終了は`MusicSyncInitializer`の`StartGameplay`/`StopGameplay`が`MusicSyncView.SetGameplayActive`で切り替え、終了時とBGMのCue変更時には同期状態（入力履歴・予約・ゲージ基準）を破棄する。

```mermaid
sequenceDiagram
    autonumber
    participant MSView as MusicSyncView
    participant MPlayer as MusicPlayer
    participant MSCont as MusicSyncController
    participant Env as IEnvironmentSettingsViewModel
    participant MSState as MusicSyncState
    participant MSService as IMusicSyncService

    Note over MSView: 毎フレームの Update ループ（ゲームプレイ中・Cue 設定済み・BPM 設定済みのときだけ）
    MSView ->> MPlayer: 現在の再生時間を取得 (MusicPlayer.Time)
    MPlayer -->> MSView: playTime (double) を返却
    alt playTime が負
        MSView ->> MSCont: ResetPlayback()
    else それ以外
        MSView ->> MSCont: タイミング更新 (Tick: playTime)
        MSCont ->> Env: リズム判定オフセットを取得 (RhythmOffsetSeconds)
        Env -->> MSCont: オフセット秒（未取得なら 0）
        MSCont ->> MSState: 再生時間を反映 (UpdatePlayTime: playTime + オフセット)
        MSCont ->> MSService: ビート進行の更新 (Update: playTime + オフセット)
        MSService ->> MSService: 巻き戻しを検知したら ResetPlayback
        opt 最後の入力から2小節経過
            MSService ->> MSService: 入力履歴を破棄し OnRhythmTimedOut を通知
        end
        MSService ->> MSService: 実行時刻に達した予約済みアクションを実行
    end
```
