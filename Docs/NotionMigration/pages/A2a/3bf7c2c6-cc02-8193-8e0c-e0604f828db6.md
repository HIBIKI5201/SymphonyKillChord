## 適用する本文

バフ・デバフは状態効果（StatusEffect）として実装され、ダメージの授受に合わせて呼び出される。効果の実体はStatusEffectモジュールとBuffモジュールにあり、当モジュールは呼び出し口とコンテキストを提供する。補正は、攻撃力 → クリティカル倍率 → 与ダメージ → 被ダメージ の順に掛かる。

```mermaid
sequenceDiagram
    autonumber
    participant ACalc as AttackCalculator
    participant Crit as CriticalStep
    participant DExec as DamageExecutor
    participant ASys as 攻撃側 StatusEffectSystem
    participant DSys as 防御側 StatusEffectSystem
    participant Effect as 各状態効果の実装

    Note over ACalc: 攻撃処理開始（パイプラインの前）
    ACalc ->> ASys: 攻撃力の補正を要求 (ApplyAttackPowerModifiers)
    ASys ->> Effect: IAttackPowerModifier を順に適用
    Note over Crit: パイプライン内のクリティカル判定
    Crit ->> ASys: クリティカル倍率の補正を要求 (ApplyCriticalDamageMultiplierModifiers)
    ASys ->> Effect: ICriticalDamageMultiplierModifier を順に適用
    Note over DExec: AttackPipeline によるコアダメージ計算のあと
    DExec ->> ASys: 与ダメージの補正を要求 (ApplyOutgoingDamageModifiers)
    ASys ->> Effect: IOutgoingDamageModifier を順に適用
    DExec ->> DSys: 被ダメージの補正を要求 (ApplyIncomingDamageModifiers)
    DSys ->> Effect: IIncomingDamageModifier を順に適用
    DExec ->> DExec: バリア吸収とHPへの適用
    DExec ->> DSys: DamageTakenContext を通知 (NotifyDamageTaken)
    DSys ->> Effect: 被弾回数で切れる軽減などの後処理を実行
    DExec ->> ASys: DamageDealtContext を通知 (NotifyDamageDealt)
    ASys ->> Effect: ライフスティール等の後処理を実行
```
