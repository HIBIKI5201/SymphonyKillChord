## 適用する本文

攻撃のたびに、ジャストできたかどうかを画面全体で返す。入力1回につき1回再生し、空振りでも再生する。

```mermaid
sequenceDiagram
    autonumber
    participant Attack as PlayerAttackController
    participant AttackPresenter as PlayerAttackPresenter
    participant Signal as IPlayerAttackSignal
    participant Presenter as RhythmGuidePostEffectPresenter
    participant Guide as ACLikeRhythmGuideView (IRhythmGuideBeatViewModel)
    participant VM as RhythmGuidePostEffectViewModel
    participant View as RhythmGuidePostEffectView

    Attack ->> AttackPresenter: 入力時に確定した拍種とジャスト成否 (Push)
    AttackPresenter ->> Signal: PlayerAttackDto を通知
    Signal -->> Presenter: OnAttackExecuted(拍数, isJustHit)
    Presenter ->> Guide: 攻撃した拍種のビート色を取得 (TryGetBeatColor)
    alt 色を取得できない（ガイド未構築）
        Presenter ->> Presenter: 演出を出さない
    else 取得できた
        Presenter ->> VM: RhythmGuidePostEffectDto(isJustHit, 色) を渡す (Play)
        VM ->> VM: ジャストかどうかで強さと時間を選ぶ
        VM ->> View: 色を設定し、指定した強さから0へ減衰させる (SetColor / PlayOneShot)
    end
    Note over View: 全画面のVignetteとして描画される
```
