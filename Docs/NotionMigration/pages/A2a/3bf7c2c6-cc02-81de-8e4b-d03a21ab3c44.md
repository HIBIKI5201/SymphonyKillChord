## 適用する本文

ダメージを受けた際に Entity の HP が変化し、HUD（HPバー）へ即時反映される処理フローである。`OnHealthChanged`は被弾だけでなく、回復とスキルによるHP消費（`ConsumeHealth`）でも発火する。変化量はダメージが負、回復が正である。

```mermaid
sequenceDiagram
    autonumber
    participant DExec as DamageExecutor
    participant Defender as CharacterEntity (IDefender)
    participant HEntity as HealthEntity
    participant PHPresenter as PlayerHealthHudPresenter
    participant HHudVM as HealthHudViewModel (IHealthHudViewModel)
    participant HHudView as HealthHudView
    participant PView as PlayerView
    participant Recorder as MissionProgressRecorderController (Mission)

    DExec ->> Defender: TakeDamage (ダメージ値)
    alt 無敵中（回避中）
        Defender -->> Defender: OnDamageAvoided を発火（HPは変えない）
    else 通常
        Defender ->> HEntity: ChangeHealth（現在 HP を更新）
        Defender -->> PHPresenter: OnHealthChanged (currentHp, maxHp, amountChanged)
        Defender -->> Recorder: OnHealthChanged（減少時は被ダメージを記録し、コンボを0に戻す）
        PHPresenter ->> HHudVM: UpdateHealth (HealthHudDTO)
        HHudVM -->> HHudView: ReactiveProperty 経由で HP バーを更新
        opt 減少した
            PHPresenter -->> PView: OnDamaged（被弾演出 PlayDamageFeedback）
        end
        opt HP が 0 になった
            Defender -->> Defender: OnDied を発火（1回だけ）
        end
    end
```

敵の HP は`EnemyHealthHudPresenter`（Enemyモジュール）が同じ経路で頭上のHPバーへ反映する。
