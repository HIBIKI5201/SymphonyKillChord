## 適用する本文

瞬間イベントを受けて、基本アニメーションへ重ねて再生する。プレイヤーの攻撃系の要求（`PlayerCharacterAnimationSignal`経由）だけ、同一クリップの頭出しと移動キャンセルのオプションが付く。敵の要求はどちらもOFFである。

```mermaid
sequenceDiagram
    autonumber
    participant Owner as PlayerView / EnemyMoveView
    participant Signal as CharacterAnimationSignal / PlayerCharacterAnimationSignal
    participant View as CharacterAnimationView
    participant Timing as CharacterAnimationOneShotTimingCalculator
    participant Playable as PlayableAnimationController

    Owner ->> Signal: 攻撃・被弾などの瞬間イベント
    Signal ->> View: ワンショット要求（プレイヤーの攻撃系は、同一クリップ頭出し・移動キャンセルのオプション付き）
    View ->> Timing: 時間進行とブレンド時間を計算
    Timing -->> View: 再生位置とブレンド量
    opt 同一クリップ頭出しが有効で、同じクリップのオーバーレイが再生中
        View ->> View: 開始ブレンドを 0 にして頭から再生
    end
    View ->> Playable: ワンショットクリップへブレンド
    opt 移動キャンセルが有効
        Note over View: 開始ブレンドの後から終了ブレンド区間の前までに、<br>一度停止（速度 0.1 未満）を観測してから速度 0.1 以上になったら
        View ->> Playable: 現在のウェイトから終了ブレンド時間で 0 へフェードし、歩行へ移る
    end
    Note over View: 再生が終わると基本アニメーションへ戻る<br>回避の再生が終わると OnDodgeEnded を通知する（プレイヤーの攻撃クールダウンを開始）
```
