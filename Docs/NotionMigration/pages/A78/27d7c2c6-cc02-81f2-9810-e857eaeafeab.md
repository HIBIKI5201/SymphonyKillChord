- Symphony の戦闘開始・被弾（大・小）・スキル発動は、録った複数のパターンからランダムに鳴らす。

- Symphony のスキル発動のボイスは、前の台詞が鳴っている間は後から来たものを鳴らさない。

## 台本 ID 規約
リポジトリ文書 `Docs/チュートリアルフロー詳細_ボイス収録用_2026-08-05.md` では、チュートリアルの台本 ID を次の形で定めている。

```
TUT_<フェーズ>_<連番>_<話者>[_<種別>]

話者:  TRI = Triad / SYM = Symphony
種別:  （無印）= 通常  F1/F2/F3 = 失敗時バリエーション  R = 再プレイ時差し替え
```

例: `TUT_BEAT4_03_TRI_F2`

実装の Cue 名（`VOICE_Triad_Tutorial4` など）とテキストキー（`triad.tutorial.04` など）は、この規約に従っていない。
ボイスの ID は、実装の Cue 名を正とする。台本 ID・サウンドリスト番号は、下の対応表で Cue 名に対応づける。

## ID の対応表
ボイスの正の ID は実装の Cue 名である。テキストキーは字幕の表（`TutorialSubtitles`）のキーである。
台本 ID（`TUT_*`）の台本は、実装された字幕と台詞が違うため、対応する Cue が無い。
