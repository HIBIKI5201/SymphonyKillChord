## 説明
会議の記録は、ルートページのデータベース「議事録」に1会議1行で書く。新しい行は議事録テンプレから作る。
| 項目 | 書くこと |
|---|---|
| 日付 | 会議の日付 |
| 議題 | 会議の目的を一言で |
| 決定（本文の節） | 会議で決まったこと。決まったことが無ければ「なし」と書く |
| ログ（本文の節） | 議論の経過・報告 |
決まったことが仕様に関わる場合は、仕様検討フォーラムに案を出すか、該当する仕様のページへ反映する。
