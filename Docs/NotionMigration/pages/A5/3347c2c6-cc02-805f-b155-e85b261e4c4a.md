## 説明
マネジメント カテゴリーには、チームの進め方と管理のためのページを置く。
| ページ | 何があるか |
|---|---|
| スケジュール | タスク管理・スプリント管理・マイルストーン |
| ステータスリスト | アセットリスト・実装リスト・発注書リスト |
| 仕様検討フォーラム | 仕様案の提案から適用までの記録 |
| 議事録 | 会議の決定とログ |
| 使用素材一覧表 | プロジェクトが使う外部の素材・パッケージ |
| ワークフロー | 誰が何をどう進めるか |
