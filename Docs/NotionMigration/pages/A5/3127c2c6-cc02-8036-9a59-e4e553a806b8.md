### 仕様案のテンプレート
新しい案はデータベースのテンプレートから作る。テンプレートには次の節がある。
| 節 | 書くこと |
|---|---|
| 結論 | 採用された案を、仕様書に書き込む文体でまとめる |
| 記述指針 | 仕様書のどこに、どのように書き込むか |
| 仕様概要 | 仕様詳細の簡単なまとめ |
| 仕様意図 | その仕様にする理由や意図 |
| 仕様詳細 | 仕様概要の内容を詳しく書く |
| ログ | 「経緯」と「提案」。提案は「初期案」のトグルに書き、差し戻されたら「第二案」などのトグルを足す |
各節の書き方は、プランナーの企画のページにある。

### ステータス
| ステータス | 意味 |
|---|---|
| 作成中 | 案を書いている【要確認: 「作業中」との違い】 |
| 検討中 | 書き終わり、査定を待っている |
| 採用 | 査定で採用された。結論をまとめて仕様書へ適用する |
| 却下 | 採用しない |
| 適用済 | 仕様書への適用が終わった |

### 納期
仕様案の納期は一律3日とする（2026-03-13決定）。【要確認: 今も運用しているかをリードプランナーに】
- 1日目に初期案を書き上げ、2日目に査定し、差し戻された場合は3日目に直して採用する
- 3日目にも差し戻された場合は、2日延長する
- 3日で決まらない内容や、詳しい案が別に出る内容は、仕様案を分ける
- 納期に間に合わない場合は、事前にプランナーのチャットで伝える
