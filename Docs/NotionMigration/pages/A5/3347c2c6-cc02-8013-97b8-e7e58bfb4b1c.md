## 説明
システム カテゴリーには、ゲームの仕様と、その実装の仕方を置く。
| ページ | 何があるか | 主な読み手 |
|---|---|---|
| 仕様概要 | ゲームとしてどうあるべきか（ゲームデザイン仕様） | 全員 |
| システム概要 | それをどう実装しているか（モジュール文書・規定） | プログラマー |
| 用語 | 仕様書で使う言葉の定義 | 全員 |
| マスターデータ | ゲームが読み込むデータ（敵のステータスなど）の現状の値。仕様概要には数値を書かず、ここを参照する | プランナー・プログラマー |
