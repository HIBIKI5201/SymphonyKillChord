# 詳細 {color="gray_bg"}

### 使用技術
- アウトゲーム（タイトル・ホーム・作戦・スキルツリー・スキル編成・設定など）は UI Toolkit（UXML / USS）で構築する
- インゲーム HUD・ロード画面・ポーズは UGUI（Canvas / TextMeshPro）で構築する
  - 頻繁に生成と破棄を繰り返す表示や、座標移動・フェードを多用する演出は UGUI の方が扱いやすいため（廃案(旧案) の検討結果）
- UXML / USS は `Assets/Level/Scenes/Develop/OutGameTest/` 配下に置かれている（製品版が使うものも含む）
- PanelSettings はアウトゲーム用が `Assets/Level/Data/Master/UI/MasterPanelSettings.asset`、インゲーム用が `Assets/Settings/UI Toolkit/Ingame HUD Panel Settings.asset` にある

### デザインの基準
- スマホ向けにデザインを行う【要確認: この方針が現行も有効か、UIデザイナー・リードプランナーに】
- PC版はキーマウ操作をメインで行い、UIはスマホの使いまわしを行う
- スマホ版から有用するならキー表示を画面下で指示を行う。ボタンの通称に関しては〇ボタンなどと明記するのではなく専用ボタンで表示を行う
- ゲームパッドで全画面を操作できるようにする。選択中の要素はフォーカス表示（枠線と 1.1 倍の拡大）で示し、押下中は 0.9 倍に縮める

  - メイン担当者：プログラマー　確認：デザイナー、プランナー、ディレクター

  - メイン担当者：デザイナー　確認：プランナー、ディレクター

  - メイン担当者：プログラマー　確認：デザイナー、プランナー、ディレクター

### ボタン実装の用語
アウトゲームのボタンの修正を依頼するときは、次の 3 つの用語で範囲を指定する。用語ごとに対象のファイルが一意に決まる。

| 用語 | 指す範囲 | 対象 |
|---|---|---|
| ボタンの見た目の実装 | 画像・色・サイズなどの静的な見た目だけ。動きは含まない | `Button.uss` の `.btn-skin`。通常時は `UI_Button_off.png`、hover / focus / active 時は `UI_Button_on.png` に切り替える。既定サイズは 200×100px |
| アニメーションの実装 | 拡縮の動き・タイミング・イージングだけ。画像は含まない | `Button.uss` の `.btn-scale-feedback`（クリック時の縮小）、`ButtonPulseAnimationManipulator`（hover / focus 中の連続パルス）、`ButtonAnimationExtensions.EnableButtonPulseAnimation` |
| ボタンの実装(全部) | 見た目 + アニメーション + クリック・フォーカスの挙動 | `ButtonPresetExtensions.ApplyBasicButtonPreset`。上の USS クラスの付与、`UINavigationExtensions` の `MakeNavigable` / `RegisterActivation`、パルスの付与を 1 回の呼び出しで行う |

- 個別のボタンだけサイズを変えるときは、UXML の inline style（`style="width: ...; height: ...;"`）で上書きする。C# は不要である
- 見た目だけ・アニメーションだけを使うときは、UXML で `class="btn-skin"` / `class="btn-scale-feedback"` を個別に付け、必要なら `EnableButtonPulseAnimation()` だけを呼ぶ
- 拡縮の倍率（選択中 1.1 倍 / 押下中 0.9 倍）は各要素の USS で指定する。USS の scale は加算されず、最も詳細度の高い指定 1 つだけが効く
```C#
using KillChord.Runtime.View.OutGame.Common;

var disposable = someButtonElement.ApplyBasicButtonPreset(() => Debug.Log("クリックされた"));
// 不要になったら disposable.Dispose() で解除する
```
