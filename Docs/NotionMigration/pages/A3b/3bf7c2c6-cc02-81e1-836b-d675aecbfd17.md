## 適用する本文

1つのフェーズを全モジュールで終えてから次のフェーズへ進むため、`Build`で登録したものを`Ready`で取得する場合は`Order`に依存しない。`Order`が必要になるのは、同じフェーズの中で登録と取得をする場合である。
同じ`Order`のモジュールがあってもよいが、同じ`Order`のモジュールの実行順は保証されない。順序に依存するものは`Order`を分ける。
```Mermaid
sequenceDiagram
    autonumber
    participant Target as TargetSystemInitializationModule (Order 100)
    participant Camera as CameraSystemInitializer (Order 600)
    participant Locator as ServiceLocator

    Note over Target,Camera: Build フェーズ（全モジュール）
    Target ->> Locator: TargetSystemModuleContainer を登録
    Camera ->> Locator: 自分の依存を登録
    Note over Target,Camera: Ready フェーズ（全モジュールの Build が終わってから）
    Camera ->> Locator: TargetSystemModuleContainer を取得
    Locator -->> Camera: 取得成功（Build フェーズがすべて終わっているため）
    Note over Camera: この例は Order を逆にしても取得できる
```
```Mermaid
sequenceDiagram
    autonumber
    participant A as モジュールA (Order 小)
    participant B as モジュールB (Order 大)
    participant Locator as ServiceLocator

    Note over A,B: Ready フェーズ（Order 昇順）
    A ->> Locator: Ready の中で X を登録
    B ->> Locator: Ready の中で X を取得
    Locator -->> B: 取得成功（A が先に実行済みのため）
    Note over B: Order を逆にすると B の取得が先になって失敗し、初期化エラーになる
```
