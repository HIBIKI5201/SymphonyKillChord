### プロジェクトでの採用状況
  2026-09-22 時点で、Symphony Kill Chord は PAD を使っていない。Addressables のデータは、すべてプレイヤー本体に同梱する（ストア同梱方式）。このページは調査用の記事集として残す。
  - Split Application Binary はオフである（Player Settings → Publishing Settings）。
  - 配信用の Android ビルド（`Release_Master_Android` / `Demo_Master_Android`）は aab を出力する。これは Google Play の提出形式のためで、アセットパックは作らない。
  - ストア同梱方式の設定は、ビルド前の検証（`AddressableStoreBuildValidator`、メニュー `Tools/Addressables/Validate Store Build Settings`）で強制される。違反するとビルドが止まる。
| 検証する設定 | 求める値 |
|---|---|
| Build Addressables on Player Build | Build with Player |
| Remote Catalog | 無効 |
| 各 Group の Build / Load Path | Local |
| 各 Group の圧縮 | LZ4 |
| 各 Group の Bundle Mode | Pack Together |
| Google Play 向けリリースビルド | aab |
  - アドレスの付け方（未設定・`/` や `\` を含む・重複を禁止）は `AddressableKeyValidator`（メニュー `Tools/Addressables/Validate Keys`）が検証する。
  - グループ構成と登録ルールは規約として「Addressables 運用規定」に書き、使われていないグループの残骸は消す（#2083）。【要確認: 新規ページの作成先と名前。作成後にここからリンクする】
