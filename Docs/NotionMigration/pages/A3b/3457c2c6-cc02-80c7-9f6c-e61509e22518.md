## 判定

- 信頼性: 一部古い — 各パスの個数（HP 8・会心ダメージ 6・範囲 3・会心率 6・攻撃 8）と 1 個あたりの値は実データどおり。ただし会心ダメージの全入手値「50％」（実データは 6×10% = 60%）と会心率の全入手値「10%」（6×2% = 12%）が誤り。範囲は合計値が空欄。HP と攻撃の「一つ入手で1.0625倍」は、実装では基準値への加算（8 個で 1.5 倍、掛け算なら 1.0625^8 ≒ 1.62 倍）で、表現が誤解を招く。コストとノード構成の記載が無い。最終確認 2026-09-22 / 73fefeb45
- 整合性:
  - 仕様検討フォーラム 0314 は旧値（各 5 個・0.15m）のまま（OG-112 の記載による）
  - 編成枠拡張ノード N7 は説明文が「装備スロットを一枠解放」だが、`_hasSkillSlotBonus` がどのノードのアセットにも入っていない（OG-110、他領域。研究画面 3437c2c6-cc02-80d1-8adc-d63d047f4199）
  - 空ノード N113・N133〜N137 は効果なしで解放できる（OG-115、研究画面）
- 変更点:
  - 左パス / 右パス: 旧: 「一つ入手でHPが（攻撃力が）1.0625倍増加」 → 新: 「一つ入手で元の値の6.25%増加（加算）」。全入手 1.5 倍は残した
  - 中央左パス: 旧: 「全入手で会心ダメージが50％増加」 → 新: 60%（会心ダメージ倍率 +0.6）
  - 中央パス: 空欄だった合計値に「全入手で射程を0.9m増加」を入れた。射程は前方エリアを対象にするスキルの範囲（基準 12m）に加算されることを足した
  - 中央右パス: 旧: 「全入手で会心率が10%増加」 → 新: 12%
  - コスト / その他のノード / ノード一覧（新しい節、末尾）: スキル解放ノード・編成枠ノード・空ノード、コスト、全 48 ノードの表を追加した
- 決定（2026-09-22 八幡）: R48 スキルツリーの空ノードには効果を入れる（#1983）。「その他のノード / 効果なし」の【要確認】（効果を付けるか削除・非表示にするか）を「効果を入れる（未実装、#1983）」に直し、入れる効果の種類と値だけを【要確認】に残した
