# 詳細 {color="gray_bg"}

## いちばん大事なこと
- 1行が1つの命令
- 1列目は番号
- 2列目は命令の種類
- 3列目以降に、その命令に必要な内容を書く
- 行の後ろにある不要な引数は省略してよい

## 保存場所
`Assets/StreamingAssets/ScenarioAuthoring/<シナリオID>.events.csv`に置く。
例：`Assets/StreamingAssets/ScenarioAuthoring/ScenarioTest.events.csv`

## まずはこの形で書けばよい
```Plain Text
1,Background,background
2,Layer,PortraitLeft,2
3,Portrait,Left,hello,-460,-120,1,true
4,Portrait,Right,hello,460,-120,1,true
5,Text,Hero,......Hello sekai?
6,Portrait,Left,good,-460,-120,1,true
7,Text,Tatuki,danger is coming
```

## 使う命令は5つだけ

### 1. 背景を変える
```Plain Text
番号,Background,背景ID
```
例：`1,Background,background`

### 2. 立ち絵の重なり順を決める
```Plain Text
番号,Layer,対象,順番
```
例：`2,Layer,PortraitLeft,2`
よく使う対象は`PortraitLeft` / `PortraitCenter` / `PortraitRight` / `Background` / `Text`である。

### 3. 立ち絵を出す・変える
```Plain Text
番号,Portrait,位置,立ち絵ID,X,Y,拡大率,表示するか
```
例：`3,Portrait,Left,hello,-460,-120,1,true`
- 位置: `Left` / `Center` / `Right`
- 立ち絵ID: 表示したい絵の名前
- X: 左右位置
- Y: 上下位置
- 拡大率: 普通は`1`
- 表示するか: 普通は`true`

最小形の`3,Portrait,Left,hello`でも使える。この場合はX=0、Y=0、拡大率=1、表示する（`true`）になる。

### 4. 会話を出す
```Plain Text
番号,Text,話者名,セリフ
```
例：`5,Text,Hero,......Hello sekai?`
話者名を空欄にすると地の文になる。話者名欄だけが隠れ、セリフは表示される。

### 5. フェードを入れる
```Plain Text
番号,Fade,開始値,終了値,秒数,対象,方法
```
例：`8,Fade,0,1,0.5`
`対象`と`方法`は省略できる。省略時は`Screen,Alpha`である。
`Alpha`の値は`0`が透明、`1`が不透明である。既定の`Screen,Alpha`では、会話枠を残して背景と立ち絵の透明度を変える。
画面を黒く暗転・明転させる場合は、`Black,Alpha`を指定する。
```Plain Text
8,Fade,0,1,0.5,Black,Alpha
9,Fade,1,0,0.5,Black,Alpha
```
透明度を変える対象は次のとおりである。
- `Screen`: 画面全体（会話枠を除く）
- `Background`: 背景
- `PortraitLeft` / `PortraitCenter` / `PortraitRight`: 各立ち絵
- `Text`: 会話枠、話者名、本文
- `Black`: 全画面黒オーバーレイ

立ち絵を、輪郭と透明度を保ったまま黒くする場合は、対象の後ろへ方法`Black`を指定する。
```Plain Text
9,Fade,0,1,0.5,PortraitLeft,Black
10,Fade,1,0,0.5,PortraitLeft,Black
```
`対象`に指定する`Black`は全画面黒オーバーレイ、`方法`に指定する`Black`は立ち絵の黒化である。立ち絵黒化の対象には`PortraitLeft` / `PortraitCenter` / `PortraitRight`だけを指定できる。
テキストの末尾でTriggerから立ち絵を黒くする場合は、開始値・終了値・秒数の後ろへ対象と方法を追加する。
```Plain Text
20,Text,案内役,この本文の表示完了時に左の立ち絵が黒くなります
21,Trigger,20,AtTextEnd,,,Fade,0,1,0.5,PortraitLeft,Black
```

## 省略してよい書き方
後ろの引数は省略できる。次の2つはどちらも有効である。
```Plain Text
3,Portrait,Left,hello,-460,-120,1,true
3,Portrait,Left,hello
```
ただし、途中を飛ばして後ろだけ書くときはカンマが必要である。
```Plain Text
3,Portrait,Left,hello,-460,,1,true
```
これは`Y`だけを空欄にして、その後ろの`拡大率`と`表示するか`を書いている。

## ルール
- 文字の間にカンマを入れたいときは`"..."`で囲む
- `"`を文字として入れたいときは`""`と書く
- 小数は`0.5`のように`.`を使う
- `true`と`false`が使える
- 空行と`#`で始まる行は無視される

## よくあるミス
- 行番号が重複している
- `Text`のセリフが空
- `Portrait`の位置が`Left` `Center` `Right`以外になっている
- 数字を書く場所に文字を書いている

## コピペ用テンプレート
```Plain Text
1,Background,background
2,Layer,PortraitLeft,2
3,Portrait,Left,hero
4,Text,Hero,こんにちは
5,Portrait,Right,friend
6,Text,Friend,やあ
```

## もっとやりたいとき
この5つで足りない場合は、子ページ「ScenarioCommandSpec」の次の機能を使う。
- `Animation`: アニメーションを再生する
- `Trigger`: セリフの途中や最後で別の命令を発火する
- ヘッダー付きCSV: 列名ありの詳細形式
