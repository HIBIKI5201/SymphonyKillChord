> 📦 **アーカイブ（2026-06 の研究記録）**
このページは研究ブランチでのセーブシステム試作の記録である。ここに載っている `SaveBase` / `SaveSystem` は本体から削除され、SymphonyFramework の `SaveStore` に統合された。現行の仕組みは「システム概要 / セーブ」を参照する。
暗号化（「セーブデータの暗号化開発」）は研究ブランチだけの内容であり、本体のセーブデータは平文 JSON である。
現行実装に引き継がれた考え方は次のとおり。
- セーブデータは型ごとに 1 ファイルで管理する（保存先は `Application.persistentDataPath/<型名>.json`）
- 書き込みは一時ファイル（`.tmp`）に書いてから入れ替え、書き込み中断によるデータ消失を防ぐ（自前の`PersistentFileSaveDataLoaderStrategy`。このクラスは現在使われておらず、フレームワーク側のローダーを正として削除する（#2061））
