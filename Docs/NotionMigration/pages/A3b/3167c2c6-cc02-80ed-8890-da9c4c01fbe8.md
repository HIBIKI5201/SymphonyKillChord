# プロジェクトでの使用状況 {color="gray_bg"}
2026-09-22 時点では、本番のキャラクターに揺れ物は設定されていない。
- 本番のプレイヤー `Player.prefab`（新モデル Symphony_0828）には SpringManager / SpringBone が付いていない
- SpringBone を設定しているのは、開発用シーン `Assets/Level/Scenes/Develop/Designer/SymphonyModel/SymphonyModelDemo.unity` と研究用シーン `Assets/DevelopProducts/Research/SpringBone/Scenes/SpringBoneResearch.unity` だけである
- 「シーン開始時に揺れ物ボーンが暴れる」の対処は、研究用の `SpringBoneInitializer`（`Assets/DevelopProducts/Research/SpringBone/Scripts/Runtime/`）にだけ実装されている。本番のキャラクターに揺れ物を付けるときは、この実装を本番側へ移す必要がある
- 体験版（TGS 2026）は揺れ物なしで出す【要確認: 体験版で揺れ物なしとすることを、アートディレクション・クライアントリードに】
- 揺れ物はハイブリッドにする。髪などのチェーン型は軽量なSpringBone、服などの布型は正確なMagica Cloth 2で作る
  - Magica Cloth 2は、2026-09-22時点でリポジトリに導入されていない（`Packages/manifest.json`にもアセットにも無い）
  - 両者の負荷のベンチマークを今後測る（Issue 化予定）
- ハイブリッドにするときの注意点
  - 同じボーンをSpringBoneとMagica Cloth 2の両方で動かさない
  - コライダーが二重になる
  - スローモーション時の時間倍率を、両方で揃える
  - 瞬間移動（位置の強制移動）のときに、両方の揺れをリセットする
  - スマホでの負荷
