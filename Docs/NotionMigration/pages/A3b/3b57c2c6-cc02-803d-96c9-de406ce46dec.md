# 説明 {color="gray_bg"}
（既存のリンクを残す）
グーグルドライブのシナリオcsvをUnityに同期する方法を説明します。
共有フォルダ直下のスプレッドシートとCSVファイルを取得し、`Assets/StreamingAssets/ScenarioAuthoring`へ保存します。

### **手順１**
  Unityの上部の「Tools」のタブを押し、「Import CSV]を押す。
  （既存の画像を残す）

### 手順２
  「API Key」欄に、配布されたAPIキーを入力します。【要確認: APIキーの配布方法（どこで受け取るか）を担当者に確認する】
  APIキーはこのPCのUnity（EditorPrefs）にだけ保存され、リポジトリには含まれません。APIキーは本ページやDiscordの公開チャンネルなど、誰でも見られる場所に書かないでください。
  「Folder ID」欄には既定のフォルダが入っています。別のフォルダから取り込むときだけ書き換えます。
  （既存の画像を残す）

### 手順３
  「インポート」ボタンを押すと、ドライブからcsvがダウンロードされます。
  既存のファイルを上書きする場合は、上書きするファイルの一覧が確認ダイアログに出るので、内容を確かめて続行します。
  完了すると、ウィンドウの下に結果が表示されます。これで同期完了！！

### ファイル名の決まり
- 保存名は、ドライブ上のファイル名の末尾に`.csv`を付けたものになります（ファイル名が既に`.csv`で終わる場合はそのまま）。
- ゲームが読むのは`<シナリオID>.events.csv`です。そのため、ドライブ上のファイル名は`<シナリオID>.events`（例：`Episode_1.events`）にしてください。
- 保存名が重複するファイルがフォルダにあると、取り込みを中断します。
- フォルダ内のスプレッドシートとCSV以外のファイルは取り込みません。
