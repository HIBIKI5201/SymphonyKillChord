> 💡 このページは設計時の資料である。`SinfoniaAssetManager` という名前のツールは実装されておらず、下記 3 機能はそれぞれ別のツールとして実装済みである。
> - 1（Google Drive のアセットを取り込む）: `DriveImportSync`（メニュー `Tools/DriveImportSync/Sync Now`）。Service Account の JSON 鍵（`DriveImportSecrets`）で認証し、配置先は `Assets/` 配下に限る。設定は `ProjectSettings/KillChord/DriveImportSettings`
> - 2（パッケージを Google Drive 経由で共有する）: `DriveUploadPackageStrategy`（`Assets/Editor/Scripts/AssetStorePackagePipeline/`）。出力した `.unitypackage` を Drive へアップロードする
> - 3（Drive の unitypackage で自動ビルドする）: GitHub Actions の `BuildAndRelease.yml`。Drive のフォルダから更新日時が最新の ZIP を 1 つ取得し、中の `.unitypackage` を展開してからビルドする。詳細は「AutoBuilder」ページを参照する
