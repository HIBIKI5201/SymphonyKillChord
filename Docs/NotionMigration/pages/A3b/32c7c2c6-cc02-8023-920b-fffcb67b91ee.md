### プロジェクトでの現状
  2026-09-22 時点の Symphony Kill Chord の設定と実装である。
  - Incremental GC は有効である（Project Settings → Player → Use incremental GC。`ProjectSettings/ProjectSettings.asset` の `gcIncremental: 1`）。
  - 文字列の組み立てには ZString（`com.cysharp.zstring` 2.6.0）が使える。`ZString.Format` や `ZString.CreateStringBuilder` は、`string.Format` や `$""` と違ってヒープ割り当てを抑えられる。
  - 頻繁に生成・消滅するものは、次のプールで使い回している。新しく同種のものを作るときは、これらに合わせる。
| 対象 | 実装 |
|---|---|
| 敵 | `6.Composition/InGame/Enemy/EnemyPools.cs` |
| ダメージ数値 | `4.View/InGame/Enemy/DamageNumberPoolView.cs` |
| パーティクル | `4.View/InGame/Character/ParticleSystemPoolView.cs` |
| スキルエフェクト | `4.View/InGame/Skill/Effect/SkillEffectSpawner.cs` |
  - Linq はアウトゲームの画面処理と初期化処理だけで使っている。インゲームの毎フレーム処理では使っていない。
  - Runtime 監査（`Docs/RuntimeAudit/04_GCAllocとメモリリーク.md`、2026-07-27）の指摘のうち、ボスの照準線 `TripleShotRaycastDetectView` が `LineRenderer.material` を参照してマテリアルを暗黙に複製する箇所が残っている（`4.View/InGame/Enemy/Boss/TripleShotRaycastDetectView.cs` の照準線の色設定 3 か所）。`sharedMaterial` か `MaterialPropertyBlock` を使うと複製を避けられる。
