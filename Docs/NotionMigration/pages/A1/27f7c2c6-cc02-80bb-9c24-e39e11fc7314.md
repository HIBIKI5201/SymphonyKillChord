# 詳細説明 {color="gray_bg"}
攻撃のアクションによってリズムを刻む。
回避はリズムを刻まない（拍子判定・スキルのコマンドに関係しない）。【要確認: 回避もリズムを刻む仕様に戻すかを企画に】
判定されたタイミングは「ノーツ」として記録される。
判定された拍子に応じてノーツの種類が変わる。
もし2拍子と判定されれば2ノーツ、8拍子の判定されれば8ノーツとなる。

判定する拍子は
- 1拍子
- 2拍子
- 3拍子
- 4拍子
- 6拍子
- 8拍子

の6種類である。

## リズムの判定方法
（既存の画像を残す）
前回と今回の入力の時間差から、何拍子かを判定する。
判定の起点は直前の入力（またはリズムタイムアウトした時点）であり、曲の拍の格子ではない。
時間差の計算にはBPMが影響する。時間差を1小節の長さで割った値（小節比）で拍子を決める。
BPMは全ステージ共通で84（1拍 約0.714秒、1小節 約2.857秒）、曲頭オフセットは0秒である。1小節は4拍で固定である。
例えばBPMが84の場合、4拍子の1拍の時間は約0.714秒になる。
ここで前回と今回の入力の時間差が約0.357秒なら、判定は8拍子となる。

| 拍子 | 小節比 | BPM84 での秒 | 正本 |
| --- | --- | --- | --- |
| 8拍子 | 0〜0.148 | 0〜0.423 | `Assets/Level/Data/Master/InGame/Music/RhythmJudgmentDefinitionAsset.asset` |
| 6拍子 | 0.1458〜0.2083 | 0.417〜0.595 | 同上 |
| 4拍子 | 0.2083〜0.3 | 0.595〜0.857 | 同上 |
| 3拍子 | 0.3〜0.4167 | 0.857〜1.191 | 同上 |
| 2拍子 | 0.4167〜0.75 | 1.191〜2.143 | 同上 |
| 1拍子 | 0.75〜1（1以上は1拍子に丸める） | 2.143〜タイムアウト | 同上 |

- 範囲は開始を含み、終了を含まない。
- 8拍子と6拍子の範囲は 0.1458〜0.148 で重なっており、重なった区間では8拍子になる（アセットのリストで先にある拍子を優先する）。【要確認: 重なりが意図どおりかを企画に】
- Just判定の範囲に入っている場合は、Just判定の範囲の拍子を優先する。
- BPMと曲頭オフセットはステージごとのデータを持たず、インゲームシーンの設定値（`MusicSyncInitializer`）で決まる。
- 判定は攻撃入力の時点で1回だけ行い、同じ結果を通常攻撃・スキル・多段ヒット・演出に使う。

攻撃を行ったタイミングが実際の拍子の感覚と同じだった場合**Just**の判定を行う。

## 拍子が判定できない入力
- 前回の入力がない場合（そのプレイで最初の入力、または曲頭オフセットより前の入力）
- 被弾した直後の入力の場合
  - 未実装である。現状の実装では、被弾してもリズムの履歴と判定の起点は続く。【要確認: この仕様を残すか外すかを企画に】

前回の入力から一定以上離れた入力は、判定できない入力ではなく「リズムタイムアウト」として扱う（後述）。

## 拍子が判定できない入力の仕様
- 前回の入力がない場合は、その入力を新しい起点にし、入力自体は1拍子ノーツとして記録する。
  - Just判定は成立しない。
  - 最初の攻撃は1拍子の武器（対物ライフル）で発射される。
- 判定できない入力をどのコマンドにも使える拍子として扱う案（Allノーツ）は保留である（拍子の判定と武器の選択の責務が分かれていないため。PR #1893）。

## 硬直時間
- モーションなどの再生のため攻撃を再度行うときに若干の硬直が発生する。
硬直時間の際はプレイヤーの入力はされず攻撃も発動しない。
  - 攻撃中：0.2秒（移動・次の攻撃を受け付けない。`Assets/Level/Data/Master/Character/Player.asset` の `_attackInterval`）
  - 攻撃クールダウン：0.2拍（BPM84で約0.143秒。`Assets/Level/Data/Master/InGame/Player/PlayerConfig.asset` の `_attackCooldown`）
  - どちらかが残っている間は攻撃を受け付けない。最短の再攻撃間隔はBPM84で0.2秒であり、8拍子の間隔（約0.357秒）より短い。
- 多段攻撃の途中で次の攻撃を行うと、残りのヒットは破棄される。
- スキルのモーション中は移動・攻撃を制限しない。【要確認: スキルのモーション中に操作をロックするかを企画に】

## リズムタイムアウト
- 前回の入力から2小節（BPM84で約5.714秒）経過すると「リズムタイムアウト」となる。
  - 値の正本は `RhythmJudgmentDefinition.TIMEOUT_BAR_COUNT`（`Assets/Scripts/Runtime/1.Domain/InGame/Music/RhythmJudgmentDefinition.cs`）で、[[リズムUI]] のゲージの全長と同じ値を使う。
- タイムアウトしたときは、次の処理を1回だけ行う。
  - 入力の履歴を消す
  - コンボを0に戻す
  - 全スキルの入力の進捗を消す（スキルのクールダウンはそのまま残る）
  - 判定の起点をタイムアウトした時点に移し、リズムUIのゲージを中心から再び進める
- タイムアウト後の最初の入力は、判定できない入力にはならない。タイムアウトした時点を起点として拍子とJustを判定する。
- 無入力が続く場合、ゲージは2小節ごとに周回する。タイムアウトの処理は履歴が残っているときだけ行う。
- 曲の停止・巻き戻し・戦闘の終了では、タイムアウトの処理を行わずに履歴と起点を破棄する。
