## 詳細説明

### 変更する設定
インゲームとアウトゲームで時間をかけて設定するものと、
時間のかからないもので区別し、インゲーム内での設定する時間を減らす。
重要、時間のかかる設定項目と短い時間で設定が終わる項目をインゲームとアウトゲームで分ける。
（旧ページ「コンフィグ」の内容をこの節にまとめた。項目の選択肢・既定値・保存のタイミングは「環境設定」「オーディオ設定」に記載する）

#### 重要な、時間がかかる項目
- 言語設定
  - 現状: ホームの設定画面（環境設定）とタイトルのメニューにある（日本語 / English、既定は日本語）
- 画質プリセット
  - 現状: ホームの設定画面（環境設定）にある（既定はPCがUltra、スマホがMedium。現状の実装は共通でHigh、#2062）
- 画面の明るさ
  - 現状: ホームの設定画面（環境設定）にある（0〜10、既定は5）

など、重要で設定に時間がかかる項目はアウトゲームにまとめる方向性にする。
**短時間で変更、決定が可能な項目**

#### 操作の感覚
- **カメラ感度： **3人称視点での索敵・エイムに影響。1〜10段階
  - 未実装（製品版で実装する、#2054。インゲームのカメラは固定の感度で、設定から変える経路が無い）
- **カメラ操作反転：** プレイヤーの資料にある上下左右の操作反転をここで実装
  - 未実装（製品版で実装する、#2054。反転はカメラの設定データの固定値）
- **オートロックオン有効/無効：** プレイヤーの意図しない視点移動を防ぎたい人向けの切り替え
  - 未実装（製品版で実装する、#2054。ビルドでは常に有効で、エディタ専用のデバッグ項目だけがある）
- **マニュアルロックオン時の追従速度：** 対象を捉え続ける際の視点移動速度の調整。
  - 未実装
- **振動：** ゲームパッドの振動の強さ。強い / 弱い / オフ（倍率1.0 / 0.5 / 0）、既定は強い
  - 現状: ホームの設定画面（環境設定）にある。Just判定が成立したときの振動に使う（[[Just判定について]] 参照）
- **決定・キャンセルのボタン：** ゲームパッドの決定とキャンセルのボタンを、海外式と日本式で切り替える。既定は海外式（決定＝South、キャンセル＝East）
  - 未実装（#2068。現状は日本式で固定）

#### 音の大きさ
- **Master Volume：** 全体の音量
  - 未実装
- **BGM：** リズムを刻むための基準音
- **SE：** 武器ごとの発射音・着弾音
- **ボイス：** キャラクターのボイス等

など、実際に体感し且つ短時間で調整可能な設定の物はインゲーム内で変更可能とする。
- 現状の音量はBGM・SE・ボイスの3つで、それぞれ0〜10の整数である。範囲と既定値は「オーディオ設定」に記載する

#### 判定調整機能
（子ページ「判定調整機能」を残す。旧ページ「コンフィグ」からこのページの子へ移す）
- 現状は、ホームの設定画面に「リズム判定タイミング」として実装されている。
- リズム判定の判定と表示の両方をずらす（-0.30〜+0.30秒、0.05秒刻み）。

#### 設定できる場所
現状の実装（体験版 TGS 2026 時点）で設定を変えられる場所は次のとおりである。
- ホームの設定画面
  - 環境設定: 画面モード、解像度、画質、明るさ、言語、振動、リズム判定タイミング
  - オーディオ設定: BGM、SE、ボイス
- タイトルのメニュー: BGM、SE、言語、クレジット、データリセット（ボイスは追加する、#2060）
- インゲーム: 無し（ポーズメニューは「リスタート」「タイトルへ戻る」だけ）
  - 方針にある、インゲームで短時間の設定（音量など）を変える機能は未実装である

### 注意点
設定画面を表示するとき画面は遷移せず、ウィンドウのみを表示させる


#### 使用するアセット
- 決定ボタン
  - 設定の保存に必要
- キャンセルボタン
  - 設定の変更時のキャンセルや前の画面に戻るときに必要
- 設定変更を表示する枠
- スライダー
  - 音声や光量などの設定時に使う
- 左右の切り替え（< 値 >）
  - 選択肢がある設定変更時に使う
- ミュートボタン
  - 音声設定変更時に使う
  - 現在は使っていない
- チェックボックス
  - 選択肢がある設定変更時に使う
  - 現在は使っていない（左右の切り替えを使う）

### 画面の構成
設定のメニューは次の4つで構成する。
- 環境設定
- オーディオ設定
- タイトルへ戻る
  - 確認ダイアログを出す
    - 文言：「タイトル画面に戻りますか？」
    - ボタン：「タイトル画面に戻る」「キャンセル」
- とじる

環境設定とオーディオ設定のパネルには、メニューに戻る「<」ボタンを置く。

### 環境設定

| 項目 | 選択肢・範囲 | 既定値 |
| --- | --- | --- |
| 画面モード | フルスクリーン / ウィンドウ | フルスクリーン |
| 解像度 | 端末が対応する解像度から左右で選ぶ | 初回はモニターの解像度（取得できないときは1920×1080） |
| 画質 | Very Low / Low / Medium / High / Very High / Ultra | PCはUltra、スマホはMedium |
| 明るさ | 0〜10 | 5 |
| 言語 | 日本語 / English | 日本語 |
| 振動 | 強い / 弱い / オフ | 強い |
| リズム判定タイミング | -0.30〜+0.30秒（0.05秒刻み） | 0秒 |
| 決定・キャンセルのボタン | 海外式（決定＝下のボタン〈South〉、キャンセル＝右のボタン〈East〉）/ 日本式（決定＝右のボタン〈East〉、キャンセル＝下のボタン〈South〉） | 海外式 |

- 明るさは、画面全体の露出を-3〜+3の範囲で変える（5のときは変えない）
- 言語の選択肢は、どちらの言語でも「日本語」「English」と表示する
- 振動は、ジャスト判定が成立したときのゲームパッドの振動の強さである（強い＝1倍、弱い＝0.5倍、オフ＝振動しない）。ゲームパッドをつないでいないときは何もしない
- リズム判定タイミングは、リズム判定の判定と表示の両方をずらす。詳細は[[判定調整機能]]に記載する
- タイトルのデータリセットでは、言語とリズム判定タイミングは保持する（それ以外の環境設定は既定値に戻る）
- 画質の既定値はプラットフォームごとに分ける（PCは5〈Ultra〉、スマホは2〈Medium〉）。未実装である（#2062。現状はPC・スマホ共通でHigh）
- 決定・キャンセルのボタンの切り替えは未実装である（#2068。現状は日本式で固定）
- 変更はすぐ画面に反映するが、保存するのは「設定を保存」を押したときだけである
- 保存せずにパネルを離れる（戻る、ウィンドウの外をクリック、キャンセル）と、変更は破棄する
- 既定値はプランナーが `Assets/EnvironmentSettingsDefaultAsset.asset` で変更できる
- カメラ感度・カメラ操作反転・オートロックオンの有効/無効の項目は未実装である（製品版で実装する、#2054。項目の方針は「変更する設定」に記載する）
- 英語表記は「Settings」とする（#2028。現在は Display Settings）

### 開き方・閉じ方
- 開き方
  - ホーム画面の歯車アイコンを押す
  - ゲームパッドのStart（キーボードはEsc）を押す
  - ウィンドウは画面の左から0.2秒でスライドインする
- 閉じ方
  - 「とじる」を押す
  - ウィンドウの外をクリックする
  - キャンセル（ゲームパッドは既定でB〈右のボタン〉、キーボードのEsc）を押す（環境設定・オーディオ設定のパネルではメニューに戻る）。現状のゲームパッドのキャンセルはA〈下のボタン〉で固定である（#2068）
  - 閉じるときは左へスライドアウトする
- 設定を開いている間は、Startを押しても何もしない
- Escは開く操作と閉じる操作の両方に割り当てているため、開いた瞬間と閉じた瞬間の入力で続けて反応しないようにしている
- ホーム以外の画面（作戦・改造・研究）から開けるか【要確認: 実機で確認】

## 仕様意図

【要確認: 設定画面の仕様意図を企画に】

設定項目の分け方（「変更する設定」節、旧ページ「コンフィグ」）の意図は次のとおりである。

プレイヤーが混乱しないため。
インゲームでの設定項目にかかる時間をできるだけ短くコンパクトにするため。
インゲームで設定しても即座に反映されない項目をインゲームで設定できると、混乱を招く。このため、アウトゲームとインゲームの両方で設定できる項目と、アウトゲームだけで設定できる項目を分ける（フォーラム「コンフィグについて」3137c2c6-cc02-8092-a2fe-ca60eabec568 の経緯による）。

### 却下・保留した案

- ミュートボタンとチェックボックス: 本ページとフォーラム「アウトゲームUIの構成要素」に挙げられているが、実装は使っていない（選択肢は「< 値 >」形式、数値はスライダー）。使わないと決めた記録は無い
- Key（キー設定）のカテゴリ: PR #816 で加えたが、PR #1391 でサウンド・システムの 2 カテゴリに作り直した。キー設定を外した理由の記録なし
- 「既定値に戻す」を画面に出すか: 出すことにした（決定（八幡）R53、#2066）。処理はある（PR #1648）が UI が無い
- 設定画面をホーム以外（作戦・改造・研究）から開けるようにするか: 保留【要確認: 実機で確認】
- 画質の初期値をプラットフォーム別にするか（現在は全プラットフォーム High）: 分けることにした（PC 5 / モバイル 2、決定（八幡）R43、#2062）
- 設定画面とコンフィグの役割分担（設定画面 = 画面の仕様、コンフィグ = 項目の方針）: 分けずに 1 ページにまとめることにした（決定（八幡）R59）
- 判定調整を「表示だけの補正」にする案（2026-08-04 の子ページの記述）: 2026-09-22 に判定と表示の両方をずらすことにしたため、採らない（決定 No.11）
- マニュアルロックオン時の追従速度、Master Volume、インゲームでの設定変更: 未実装として仕様に残す（決定 No.34、R52）。カメラ感度・反転・オートロックオンの切り替えは、決定 R26 で製品版で実装することになった（#2054）
- ゲームパッドの決定・キャンセルを日本式（決定 = East / キャンセル = South）で固定する現状: 既定を海外式にし、設定で切り替えられるようにする（決定（八幡）R56）
