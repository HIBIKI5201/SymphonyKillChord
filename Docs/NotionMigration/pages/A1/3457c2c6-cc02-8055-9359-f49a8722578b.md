## 詳細説明

### 戦闘勝利時
- ▶ 崩壊3rd：リザルト
  （既存の画像を残す）
キャラクターを見せながら、ミッション、タイム、コンボ数、ランクを見せるとクリアした際の、達成感を演出できる

#### 表示させるもの
- 挑戦したステージ名
- ポーズを取らしたキャラクター
  - クリア用のカメラでプレイヤーを画面の左側に映す
  - ポーズのモーションは現在は再生していない【要確認: 実機で確認】
- メインミッション
  - メインミッションの文と「達成」
- サブミッション
  - サブミッション（評価項目）ごとの達成・未達成
- 戦闘時間
  - ゲーム中の経過時間
  - 「分:秒」（mm:ss）で表示し、1秒未満は切り捨てる
- 最大コンボ数
  - ゲーム中の最大コンボ数
- ランク
  - 達成したサブミッションの数で決める

| 達成数 | ランク |
| --- | --- |
| 0 | C |
| 1 | B |
| 2 | A |
| 3以上 | S |

- 完了
  - 出撃元のシーンに戻る（通常はホーム画面）
- 再出撃
  - ステージをやり直す

### 戦闘敗北時
- ▶ 崩壊3rd：リザルト
  （既存の画像を残す）
キャラクターを見せながら、メインミッション、タイム、コンボ数を見せること
任務失敗した際のアドバイスとしてどのような点に気を付けるかのワンポイントアドバイスを記載する。

#### 表示させるもの
- 挑戦したステージ名
- ポーズを取らしたキャラクター
- メインミッション
  - メインミッションの文と「失敗」
- Tips
  - ゲームの攻略アドバイス
  - ステージのミッションに登録したTipsから1つをランダムに選ぶ。登録が無い場合は既定の文を表示する
- 戦闘時間
  - ゲーム中の経過時間
- 最大コンボ数
  - ゲーム中の最大コンボ数
- 完了
  - 出撃元のシーンに戻る（通常はホーム画面）
- 再出撃
  - ステージをやり直す

### クリア演出
ステージクリアからリザルト表示までは、次の順で演出する。
1. 画面の上下に黒帯を出す（ステージ開始演出と同じ黒帯）
2. プレイヤーの正面にカメラを移動する
3. クリアのメッセージを表示する
4. リザルト画面を表示する
5. リザルトの文字を上から順に表示する
6. 文字の表示が終わったら、数値をカウントアップする

| 名前 | 値 | 単位 |
| --- | --- | --- |
| クリア演出の長さ | 1.8 | 秒 |
| 黒帯の開閉 | 0.3 | 秒 |
| 正面カメラへの移動 | 1 | 秒 |
| 正面カメラの距離 | 2.5 | m |
| 正面カメラの高さ | 1.23 | m |
| 正面カメラの注視点の高さ | 0.93 | m |
| プレイヤーを映す画面上の横位置 | 0.25 | 画面幅に対する割合（左から） |
| 文字の表示にかける時間 | 3 | 秒 |
| 文字のスライドイン | 距離600・0.35秒・間隔0.06秒 | px・秒 |
| 数値のカウントアップ | 1 | 秒 |

【要確認: 各段階の時刻の対応を実機で確認】

### 操作
- 左右の入力で「再出撃」と「完了」を選ぶ
- 決定の入力で、選んでいるボタンを実行する
- 画面を開いたときは「完了」を選んでいる
- 選んでいるボタンは文字をシアンにし、1.1倍に拡大する

### 表示する文言の言語
- 開始・終了のメッセージ（Mission Start! など）と、リザルトの見出し（Mission Complete / Mission Failed）は英語で固定している
- メインミッションの判定（達成／失敗）と既定のTipsは日本語で固定している
【要確認: 英語固定を演出意図とするか、ローカライズ対象にするかを企画に確認】

### 遷移先
- 完了を選んだときの戻り先は、出撃したときにアウトゲーム側で決める（通常はホーム画面）【要確認: 実際に入る戻り先を確認】
- 体験版（TGS 2026）では、最新の解放済みステージを最終ステージとして扱う専用の遷移に差し替える。詳細は[[体験版仕様]]に記載する
- インゲームの読み込みに失敗したときは、黒い画面のままアウトゲームへ戻る

## 仕様意図

ステージをクリアした際に、リザルトがあることでクリア感を演出できる。
勝利時は、キャラクターを見せながらミッション・タイム・コンボ数・ランクを見せることで、クリアした際の達成感を演出する。
敗北時は、任務に失敗した際のアドバイスとして、どのような点に気を付けるかのワンポイントアドバイス（Tips）を載せる。
（2・3 文目は現行ページの「戦闘勝利時」「戦闘敗北時」節の説明文から採った）
