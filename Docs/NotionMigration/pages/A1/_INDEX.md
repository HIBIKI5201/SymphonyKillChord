## 領域全体で見つかった矛盾・重複

1. **ダメージ計算式が 4 か所で食い違う**（ダメージ計算・攻撃アクション・Just判定について・用語）。どれも実装の順序と違う。式の正本をダメージ計算に置き、他はリンクにした（BT-27）。**Just ダメージ倍率は仕様 200% だが実装は全武器 1.0**で、Just でダメージが増えない（BT-01）
2. **体験版仕様が陳腐化**: 5 分・PC とモバイル・導入とチュートリアルのみ → 実装は全体 420 秒／ホーム 90 秒・PC のみ・第1話 → チュートリアル → ホーム → 3 ステージ。全体の期限切れは戦闘中でも即 DemoEnd（計画書と逆）（DM-01〜08）
3. **ロックオンの仕様が実装と逆**: 「視界内で HP 最低 or 最近」→ 正面優先・距離/視界の制限なし。オート解除は「移動・視点操作で解除」→ 3 条件（命中なし 3 秒・画面外・強い視点操作）。対象消失時は次へ移らず解除（CM-01〜04）
4. **判定の数値の食い違い**: Just 幅は「±0.1 秒・対称」→ 小節比・非対称（TGS で 1.25 倍）。リズムタイムアウトは 1.5 小節 → 2 小節。判定調整は「表示専用・10ms 刻み」→ ±0.30 秒・0.05 秒刻みで判定時刻にも効く（BT-02, 05, 08）
5. **回避はリズムを刻まない**のに、リズム判定・スキル・システム概要が回避で刻む前提。回避キーは右クリック → Space・A、キーコンフィグは未実装（BT-16, 19）
6. **戦闘準備画面は #1839 で削除済み**なのに、作戦画面・ゲームフロー・システム概要に残る。タイトルの「始めから／続きから」も実装に無い
7. **チュートリアル**: キルコード固定の上書き（スキル0＆13）が未実装。アウトゲームのチュートリアルはホームだけで、スキル1の解放誘導も無い（「終了時に 3 種所持」と合わない）。ミッション定義が Release と Demo で別（TU-04, 09, 10）
8. **敵の数値**: HP 40/25 → 1000（#1800 の 10 倍スケール）、攻撃は基礎 10 固定で倍率なし。射程外に出ると攻撃をキャンセル（フォーラム 0218「必ず攻撃」と逆）。クリティカル時の 2 秒硬直は、却下済みフォーラム（0285/0297/0302）の足止め案と同じものが入っている
9. **研究画面の編成枠**: 枠拡張フラグが全 49 ノードで未設定で、枠が増えない可能性。拡張条件の記述が 3 系統に分かれる。作戦画面の報酬データは旧形式だけで、成功報酬（2 回目以降）が常に 0
10. **ステージBGM**: アウトロ移行は未実装（戦闘終了で停止）。組み替え単位は 2 小節 → 実装 4 小節、BPM は 90 前提 → 実装 84、対応スキルは skill_01/02 だけ
11. **重複ページ**: ボス／ボス戦闘（空。ボスへ統合）、α版・β版・体験版開発指針と体験版仕様の並列（DM-12。α版・β版開発指針と研究モック配下をアーカイブ推奨）、研究モックは研究画面と無関係（OG-123）
12. **表記の不統一**: フェーズ（仕様概要）と Wave（実装・システム概要）、解放ポイント（研究画面・ホーム）と研究ポイント（マスターデータ・作戦画面）、拍子の色がリズムUIとスキル入力進捗 UI で逆順（BT-15）
13. **リザルト後の戻り先**: ステージルールは作戦画面、リザルトはホーム、実装は「出撃元のシーン」（GS-05 未解消）
14. **タイトルのアイドル PV**: 40_ DM-14 は「90 秒無操作で再生・入力で中断」とするが、実装（#1878）は操作の有無に関係なく 90 秒ごとで、中断処理は無い
