# 共通ステータス {color="gray_bg"}

## HP（体力）

### 概要
- プレイヤー（敵）は体力制で敵（プレイヤー）の攻撃を食らうとHPが減少する
- HPが０になると死亡する

#### プレイヤー
- また、HPの残量を参照できるようにしてほしい

**使用用途**
- ステージクリア後のアチーブメント入手

- 最大HP：100（正本は `Assets/Level/Data/Master/Character/Player.asset` の `_maxHealth`）

#### 敵
- 敵は個体ごとにHPを所持している
- 敵の種類ごとの値は [[敵]] を正とする。

## 基礎攻撃力

### 概要
- 攻撃発生時のダメージ量計算に使用するステータス

#### プレイヤーの場合
- 基礎攻撃力：100（正本は `Assets/Level/Data/Master/Character/Player.asset` の `_baseDamage`）
- 実際のダメージは、基礎攻撃力に武器（拍子）ごとの倍率などを掛けて求める（[[ダメージ計算]] 参照）。
- TGS対応（2026-09-17）で、敵のHPとプレイヤーの攻撃力を10倍の桁に揃えた（基礎攻撃力 10→100、通常の敵のHP 100→1000）。与えたダメージに比例する回復・バリア、HPを消費するスキル、攻撃力を奪うスキルは、効果の比率が変わらないよう補正している。この値はMasterデータであり、製品版と体験版で共通である。【要確認: 製品版でもこの桁を追認するかを企画に】

#### 敵の場合
- 敵の種類と攻撃ごとの値は [[敵]] を正とする。

## クリティカル率

### 概要
- ダメージ量計算時に使用するステータス
- （クリティカル率）％の確率で攻撃がクリティカルになる

#### プレイヤーの場合
- ステータスの最大値：100
- ステータスの初期値：5（正本は `Assets/Level/Data/Master/Character/Player.asset` の `_criticalChance: 0.05`）

#### 敵の場合
- ステータスの最大値：100
- ステータスの初期値：0

## クリティカルダメージ

### 概要
- ダメージ量計算時に使用するステータス
- クリティカル時、（100+クリティカルダメージ）％分ダメージが上昇する。
- キャラクターではなく、武器（拍子ごとの攻撃定義）が持つ値である。

#### 敵＆プレイヤーの場合
- 初期値：50
  - プレイヤーの6武器はすべて150%（＝クリティカルダメージ50）である（正本は `Assets/Level/Data/Master/InGame/Battle/PlayerAttack_Beat*.asset` の `_criticalDamageMultiplier: 1.5`）。
  - スキルの効果でクリティカルダメージを上書き・補正する場合がある（[[スキル]] 参照）。
