## 詳細説明

### シナリオシステム

#### 進行の流れ
1. 背景の表示
2. 場面に登場するキャラクターの立ち絵の表示
左上に場所に関する記載
  - 場所の記載は未実装である
3. キャラクターの名前の明記
  1. キャラクターの立ち絵を目立たせる
・待機時には暗く表示を行い発現時に通常通りの表示を行う
  - 話者以外の立ち絵を自動で暗くする処理は未実装である。シナリオCSVのFade（黒）で手動で暗くする
4. シナリオ本文の表示の表示
  1. 本文は左から右に表示を行う
  2. アニメーションに関しては再生はどこからでも行う。
難しい場合はテキストを表示した最初に統一を行う。
5. テキストを表示しきったらプレイヤーの左クリックがあるまで待機
オートの場合は表示完了後2秒待機し次のテキストに移行
  - 送りの操作は、左クリック・Enter・ゲームパッドの東ボタン（Xbox B）である
  - 最後のテキストでも送りの入力を待つ

#### 画面イメージ図
  （既存の画像を残す）

#### イメージ図内機能説明
- スキップ
  - ボタンを押すことで、そのパートで再生されるシナリオをスキップする。
  - スキップする前に本当にスキップするかの確認画面を一度挟む。
  - スキップしたときは、すぐにシナリオの画面を閉じる
- オート
  - ボタンを押すことで、テキストの再生を自動で行いシナリオを自動進行させる。
ボタンのどこかを押すことによってオート再生は停止する。
  - 文字の表示を通常通り行いすべての文字を表示した2秒後に次のテキストに移行する。
  - オートが有効な間は、ボタンを水色で強調する
- 早送り
  - 押している間、文字の表示を速くする
- ログ
  - これまでの会話を振り返れる画面を表示する。
  - ボタンは配置しているが、表示の処理は未実装である【要確認: 実機で確認】
- UI削除
  - ボタンを押すことで表示されているUIをすべて非表示にする。
画面内のどこかを押すことによって元に戻る。
  - UIを戻した瞬間の入力では、テキストを送らない
- ツールバーの各ボタンには、アイコン・操作名（Skip / Auto / Log / Hide UI）・キーの案内を並べて表示する

#### 操作の割り当て

| 操作 | キーボード・マウス | ゲームパッド |
| --- | --- | --- |
| 送り | 左クリック / Enter | 東（Xbox B） |
| 早送り | 左Shift | 南（Xbox A） |
| ポーズ | Space | Start |
| スキップ | Esc | 北（Xbox Y） |
| オート | Ctrl | 西（Xbox X） |
| UI削除 | W | RB |

- 決定を東ボタン、取消を南ボタンにそろえる全体の方針に合わせている
- ゲームパッドの決定・キャンセルは設定で切り替えられるようにし、既定は海外式（決定＝南〈South〉、キャンセル＝東〈East〉）にする（[[設定画面]]、#2068）【要確認: シナリオの送り・早送りの割り当てをこの切り替えに合わせるかを企画に確認】

#### 送りの判定
- 文字の表示の途中で送りの入力をすると、次へは進まず、そのテキストを全て表示する
- 送りの入力、オートの待機時間の終わり、オートなどの切り替えのうち、先に来た1つだけで次へ進む。余った入力は次のテキストに持ち越さない
- マウスで画面上のボタンを押したときは送らない。キーボードとゲームパッドの送りは止めない
- 送ったときにボタンの選択状態を外し、決定の入力がボタンの操作と二重にならないようにする
- シナリオの開始時と終了時に、オート・ポーズ・早送り・UI削除の状態を元に戻す

#### 設定値

| 名前 | 値 | 単位 |
| --- | --- | --- |
| 文字の表示間隔（通常） | 0.03 | 秒/文字 |
| 文字の表示間隔（早送り） | 0.01（通常の3倍の速さ） | 秒/文字 |
| オートで次へ進むまでの待機 | 2 | 秒 |
| シナリオが終わってから画面を閉じるまで | 5 | 秒 |

（値の正本は `Assets/Level/Data/Master/Scenario/ScenarioSettingsAsset.asset`）
- 早送りの値は未実装である（#2076。現在のデータは0.025秒/文字）

#### 未実装の機能
次の機能は現在実装していない。
- ログの表示
- 話者以外の立ち絵の自動の暗転（シナリオCSVで手動で行う）
- 場所の表記
- テキストウィンドウを切り替えるコマンド
- シナリオ本文の多言語対応（ゲームの全表示を日英に対応させる。現在のシナリオCSVは1言語、#2067）

設定画面へのボタンは置かない（削除する、#2077）。

#### BGM
- シナリオ中は、シナリオ用のBGMに切り替える
- 今はホームと同じ曲を使う
- シナリオ用のBGMに切り替える仕組みは未実装である（#2069。現状はホームのBGMが流れ続ける）

## 仕様意図

バトルの独特なシステムや戦場の雰囲気に説得力を持たせ、よりゲームに没入感を与えるため。
