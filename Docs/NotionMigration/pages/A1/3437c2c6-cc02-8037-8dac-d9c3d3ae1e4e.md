# 仕様概要 {color="gray_bg"}
インゲームのリズムコマンドで使用されるUI。
4拍子や8拍子などのタイミングが視覚的に分かるように、QTEのシステムUIなどを参考に考案された。
現状の実装は、画面中央から左右対称に伸びる横型のゲージである（アーマードコア風）。

# 詳細説明 {color="gray_bg"}
- ▶ イメージ図（旧案：円形）
  （既存の画像を残す）
画面中央から左右対称に伸びる横型のゲージで、ゲージに沿って拍子ごとの範囲が配置される。
ゲージには1, 2, 3, 4, 6, 8拍子のそれぞれの範囲表示がされる。
ゲージの始め（中央）にはインジケーターも表示される。
仕組みとしてはDBDの発電機のようなタイミングゲームに近しい。
インジケーターが時間と共にゲージを沿うように移動し、プレイヤーがアクション（攻撃）を起こすと、インジケーターが入っている範囲表示の拍子が実行される。
- ▶ Dead By Daylight：発電機
  （既存の画像を残す）
アクションが起こされたらインジケーターは初期位置に戻り、また時間と共に移動する。
このような表示によって、視覚的にタイミングを掴む事ができ、
**リズムタイムアウト** も視覚的に表現できる。

- ゲージの全長は2小節で、[[リズム判定]] のリズムタイムアウトと同じ長さである。無入力の間もインジケーターは進み続け、タイムアウトすると中心から再び進む。
- ゲージの幅は画面の安全領域とCanvasの倍率から求め、1920×1080基準で左右に約100pxの余白を取る。
- 拍子の範囲の位置は [[リズム判定]] の判定範囲（`RhythmJudgmentDefinitionAsset`）と共通である。
- Just判定の範囲には黄色の帯（Just帯）を表示する。帯の中心は判定範囲と揃える。帯は判定範囲の幅に関係なく、一定の太さで描く（太さは現在の見た目と同じ）。
  - 現状の実装は、帯を判定範囲の1/3の幅で描いている（修正が必要）。
- 攻撃の硬直中で攻撃を押せない範囲は、ゲージを灰色で表示する（[[攻撃アクション]] の「攻撃の間隔」参照）。未実装である。
- コントローラーの操作ガイドは画面右上に置く（[[戦闘UI]] 参照）。
- Just成立時の演出は [[Just判定について]] の「演出（フィードバック）」を正とする。

### 敵をターゲットしていない時
- リズムUIは半透明にしない（ターゲットあり・なしとも透明度1）。照準のUIもそのままである。
- 色を指定するチュートリアルでは、課題の対象外の拍子を透明度0.15まで暗くする（[[チュートリアル]] 参照）。

### スキル入力ガイド
装備中のキルコードの次に入力すべき拍子を、ゲージの上に表示する。
- 装備中の各キルコードについて、まだ何も入力していなければ最初の拍子、入力の途中なら次の1拍子のアイコンだけを、ゲージ上のその拍子のJust位置に左右対称で表示する。
- キルコードのコマンドの次の対象の拍子にだけ色帯を付ける。色帯の幅は、その拍子のJust中心を含み、同じ色の範囲が続く区間に合わせる。
- ゲージ全体に拍子の色を常に表示する案は取り消した（PR #1907）。
- キルコードのクールダウン中は、ゲージで残り時間を示す。
- 入力が成功したときはアイコンを拡大（1.25倍）・回転（12°）させ（0.3秒）、進捗がリセットされたときは揺らす（強さ20、0.35秒）。演出値の正本は `Assets/Level/Data/Master/InGame/Skill/SkillInputProgressUIConfig.asset` である。

# 仕様意図 {color="gray_bg"}

クオンタイズの仕組みなどから、リズムの判定タイミングはプレイヤーのユーザーより音楽が優先され、感覚的にズレる事がある。
そのために、聴覚だけでなく視覚的な情報からリズムの判定タイミングを確認・予測できるようにする。
