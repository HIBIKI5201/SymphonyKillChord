#### 黒と灰色の円
**機能：**移動スティック
- 灰色の円は不動
- 黒い円を移動方向に向かって動かす
- スマホ（Android/iOS）でのみ表示する。PCでは表示しない

#### 青色の■
**機能：**コンボ数
- 連続で敵に攻撃を行った回数の表示を行う
表示タイミング
- コンボ数が3以上のときに表示し、2以下のときは表示しない
  - 現状の実装は4以上で表示している（実装の修正が必要）
- コンボ数が更新されるたびに、数字を小さく揺らす（5px・0.1秒）

#### 灰色の■
**機能：**ミッション
- ステージごとのクリアに必要な目標を常に表示する
  - メインミッション1つ
  - サブミッション（評価項目）は原則3つ（表示数はミッションに定義した数に合わせる）
を表示する
- 評価項目は状態ごとに表示を変える
  - 挑戦中：通常の表示
  - 成功：チェックを付け、文字に取り消し線を引く
  - 失敗：文字を暗くする
- ▶ イメージ図
  （既存の画像を残す）

#### ロックオン表示
**機能：**ロックオン表示
- 敵のロックオン状態を3段階で表示する
  - ロックオン中の敵：敵に重ねてレティクルと体力バーを表示する
  - ロックオン候補（ロックオンしていないときに、今攻撃したらロックオンされる敵）：黄色の小さな点を表示する
  - それ以外の画面内の敵：敵ごとにレティクルマーカーを表示する
- ロックオン対象の決め方は[[カメラワーク]]に記載する

#### 敵方向インジケーター
**機能：**画面外の敵の方向表示
- 次の条件をすべて満たす敵の方向に、プレイヤーの足元付近からマーカーを出す
  - 生存している
  - プレイヤーから20m以内にいる
  - 画面外にいる
- プレイヤーに近い順に最大3体まで表示する
- 表示・非表示は0.15秒でフェードする
- 現在のマーカーは仮のモデルであり、当面は仮のまま使う

#### 操作案内
**機能：**コントローラーの操作案内
- 戦闘中のみ表示する（開始演出中とリザルトでは表示しない）
- 表示する割り当ては次の通りである

| ボタン | 操作 |
| --- | --- |
| LT | ロックオン／解除 |
| RT | 攻撃 |
| LB | ロックオン対象の切り替え（左） |
| RB | ロックオン対象の切り替え（右） |
| Lスティック | 移動 |
| Rスティック | 視点 |
| Menu | ポーズ |
| B | 攻撃 |
| A | 回避 |

- 文言は日本語と英語に対応する
- ボタンの絵は、接続しているゲームパッドの種類によらずXboxの表記で固定する
- キーボード用の案内は無い【要確認: キーボード用の案内が要るかを企画に確認】
- 表示位置は画面右上である【要確認: 最終的な位置を実機で確認】

#### ダメージ表記
**機能：**敵に与えたダメージの数値表示
- 敵に攻撃が命中したとき、ダメージ量を数値で表示する
- 表示の種類
  - 通常
  - ジャスト：Just判定の攻撃が命中したとき
  - クリティカル：クリティカルが発生したとき、通常またはジャストの表示に重ねる
- 種類ごとに色・フォント・背景を変える【要確認: 各種類の色を実機で確認】
- 表示は1.5秒間その場に残る
- キルコード専用の表示の種類は用意されているが、現在は使っていない【要確認: キルコード用の表示を使うかを企画に確認】
