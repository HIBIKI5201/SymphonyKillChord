## 詳細説明
セーブデータのカテゴリーは主に七種類ある。
- ステージの進行状況
  - どこまでステージがクリアされているかIDを記録する
  - ステージごとに、達成したサブミッション（評価項目）のIDを記録する（複数回のプレイで達成したものをまとめて残す）
- スキルツリーの進捗内容
  - どこまでスキルツリーがクリアされているかIDを記録する
  - 解放したキルコードのIDを記録する
- キルコードの装備と強化の内容
  - どのキルコードが装備されているか種類や順番を記録する
  - 各キルコードごとにレベルを記録する
- チュートリアルの進行状況
  - 未開始 / オープニングシナリオ完了 / バトルチュートリアル完了 / ホームチュートリアル開始 / 完了 の5段階で記録する
- ゲーム内リソース
  - 解放ポイント・改造ポイントの所持数を記録する
- 音量設定
- 環境設定

### 音量設定

| 名前 | 範囲 | 既定値 |
| --- | --- | --- |
| BGM | 0〜10 | 5 |
| SE | 0〜10 | 4 |
| ボイス | 0〜10 | 8 |

### 環境設定

| 名前 | 範囲 | 既定値 |
| --- | --- | --- |
| 解像度 | 端末が対応する解像度 | 初回はモニターの解像度（取得できないときは1920×1080） |
| 画面モード | フルスクリーン / ウィンドウ | フルスクリーン |
| 画質 | Very Low〜Ultra | PCはUltra（5）、スマホはMedium（2）。現状の実装は共通でHigh（#2062） |
| 明るさ | 0〜10 | 5 |
| 言語 | 日本語 / English | 日本語 |
| 振動 | 強い / 弱い / オフ | 強い |
| リズム判定タイミング | -0.30〜+0.30秒 | 0秒 |

（環境設定の既定値の正本は `Assets/EnvironmentSettingsDefaultAsset.asset`。各項目の詳細は[[設定画面]]に記載する）

### データリセット時の扱い
- タイトルのデータリセットでは、セーブデータをすべて消去する
- 音量設定、言語、リズム判定タイミングはリセットの前の値を保持する
  - 現状の実装は音量設定だけを保持し、言語とリズム判定タイミングは既定値に戻る（修正予定）
- それ以外の環境設定は保持せず、既定値に戻る
- 体験版の終了画面でセーブデータを削除するときも、言語と音量設定は残す
  - 現状の実装は言語と音量設定も含めて全て削除する（修正予定）

### 保存形式
- 製品版では、セーブデータを暗号化して保存する
  - 未実装。現状は暗号化せずにJSONのまま保存している
- セーブデータの読み書きは、フレームワーク側のローダー（`JsonUtilitySaveDataLoaderStrategy`、`Assets/Resources/SymphonyFrameWork/SaveDataConfig.asset` で指定）を使う
  - 使っていない自前のローダー（`PersistentFileSaveDataLoaderStrategy`）は消す（#2061）

## 仕様意図

拡張可能なようにデータをカテゴリー分けして管理する。

### 却下・保留した案

- 平文の JSON のまま保存する: 製品版では採らない。暗号化する（決定 No.24）。研究ブランチでは暗号化を作ったが（PR #852）、現行の保存には入っていない。
- データリセットで音量だけを残し、言語・リズム判定タイミングを消す（現行の実装）: 採らない。言語とリズム判定タイミングも残す（決定 No.25）。
- 体験版の終了画面でセーブデータを全部消す（現行の実装）: 採らない。言語と音量は残す（決定 No.26）。
- 自前のセーブのローダー（`PersistentFileSaveDataLoaderStrategy`）: 採らない。フレームワーク側のローダーを正とし、自前のものは消す（決定（八幡）R42）。
- セーブデータのクロスセーブ（プラットフォーム間の共有）: 採らない。プラットフォームごとに設定の内容が変わるため（Discord 進捗共有「セーブデータの暗号化」、2026-06-28）
- データリセットのときにチュートリアルをスキップするかをプレイヤーに選ばせる: 企画の希望として出たが、採否の記録なし。保留（Discord 進捗共有「アウトゲーム」、2026-06-28）
