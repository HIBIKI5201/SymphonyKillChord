## 仕様概要
インゲームで表示されるUIについて。
現行（体験版 TGS 2026 時点）のHUDは次の要素で構成される。
- HPの数値（現在/最大）とHPバー
- コンボ数
- メインミッションと評価項目（サブミッション）
- スキルリストとスキル入力の進捗
- クロスヘアとリズムガイド
- ロックオン中の敵の体力（レティクル＋体力バー）と、ロックオン候補の表示
- 画面外の敵の方向マーカー
- コントローラーの操作案内
- 体験版タイマー（体験版のみ）

各要素の詳細は[[戦闘UI]]と[[リズムUI]]に記載する。
（HUDの実体は `Assets/Level/Prefabs/Master/InGame/InGameCanvas.prefab`）

## 仕様意図
インゲーム中に必要なUIだけを置く。
視覚情報が多すぎるとリズムなどのゲームプレイに集中がそがれてしまうため、構成要素は最小限にする。

#### 表示タイミング
ゲームの状態ごとのHUDの表示は次の通りである。

| 状態 | HUDの表示 |
| --- | --- |
| ロード中 | 表示しない（ロード画面） |
| ステージ開始演出 | 表示しない（演出の開始でHUDのCanvasを非表示にする） |
| 戦闘中 | 表示する |
| クリア・ゲームオーバー演出 | 【要確認: 演出中のHUD表示を実機で確認】 |
| リザルト | 表示しない（HUDのCanvas群を無効化する） |
| ポーズ中 | 表示したまま、ポーズウィンドウを重ねる |

#### ポーズ画面
- ポーズの操作
  - キーボードはEsc、ゲームパッドはStart（Menu）で開く
  - もう一度同じボタンを押すか、UIのキャンセル操作で閉じてゲームに戻る
- ポーズできないタイミング
  - ステージ開始演出の再生中
  - 戦闘終了からリザルト表示までの間
- ポーズ中の挙動
  - ゲーム内の時間を止める（弾幕も停止する）
  - BGMを一時停止する
  - 入力はポーズ画面の操作だけを受け付ける
- ボタン
  - リスタート（開いたときの初期選択）：ステージを最初からやり直す
  - タイトルへ戻る
- 未実装の要素
  - HUD上のポーズボタン、オプション、ミッションの同時表示、再開時のカウントダウンは実装していない【要確認: 製品版で実装するかを企画に確認】
