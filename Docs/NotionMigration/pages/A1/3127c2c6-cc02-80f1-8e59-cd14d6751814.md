## 仕様概要
TGSは回転率のためにプレイ時間を短く区切る。
体験版（TGS 2026）のプレイ時間は全体で7分（420秒）である。
体験の範囲は、導入ストーリー（第1話前半）→ バトルのチュートリアル → アウトゲーム（ホーム画面）→ 作戦画面の3ステージとする。
当初の体験版方針では、プレイ時間5分を目安にし、導入ストーリーとチュートリアルのみを体験させるとしていた（[当初の体験版方針](#当初の体験版方針)を参照）。

## 詳細説明

### ゲームルール
[[チュートリアル]]
TGS版はタイトル画面を開いた状態で待機する。
体験版はAndroidとWindowsの2つでビルドする（#2079）。TGS 2026 の出展版はPC（Windows）だけだった（当初の体験版方針はPCとモバイル一つづつ）。
体験版の流れは次の通りである。
1. タイトル画面で開始の操作をする（PCは「Press [B] To Start」）
2. 導入ストーリー（第1話「ZeroDivide」の前半）が再生される
3. ストーリーの後、自動でバトルのチュートリアルに出撃する
4. チュートリアルの後、ホーム画面で各ボタンの説明を受ける。ここからホームの制限時間が始まる
5. 作戦画面でステージ1 → ステージ2 → ステージ3の順に出撃する
6. 全体の制限時間が切れるか、ステージ3をクリアしてリザルトを閉じると、終了画面に移る
7. 終了画面でセーブデータを削除し、攻撃の入力でタイトル画面に戻る

- タイトルでは開始ボタンのほかに、設定・データリセットも操作できる

### 時間制限
体験版には全体とホームの2つの制限時間がある。

| 名前 | 値 | 単位 | 正本 |
| --- | --- | --- | --- |
| 全体の制限時間 | 420 | 秒 | `Assets/Level/Data/Demo/DemoExperienceConfig.asset` |
| ホームの制限時間 | 90 | 秒 | 同上 |
| 全体の制限時間を始める地点 | チュートリアル | — | 同上（シナリオ／チュートリアル／ホームから選ぶ） |

- 全体の制限時間
  - 設定した地点（既定はチュートリアル戦闘の読み込みが終わった時点）から数え始める。それより後から再開した場合は、再開した地点から数える
  - 切れたら通知を出し、戦闘中であってもすぐに終了画面へ移る（リザルトを待たない）
  - 読み込み中、ストーリーからの出撃中、通知の表示中は、終わるまで待ってから移る
- ホームの制限時間
  - ホームのチュートリアルが始まってから有効になる
  - アウトゲームにいる間だけ進み、アウトゲームに入るたびに0に戻る
  - 切れたら通知を出し、作戦画面で出撃先のステージを選んだ状態にして、出撃以外の操作（戻る・装備変更・設定・別ステージの選択）を禁止する
  - 出撃先は、解放済みのステージのうち最も先にあるものを自動で選ぶ
  - 全体の制限時間と同時に切れたときは、全体を優先する
- どちらもポーズ中も進む
- タイトル画面に戻ったら止めて、最初からやり直す

### 通知
次のときに、画面に通知を出す。

| きっかけ | 文言（日本語） | 文言（英語） |
| --- | --- | --- |
| 全体の制限時間切れ | お時間になりました。体験版を終了します。 | Time is up. The demo will now end. |
| ホームの制限時間切れ | ホームタイマーが終了しました。ミッションに移動します。 | The home timer has expired. Moving to the mission. |
| セーブデータのリセット | セーブデータをリセットしました。 | Save data has been reset. |

- 通知は3秒表示し、0.5秒でフェードアウトする
- 通知の間もゲーム内の時間は止めないが、入力と次の画面への移動は通知が終わるまで待つ
- セーブデータのリセットの通知は、タイトル画面から手動でリセットしたときだけ出す。終了画面での自動削除では出さない

### ステージ構成
体験版の作戦画面のステージは次の通りである。

| ステージ | 表示名 | 内容 |
| --- | --- | --- |
| scenario_stage_01 | 第1話「ZeroDivide」 | 導入ストーリー（前半） |
| stage_Tutorial | チュートリアル | バトルのチュートリアル |
| stage_01 | 1 | 敵の全滅 |
| stage_02 | 2 | 耐久 |
| stage_04 | 3 | 敵の全滅（体験版の最終ステージ） |

- 第1話の後はチュートリアルに自動で進む。それ以降は作戦画面で選んで出撃する
- 正本は `Assets/Level/Data/Demo/OutGame/StageSelect/StageTreeAsset.asset` である

### 終了画面
- 終了画面では次の順に進む
  1. 体験版の終わりのムービー（9.5秒）を再生する
  2. タイトルのイラストと、ホームページへのQRコードを表示する
  3. 攻撃の入力でタイトル画面に戻る
- 時間の経過で自動的にタイトルへ戻ることはしない
- QRコードの遷移先はホームページである（当初の体験版方針はストアページ）

| 名前 | 値 | 単位 |
| --- | --- | --- |
| ムービーの長さ | 9.5 | 秒 |
| 案内の表示にかける時間（フェードイン） | 1 | 秒 |
| 案内の表示から入力を受け付けるまで | 1 | 秒 |
| 案内の表示からBGMのフェードアウトを始めるまで | 10 | 秒 |
| BGMのフェードアウト | 3 | 秒 |

（値の正本は `Assets/Level/Data/Demo/DemoEndSequenceConfig.asset` と `DemoEndMovie.playable`）

### セーブデータの削除
- 終了画面に入ったとき、セーブデータを削除する。キルコードの解放・装備、ステージの進行、チュートリアルの進行は初期状態に戻す
- 言語と音量の設定は削除せずに残す
  - 現状の実装はセーブデータを全て削除し、言語と音量の設定も初期値に戻る（修正予定）
- タイトルから手動でリセットしたときに残すものは[[タイトル画面]]に記載する
- タイトル画面に戻ったときに、初期キルコード（スキル0・スキル13）を装備した状態に戻す

### タイマー表示
- 画面の左下に、全体とホームの残り時間を表示する
  - 文言は「全体  MM:SS」「ホーム  MM:SS」で、秒は切り上げて表示する
  - ホームの行は、アウトゲームでホームの制限時間が有効なときだけ表示する
  - 文言は日本語と英語に対応させる。未実装である（#2067。現状は英語の設定でも日本語で表示する）
- 画面ごとの表示位置（画面の下端からの高さ）

| 画面 | 下端からの高さ |
| --- | --- |
| ホーム | 80 |
| 作戦 | 80 |
| 研究 | 448 |
| 改造 | 8（左端から320） |
| 設定 | 160 |
| 戦闘 | 24 |
| リザルト | 24 |
| シナリオ | 400 |

- 始まる前、タイトル画面、終了画面では表示しない

### 展示中のタイトル画面
- タイトル画面では、90秒ごとにPVを再生する。操作の有無による判定と、入力でPVを止める処理は無い
- 開始の操作は、PCが「Press [B] To Start」、スマホが「Tap to Start」である

### 当初の体験版方針
2026年6月時点の体験版の方針は次の通りだった。現在の体験版（TGS 2026）の仕様は、このページの上の節に記載する。
- プレイ時間5分を目安にし、導入ストーリーとチュートリアルのみを体験させる
- 想定端末はPCとモバイル一つづつとする
- タイトルでは始めるボタンのみが押せる
- 始めると通常版と同じく導入ストーリーが再生される
- ストーリー後にバトルのチュートリアルが発生する
- バトルチュートリアル終了後は暗転し、ストアページへのQRコードが表示された専用画面に遷移する
- 時間経過かつ入力によって、タイトル画面に戻る

## 仕様意図

TGSではプレイ時間を短く抑える必要があるため、コアメカニクスのみを重点的に体験させる必要がある（当初は 5 分。TGS 2026 の出展版は全体 7 分）。
TGSではコアメカニクスを体験してもらうことに全てをささげる（フォーラム「TGSのゲームフロー」）。

体験版の範囲を第一話から始めて通常戦闘まで広げたのは、8/23 の体験版デモ本番と TGS 本番に向けて、体験版の開発状況の遅れを週単位で把握できるようにするためである（フォーラム「体験版マイルストーン」）。
