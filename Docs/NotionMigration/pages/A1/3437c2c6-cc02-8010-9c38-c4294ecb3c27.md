#### 画面ごとの遷移の種類
画面を切り替えるときの遷移の種類は、画面ごとに決まっている。
- 置き換え（Replace）：今の画面を閉じて次の画面を表示し、戻れるように履歴に残す
- 重ねる（Overlay）：今の画面を残したまま、上に次の画面を重ねて表示する
- リセット（Reset）：履歴を消してから次の画面を表示する

| 画面 | 遷移の種類 | 履歴に残すか |
| --- | --- | --- |
| ホーム | リセット | 残さない |
| 作戦 | 置き換え | 残す |
| 研究 | 置き換え | 残す |
| 改造 | 置き換え | 残す |
| 設定 | 重ねる | 残す |
| タイトル | リセット | 残さない |
| タイトルのオプション | 重ねる | 残す |
| クレジット | 置き換え | 残す |

（正本は `Assets/Level/Data/Master/OutGame/Screen/OutGameScreenRuleData.asset` と `TitleScreenRuleData.asset`）

#### 戻る操作
- 戻る操作をすると、履歴から1つ前の画面に戻る
- 履歴が空のとき（ホーム画面など）は何もしない
