#### キルコードの効果
- 3拍子の通常攻撃を行う。
  - その通常攻撃が当たった敵と、その敵の一定の半径（InfectionRange）以内にいる敵に対して
伝染状態を付与する。
(伝染が一定回数（InfectionTriggerCount）起きると効果が消滅する。)
**伝染状態について**
効果内容
- 攻撃を受けたときすべての伝染状態の敵に対して、攻撃を受けた敵の被ダメージに一定の倍率（InfectionDamageRate）をかけたダメージを与える。
  - 他の伝染状態の敵に与えたときのダメージ判定は通常攻撃を受けたときのダメージ判定と同じものを行う。
（クリティカル判定やジャスト判定も行いその倍率もかかる）
  - 「伝染」効果は、一連の伝染フローにつき**1回のみ**発生する。
  - 伝染から**さらに伝染する（連鎖）ことはしない**。
- 3拍子の通常攻撃は、コマンドの最後の入力（3拍子のリボルバー）の通常攻撃であり、ダメージも出る
- 伝染状態の敵にもう一度付与した場合は、新しい効果に置き換える
- レベルが上がるごとに伝染ダメージの割合が上がる
- クールダウンは 1 小節である
- 値（Lv0 の現在値とレベルによる成長）はマスターデータ（[[敵・ボスのステータス]] の「キルコードの効果」）を正とする。仕様には効果の説明だけを書く
- 正本: `Assets/Level/Data/Master/Skill/Templates/SkillData08.asset` の `_effectParameters`
