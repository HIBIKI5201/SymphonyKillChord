## **仕様意図**
ボタンが少なくタップすることが多いゲームのため、
単調な動作になり飽きが来やすい。
そのため、単調な動作に意味を持たせ飽きを来させないようにするため。

それぞれのスキルは、ZeroDivide のキャラクターや、それに付随するモチーフであるセフィラなどのイメージから効果を決める。

#### 装備時の条件について
複数種類のスキルを任意に装備できるシステムでは、装備したスキルのコマンドの内容が被って同時に発動してしまう事が有り得る。
その対策として、絶対に同時には発動しないような仕組みにする。

### **スキルの発動条件**
各種スキルには発動するための条件が存在する。
スキルの条件はリズムパターンと入力の種類から成る。
スキルの条件は特定のコマンドを入力すること。
コマンドには、リズム判定（[[リズム判定]] ）とアクション種類の判定がある。
リズム判定は、特定の順番でリズムを刻むこと。
アクション種類は攻撃や回避などのアクションの種類を入れる事。
例：
”4 → 4 → 8 → 8”というリズムのコマンドなら、四拍子を二回押したのちに八拍子を二回押すと
リズム判定に成功し発動できる。
”最後は回避”というコマンドなら、コマンドの最後に回避を使用するとアクション種類に成功し発動できる。
※現状、アクション種類の判定は未実装である。リズムを刻むのは攻撃だけであり、コマンドは拍子の並びだけで照合する。
【要確認: アクション種類の判定を実装するか、仕様から外すかを企画に】
また一部のスキルには、以下の条件も関わる
- 自身のHPが〇〇％以下になった際（一度のみ）（未実装）
- 的中した敵の対数によって能力が強化される（未実装）
【要確認: HP 条件と的中数による強化を仕様として残すかを企画に】

#### **スキルの種類**
スキルの効果はジャンルがあり、そのジャンルは3種類ある。
- **攻撃**
敵に直接、ダメージを与えるジャンル
  - 敵一体に攻撃力○○％の強力な一撃攻撃
  - 敵一体に攻撃力○○％の強力な〇撃攻撃
  - 着弾後半径〇メートルに攻撃力○○％の強力な一撃攻撃
- **バフ**
PC（プレイヤーキャラ）にプラスの状態を付与するジャンル
  - ｎ秒間、攻撃力を〇％上昇
  - ｎ秒間、与えたダメージの〇％分HPを回復する（上限あり）
- **デバフ**
敵にマイナスの状態を付与するジャンル
  - ｎ秒間、攻撃対象の攻撃力を減少
  - ｍ秒間、攻撃対象の受けるダメージを1.〇倍上昇

#### 条件
- コマンドの最後のノーツが共通しているスキルは同時に装備できない。
例えば
スキルαのコマンドは A A B B
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できない。

スキルαのコマンドは A C C
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できる。
※現状、この制限は編成時に検証していない（未実装）。最後のノーツが共通するスキルも同時に装備でき、1 回の入力で複数のスキルのコマンドが一致した場合は、優先順位を付けずに全部発動する。
【要確認: 同時装備の制限を実装するか、「一致したスキルは全部発動する」を仕様にするかを企画に】

### 発動判定
- スキルごとに、コマンドの長さの 2 倍の数だけ直近の攻撃入力（拍子）を記録する
- 直近の入力の並びがコマンドと完全に一致した時点で発動する
- 無入力のまま 2 小節経つと（リズムタイムアウト）、記録した入力は消える（[[リズム判定]] を参照）
- 発動したスキルは、そのスキルの記録を消してクールダウンを始める
- クールダウン中のスキルには、その間の入力を記録しない
- 1 回の入力で複数のスキルのコマンドが一致した場合は、全部発動する
- コマンドは一致したが対象が見つからない場合は、そのスキルの記録だけを消す。クールダウンは消費しない
- チュートリアルでは、ステップごとにスキルの発動を止めることがある（[[チュートリアル]] を参照）
- 一時停止を挟んでも判定がずれないよう、入力の時刻はゲーム時間と音楽の再生時間の 2 つで記録する

### クールダウン
- スキルを発動してから 1 小節の間は、同じスキルを発動できない（BPM84 で約 2.86 秒）
- 現在は全スキルが 1 小節である。値はスキルごとに「分子 / 分母 × 1 小節」で設定できる
  - 正本: `Assets/Level/Data/Master/Skill/Templates/SkillData*.asset` の `_cooldownNumerator` / `_cooldownDenomimator`
- クールダウンは現実の時間で数え、リズムタイムアウトしても残る
- リズムUI にクールダウンの表示がある（[[リズムUI]] を参照）

### スキル発動時の通常攻撃
コマンドの最後の入力は通常攻撃でもある。
スキルごとに、その通常攻撃のダメージを出すかどうかが決まっている。
- 通常攻撃のダメージを出す: スキル0・2・4・6・8・9・10
- 通常攻撃のダメージを出さない（スキルの攻撃に置き換える）: スキル1・3・5・7・13
- 正本: `Assets/Level/Data/Master/Skill/Templates/SkillData*.asset` の `_skillNormalAttackDamagePolicy`
