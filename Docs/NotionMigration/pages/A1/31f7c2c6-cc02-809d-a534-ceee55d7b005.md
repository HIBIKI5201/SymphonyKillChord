### **キルコードの発動条件**
各種キルコードには発動するための条件が存在する。
キルコードの条件はリズムパターンと入力の種類から成る。
キルコードの条件は特定のコマンドを入力すること。
コマンドには、リズム判定（[[リズム判定]] ）とアクション種類の判定がある。
リズム判定は、特定の順番でリズムを刻むこと。
アクション種類は攻撃や回避などのアクションの種類を入れる事。
例：
”4 → 4 → 8 → 8”というリズムのコマンドなら、四拍子を二回押したのちに八拍子を二回押すと
リズム判定に成功し発動できる。
”最後は回避”というコマンドなら、コマンドの最後に回避を使用するとアクション種類に成功し発動できる。
※アクション種類の判定は未実装である。リズムを刻むのは攻撃だけであり（回避はリズムを刻まない）、現状のコマンドは拍子の並びだけで照合する。
【要確認: 回避がリズムを刻まないため、「最後は回避」の例をこのままにするかを企画に】
また一部のキルコードには、以下の条件も関わる
- 自身のHPが〇〇％以下になった際（一度のみ）（未実装）
- 的中した敵の対数によって能力が強化される（未実装）

#### **キルコードの種類**
キルコードの効果はジャンルがあり、そのジャンルは3種類ある。
- **攻撃**
敵に直接、ダメージを与えるジャンル
  - 敵一体に攻撃力○○％の強力な一撃攻撃
  - 敵一体に攻撃力○○％の強力な〇撃攻撃
  - 着弾後半径〇メートルに攻撃力○○％の強力な一撃攻撃
- **バフ**
PC（プレイヤーキャラ）にプラスの状態を付与するジャンル
  - ｎ秒間、攻撃力を〇％上昇
  - ｎ秒間、与えたダメージの〇％分HPを回復する（上限あり）
- **デバフ**
敵にマイナスの状態を付与するジャンル
  - ｎ秒間、攻撃対象の攻撃力を減少
  - ｍ秒間、攻撃対象の受けるダメージを1.〇倍上昇

### キルコード装備時

#### 編成個数
初期時
- キルコードを2個　編成可能
研究（スキルツリー）を進行していくと（6個解放後の特別なノードを解放時）
- キルコードを3個　編成可能
※編成枠を増やす条件の正本は [[研究画面]] とする。

#### 条件
- コマンドの最後のノーツが共通しているキルコードは同時に装備できない。
例えば
キルコードαのコマンドは A A B B
キルコードβのコマンドは A C B
この場合はこの二つを同時に装備できない。

キルコードαのコマンドは A C C
キルコードβのコマンドは A C B
この場合はこの二つを同時に装備できる。
※この制限は未実装である（編成時に検証していない）。現状は最後のノーツが共通するキルコードも同時に装備でき、1 回の入力で複数のキルコードのコマンドが一致した場合は、優先順位を付けずに全部発動する。

### 発動判定
- キルコードごとに、コマンドの長さの 2 倍の数だけ直近の攻撃入力（拍子）を記録する
- 直近の入力の並びがコマンドと完全に一致した時点で発動する
- 無入力のまま 2 小節経つと（リズムタイムアウト）、記録した入力は消える（[[リズム判定]] を参照）
- 発動したキルコードは、そのキルコードの記録を消してクールダウンを始める
- クールダウン中のキルコードには、その間の入力を記録しない
- 1 回の入力で複数のキルコードのコマンドが一致した場合は、全部発動する（現状。同時装備の制限は未実装）
- コマンドは一致したが対象が見つからない場合は、そのキルコードの記録だけを消す。クールダウンは消費しない
- チュートリアルでは、ステップごとにキルコードの発動を止めることがある（[[チュートリアル]] を参照）
- 一時停止を挟んでも判定がずれないよう、入力の時刻はゲーム時間と音楽の再生時間の 2 つで記録する

### クールダウン
- キルコードを発動してから 1 小節の間は、同じキルコードを発動できない（BPM84 で約 2.86 秒）
- 現在は全キルコードが 1 小節である。値はキルコードごとに「分子 / 分母 × 1 小節」で設定できる
  - 正本: `Assets/Level/Data/Master/Skill/Templates/SkillData*.asset` の `_cooldownNumerator` / `_cooldownDenomimator`
- クールダウンは現実の時間で数え、リズムタイムアウトしても残る
- リズムUI にクールダウンの表示がある（[[リズムUI]] を参照）

### キルコードのモーション中
- キルコードのモーション中は、移動・攻撃の操作をロックする。未実装である（現状はモーションを再生するだけで、操作を制限しない）

### キルコード発動時の通常攻撃
コマンドの最後の入力は通常攻撃でもある。
キルコードごとに、その通常攻撃のダメージを出すかどうかが決まっている。
- 通常攻撃のダメージを出す: スキル0・2・4・6・8・9・10
- 通常攻撃のダメージを出さない（キルコードの攻撃に置き換える）: スキル1・3・5・7・13
- 正本: `Assets/Level/Data/Master/Skill/Templates/SkillData*.asset` の `_skillNormalAttackDamagePolicy`
- キルコードの発動では [[コンボについて]] のコンボを 0 に戻さない。通常攻撃のダメージを出さないキルコードでも同じである
  - 現状: 通常攻撃のダメージを出さないキルコードが発動した攻撃では、コンボが 0 に戻る（実装の不具合）
【要確認: 現状の組み合わせを仕様として追認するかを企画に（フォーラム「スキルのコマンドの発動重複対策」の初期案は「敵に攻撃するスキルは最後の攻撃を出さない、バフ・回復は出す」であり、スキル0が合わない）】

## **仕様意図**

ボタンが少なくタップすることが多いゲームのため、単調な動作になり飽きが来やすい。
そのため、単調な動作に意味を持たせ、飽きを来させないようにする。

それぞれのキルコードは、ZeroDivide のキャラクターや、それに付随するモチーフであるセフィラなどのイメージから効果を決める。

#### 装備時の条件について
複数種類のキルコードを任意に装備できるシステムでは、装備したキルコードのコマンドの内容が被って同時に発動してしまうことがあり得る。
キルコードの効果やアニメーションによっては、同時に発動すると問題が起きる。
その対策として、絶対に同時には発動しない仕組みにする（コマンドの最後のノーツが共通するキルコードは同時に装備できない）。
この仕組みは未実装である（現状は同時に一致したキルコードがすべて発動する）。
