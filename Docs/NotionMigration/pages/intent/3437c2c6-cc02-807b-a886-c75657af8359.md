### 却下・保留した案

- ミュートボタンとチェックボックス: 本ページとフォーラム「アウトゲームUIの構成要素」に挙げられているが、実装は使っていない（選択肢は「< 値 >」形式、数値はスライダー）。使わないと決めた記録は無い（反映項目 OG-205）
- Key（キー設定）のカテゴリ: PR #816 で加えたが、PR #1391 でサウンド・システムの 2 カテゴリに作り直した。キー設定を外した理由の記録なし
- 「既定値に戻す」を画面に出すか: 処理はある（PR #1648）が UI が無い。保留（要企画確認、反映項目 OG-205）
- 設定画面をホーム以外（作戦・改造・研究）から開けるようにするか: 保留（要実機確認、反映項目 OG-206）
- 画質の初期値をプラットフォーム別にするか（現在は全プラットフォーム High）: 保留（要企画確認、反映項目 OG-227）
- 設定画面とコンフィグの役割分担: 保留（要企画確認、反映項目 OG-222）。既存の原稿では「設定画面 = 画面の仕様、コンフィグ = 項目の方針」として書いている
