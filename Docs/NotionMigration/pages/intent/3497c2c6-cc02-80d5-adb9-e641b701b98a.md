- 体力 500・三方向 30°: 2026-09-22 に実装値（HP 5000・45°）を正とし、数値はマスターデータへ移した（決定 No.17）。500 や 30° を決めた理由の記録なし
- 防御力 20%・スタン値 50: フォーラムの結論にあったが、本ページからは外れている。外した理由の記録なし（3437c2c6-cc02-8045-b176-d5d0601504ab）
- 攻撃ごとに拍を分ける（4 拍子 3 拍目 / 3 拍子 2 拍目 / 2 拍子 1 拍目）: 実装は 3 種とも同じ拍。分けるかは【要確認】（pages/A1/3497c2c6-cc02-80d5-adb9-e641b701b98a.md）
- 体力が半分を切ったときの建物破壊演出: 実装は未接続。実装するかは【要確認】（同上）
- ボスの HP でウェーブが変化する: 指示だけで未完了のまま保留（38f7c2c6-cc02-8001-a66b-cea4bc8d2720）
- クリティカルでボスが硬直する: 仕様に無い。実装から削除する（決定 No.13）
