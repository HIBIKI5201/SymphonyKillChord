## 仕様意図

インゲーム中に必要なUIだけを置く。
視覚情報が多すぎるとリズムなどのゲームプレイに集中がそがれてしまうため、構成要素は最小限にする。

### 却下・保留した案

- ロックオン時だけ敵の身体の中央に小さな HUD を出し、リズム UI を Symphony の横にコンパクトに置く案: 却下。理由の記録なし。提案の理由は「現状の HUD が大きく、敵に被ると見づらい」「リズム UI を目で追いやすくしたい」（フォーラム「ロックオンHUDについて」3527c2c6-cc02-8056-ab65-c8353f7590f0）。
- UI のトンマナを黒・白・暗い灰色・赤の 4 色にし、彩度を減らす案: 却下。理由の記録なし。提案の理由は「音楽に乗って戦うことが最も重要なので、視覚的な負担を減らしたい」（フォーラム「UIトンマナ修正」3787c2c6-cc02-80df-9ff2-f6503823b367）。
- ジャストの表示色、ダメージ表記（クリティカルの背景、ジャスト時の文字色）の更新: 検討中のまま（フォーラム「UI周りの更新」3cc7c2c6-cc02-80b5-a56c-ceeffdc3a6e3）。
- ポーズ画面の HUD 上のポーズボタン・オプション・ミッション表示・再開時カウントダウン: 未実装のまま仕様に残す（議事録「インゲームUI会議」3497c2c6-cc02-80ca-a3ce-c9c6efa93af8、決定（八幡）No.34）。
- 入力履歴 UI（3 小節分を画面上部に表示）: 会議で話し合われたが、採否の記録なし（議事録「インゲームUI会議」）。
