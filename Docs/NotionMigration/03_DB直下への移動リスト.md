# 仕様リスト・システムリストの詳細ページを DB 直下へ移す

作成日: 2026-09-22

## 決定（2026-09-22 八幡さん）

「仕様概要」と「システム概要」の DB（仕様リスト・システムリスト）では、行の下に子ページが置かれている。そのうち**階層化のためではなく、詳細仕様として使われているページだけ**を DB の直下（DB の行）へ移す。元の位置には、そのページへのリンクを置く。
DB の検索とフィルタで詳細仕様を見つけやすくするのが目的である。

## 移し方

1. Notion 上で、子ページを DB へ移動する（ページの「移動」→ 対象の DB）。**移動しても page id は変わらない**ので、キャッシュマップ・原稿・リンクはそのまま使える。
2. 移した行に、DB のプロパティを入れる。
   - カテゴリー: 親の行と同じ値
   - **種類: 詳細**（親の行は「概要」）
   - **親仕様: 親の行**（同じ DB へのリレーション）
   - ほかのプロパティ（状態・適用範囲・値の正本・キャッシュ対象・関連 Issue）は `02_キャッシュ運用とNotion記述規約.md` §5.5 のとおり
3. 親の行の本文で、子ページのブロックがあった位置に、移したページへのリンク（ページメンション）を置く。見出しや並び順は変えない。
4. DB の既定のビューは「種類 = 概要」で絞り込む。詳細ページを一覧に並べないためである。検索は全行が対象になる。
5. 移し終えたら、表の「状態」欄に `済 <日付> <担当者>` を書く。

NotionMarkdownWriter はページの移動と DB のプロパティを扱えないので、Notion 上で手作業する。2 つの DB は書き込み許可範囲の中にあるので、本文の修正（リンクの置き換え）はツールでもできる。

**移す前に:** 先に `pages/` の原稿を適用する（段階 2）。原稿は子ページの位置を前提に書いてあるので、移動後に適用すると、子ページのブロックとリンクが二重になる。
