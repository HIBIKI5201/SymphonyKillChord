# ゲージ注視の改善案 試遊ビルドの確認方法

議事録「2026-10-30 戦闘中にゲージばかり見る問題」の改善案を、案ごとにON/OFFして試すための開発ビルド（Windows）です。
プランナーが遊んで、どの案を採用するかを決めるために使います。製品版には入りません。

## 起動と切り替え

1. `SymphonyKillChord.exe` を起動します。
2. タイトル画面の「裏世界」ボタンを押します。ボタンが出ていなければ F12 キーを押します。
3. 裏世界の画面の右上に、案ごとの切り替え欄が出ます。チェックを付けた案が有効になります。
   - 切り替えた内容は、次に出撃した戦闘から使われます。戦闘中には変わりません。
   - 切り替えた内容はこのPCに保存されます。次に起動したときも同じ設定で始まります。
4. 「プレイヤー操作テスト（敵なし）」「敵テストへ出撃」「ボステストへ出撃」のどれかで戦闘に入って確かめます。
   - Justボーナス・コンボ・硬直は、敵がいないと確かめられません。敵テストかボステストを使ってください。
5. 戻るときは、ポーズからタイトルへ戻り、もう一度「裏世界」を開きます。

## 案の一覧

### 戦闘とゲージの案（最初は全てON）

| 切り替え欄の名前 | 内容 | 確かめること |
| --- | --- | --- |
| スキル入力のJustボーナス | スキルのコマンドをJustで入力した割合でスキルの効果が強くなります。効果 = 50% + 50% × Justの数 ÷ 入力の数。全部Justなら今までどおりの強さ、全部通常なら半分です。キルコードの「最後の入力がJustならダメージ200%」はなくなります。 | Justを狙う気になるか。外したときの弱さに納得できるか。長いコマンドでも狙えるか。 |
| Justのときだけ増えるコンボ | Justで当てたときだけコンボが増え、Justでない攻撃をするとコンボが0に戻ります。10・25・50コンボで数字の色が変わり、大きく弾みます。 | コンボを続けたいと思うか。Justを狙う理由になるか。 |
| スキルゲージをリズムゲージの上に | スキル入力の進み具合の表示を、リズムゲージの上に移し、アイコンを1.5倍にします。 | リズムゲージよりスキルの表示に目が行くか。 |
| ゲージの波を小さく | リズムゲージのブロックの伸び縮みを、今の0.35倍にします。色と範囲は同じです。 | ゲージに目を取られにくくなるか。判定は今までどおり読めるか。 |
| 移動・回避・硬直の調整 | 移動速度0.7倍、回避のクールタイム1拍、通常攻撃とスキルの後の硬直2倍にします（仮の値）。 | 回避を中心に立ち回るようになるか。敵を見るようになるか。重すぎないか。 |
| 1小節のゲージとタイムアウト | ゲージの長さを1小節にします。伸びきったあとは、タイムアウト（2小節）まで中央から消えていきます。 | 1小節の長さがつかみやすいか。タイムアウトまでの残りが分かるか。 |

### リズムUIの見た目（最初は全てOFF、見比べ用）

| 切り替え欄の名前 | 内容 |
| --- | --- |
| ゲージを画面の中央に | リズムゲージを画面の縦の中央に置きます。スキル入力の表示も一緒に動きます。 |
| 外側から内側へ伸びるゲージ | ゲージが画面の端から中央へ向かって伸びます。 |
| 太いバーで1小節24段階 | 1小節を24個の太いバーに分け、バーの間に隙間を空けます。 |
| Justのバーを特別なデザインに | Justの範囲の帯と枠をなくし、Justがあるバーを白っぽく、高くします。 |
| リング型（旧UIを大きく） | 画面の中央に大きなリングを出し、24段階の区切りを時計回りに点けます。バーのゲージは隠れます。 |
| リング型（画面の外周） | 画面の外周に沿ったリングを出し、上の中央から時計回りに点けます。バーのゲージは隠れます。 |

- バーの見た目の案（中央・外側から内側・24段階・Justのバー）は、組み合わせて使えます。
- リング型は、どちらか1つだけ選べます。
- 「1小節のゲージとタイムアウト」と組み合わせると、リングも1小節で1周し、伸びきったあとに始まりから消えます。

## 見比べ方の例

1. 全ての案をOFFにして、今の製品の状態で1回遊びます。
2. 戦闘とゲージの案を1つずつONにして、違いを確かめます。
3. リズムUIの見た目の案を1つずつONにして、見比べます。
4. 気づいたことは、何をONにしていたかと一緒に書き残してください。

## 試遊のあとで聞きたいこと

- 何を見てリズムを取ったか。ゲージを見ずに取れたか。
- 敵の予兆を見て避けられたか。
- Justを狙うのは楽しかったか。外した理由は何だと思うか。
- コマンドの長さに納得できたか。
- コンボを続けたいと思ったか。
- リズムUIの見た目は、どれが一番見やすく、ゲージに目を取られにくかったか。

## 注意

- 開発ビルドのため、画面にログが出ることがあります。
- 見た目の案は、実際の画面では見た目を調整していません。崩れて見えるときは、どの組み合わせだったかを教えてください。
- 数値（Justボーナスの50%、移動速度0.7倍など）は仮の値です。プランナー用の設定データで変えられます。
