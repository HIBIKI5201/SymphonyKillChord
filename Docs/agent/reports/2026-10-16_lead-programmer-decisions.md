# リードプログラマー判断の決定一覧（2026-10-16）

EsAgent の「KillChord リードプログラマー」21 件のうち、作業の前に決める必要があった点を、リードプログラマーが 2026-10-16 に決めた記録。
ディレクター判断（[2026-10-14_director-decisions.md](2026-10-14_director-decisions.md)）で決まった項目は、ここでは繰り返さず参照だけ書く。
各項目の根拠 Issue には同じ内容をコメントで残した。

## コード・アーキテクチャ（#2361）

| 項目 | 決定 | 根拠 |
| --- | --- | --- |
| Master から開発用の動作を外す | `KillChord.Develop.asmdef` の `defineConstraints` を `UNITY_EDITOR \|\| DEVELOPMENT_BUILD` にする。開発用の部品は**開発機能専用のオブジェクト**にまとめ、**Master のビルドのときだけ**ビルド前処理で外す。Dev ビルド（実機テスト）では開発用のスキル解放を使えるようにする（`EditorOnly` タグは Dev ビルドからも消えるので使わず、独自のタグなどで見分ける） | P1、C04 |
| DataID の検証 | 重複・hash 衝突・焼き込み忘れ・参照切れを、**Master のビルドではエラーで止め、Dev のビルドでは警告**にする | P2、C05、C08 |
| 公開後の固定 ID | 公開後は CollectionKey／文字列 ID の**変更を禁止**する。表示名は自由に変えてよい。どうしても変えるときは**旧 ID → 新 ID の別名表**を残し、セーブの読み込み時に置き換える。削除するときも「廃止」として ID を残す | P4、C08 |
| 保存の互換 | **体験版から製品版へはセーブを引き継がない**。製品版以降は互換を保証する。セーブにスキーマ版を持ち、版ごとに順に移行する。破損時は元のファイルを退避して新規に始め、その旨を表示する | P5、C06、C07、#2418 P8 |
| モジュール境界 | **Battle／Character／StatusEffect を 1 つの戦闘境界**とし、その中の直接参照は許す。**Music（拍）は別のモジュール**とし、戦闘とのやり取りは Adaptor 経由にする | P7、C01 |
| 画面処理の切り出し・ロードと音源登録の所有者・Container の公開面 | レビューの推奨どおりに進める。設計案をエージェントが Issue に書き、**実装の前にリードが承認**する | P6、P8、P9、C02、C09〜C11 |

## テスト・CI・マージ（#2361、#2362、#2417）

| 項目 | 決定 | 根拠 |
| --- | --- | --- |
| 最初の EditMode テストの実行場所 | **GitHub ホストのランナー（GameCI）**で実行する。ライセンスの設定が要る。結果（XML 等）と対象 SHA を保存する | #2361 P3、#2417 P5・P6 |
| develop へのマージの受け入れ条件 | PR 本文のチェックボックスに加えて、**GameCI のコンパイルと EditMode テストを必須チェック**にする。C# を変えない PR は飛ばしてよい。配布の条件（実機・許諾）はマージの条件と分ける | #2362 P9 |
| 二段階 PR の対象 | feature/ のみ（ディレクター判断） | #2362 P11 |

## AI エージェントの運用（#2363）

| 項目 | 決定 | 根拠 |
| --- | --- | --- |
| Codex への委任 | **当面、委任を止める**。残量の判定と完了の判定を直すまで、実装はエージェント（Claude）が直接行う。資源の予約・worktree の所有権も、委任を再開するまで後回し | P1、P2、P8 |
| 起動時 hook と人の作業の保護 | 起動時の背景更新（仕様のミラーなど）は**続ける**。検証の前に、**未保存のシーンや Play 中の状態があれば止まって確認する**仕組みだけ入れる | P4、P5 |
| AI の許可範囲 | 依頼者が明示すれば実装も可、コード規約の正本は Notion（ディレクター判断）。これを `CodeGuidelines.md` と `AGENTS.md` に書く | P3 |

## 公開・ビルド・性能（#2418、#2100、#2415）

| 項目 | 決定 | 根拠 |
| --- | --- | --- |
| 公開候補の版の固定 | **rc タグ（`v1.0.0-rc.N`）**で固定する。タグに SHA・Unity の版・外部 ZIP のハッシュ・サブモジュールの版・対象プラットフォームを記録し、展示用のコピーもそのタグから作る | #2418 P4 |
| ビルドの入力 | AssetStoreTools の正本はサブモジュール（ディレクター判断）。上の rc タグに版を記録する | #2362 P8、#2415 P1、#2418 P7 |
| 実機計測の下限端末 | **チームが持っている一番古い Android 端末**を下限にする（メンバーに機種を聞いて決める）。Windows は開発機の代表機を置く。性能は公開を止める条件にしない（ディレクター判断） | #2100 |
| Android の配布容量 | **AAB の本体を 200MB 以内**にする。超えたら Play Asset Delivery に分ける。テクスチャは ASTC にし、用途別の Import Preset で最大サイズを決める | #2415 P5・P8 |
