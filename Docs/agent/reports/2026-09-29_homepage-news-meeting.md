# ホームページ お知らせ追加（TGS出展・ファミ通掲載）

- 日付: 2026-09-29
- 参加者: 
- 前提資料: Notion「システム概要 / ホームページ仕様」（Astro製、`HomePage/` 配下。`main` への push で GitHub Pages にデプロイ）、Notion「ステータスリスト / TGSホームページ」（バンタン TGS2026 特集ホームページへの掲載回答）
- Issue: #2321（TGS出展）、#2322（ファミ通掲載）

## 決定
- 公式ホームページのNewsに、お知らせを2件追加する
  - 「東京ゲームショウ2026に出展しました」：バンタンのTGS2026特設ページ（本作の紹介ページ）へのリンクを記事に載せる
  - 「ファミ通.comで紹介されました」：ファミ通.comの記事へのリンクを記事に載せる
- 1件ずつIssueを分け、タスク表に登録する。納期は2026-09-30
  - 依頼では「9/31」だったが、9月は30日までのため9/30とした
- これまでNewsは「日付・タイトル・リンク先」だけで、記事ページが無かった。お知らせごとに記事ページ（`news/<slug>`）を作り、本文と外部リンクを載せる形にする

## ログ

### 現状
- `HomePage/src/data/news.ts` の配列は空で、ホームのNews欄と `/news` 一覧は「現在、お知らせはありません。」と表示されている
- `NewsItem` は `date` / `title` / `href` だけで、本文を持てない

### 載せる内容
#### 東京ゲームショウ2026 出展
- 日程・会場：2026/9/17〜21、幕張メッセ。バンタンゲームアカデミーのブースで出展
- リンク：https://www.vantan-game.com/special/tgs/sub_page_02.html （バンタン TGS2026特設ページの本作紹介）
- 特設ページのトップ：https://www.vantan-game.com/special/tgs/

#### ファミ通.com 掲載
- 記事：本間ひまわりさん（にじさんじ）がバンタン学生のゲーム制作をサポートした企画の記事。本作が取り上げられている
- リンク：https://www.famitsu.com/article/202609/88578

### 実装の方針
- `NewsItem` に `slug`（記事URL）・`body`（段落の配列）・`links`（外部リンク）を持たせる
- `src/pages/news/[slug].astro` で `news` 配列から記事ページを静的生成する
- 一覧（ホームのNews欄、`/news`）の各行は記事ページへ飛ぶ。外部リンクは記事ページ内に置き、別タブで開く
- お知らせの日付は掲載日（2026-09-29）とする

### 確認が要ること
- ファミ通.comの記事は作業環境から開けなかった（ネットワーク制限）。URLと本作の掲載は検索結果で確認したのみ。本文の言い回しと記事の公開日は、公開前に人が記事を開いて確かめる
- お知らせの文面（特に「会場で遊んでくださった皆さま〜」の一文）は広報担当が確認する
- ホームページの公開は `main` への push で行われる。今回の変更は develop 経由のため、公開のタイミングは別途決める
