## 質問

### ゲーム内の語

**Q1 ゲーム名**（Symphony Kill Chord 32 / SymphonyKillChord 141 / KillChord 244 / Kill Chord 36 / シンフォニー 5）
「Kill Chord」は #2028 でキルコードの英名に決まったため、ゲームの略称に使うと同語別物になる。
1. ⭐ 文章の正式名は「Symphony Kill Chord」、略称は「SKC」（スキル名・ブランチで既に使っている）。リポジトリ名・識別子は `SymphonyKillChord`／`KillChord` のまま。「Kill Chord」単独はキルコードの英名にだけ使う
2. 略称は「KillChord」（スペース無し）にする

**Q2 ウェーブ**（ウェーブ 210 / Wave 162 / フェーズ 119）
1. ⭐ 文章は「ウェーブ」、英語表記とコードは「Wave」。敵の出現単位を指す「フェーズ」「敵Wave」は非推奨。用語リストの「フェーズ」「敵Wave【要確認】」は「ウェーブ」1 語にまとめ、「フェーズ」はチュートリアルの段階・ボスの形態の意味だけで残す
2. 用語リストはまとめず、今の 3 語のまま

**Q3 解放ポイント**（解放ポイント 34 / 研究ポイント 18 / 解放P 7 / 研究P 9）
1. ⭐ 「解放ポイント」、略称「解放P」、英語「Unlock Points」。「研究ポイント」「研究P」は非推奨
2. 略称を使わない（常に「解放ポイント」）

**Q4 拍と拍子**（拍 850 / 拍子 550 / ビート 58 / ノーツ 45 / ノード 384）
1. ⭐ 書き分ける。「拍」は音楽の時間の単位（例: 硬直 0.5 拍）、「拍子」はコマンド入力の種類（1・2・3・4・6・8 拍子）。拍子の別名の「ノーツ」「ノード」は非推奨にし、「ノード」はスキルツリーのマスだけに使う。「ビート」はコードの `BeatType` の中だけ
2. 「拍子」に統一する

**Q5 Just**（Just 138 / ジャスト 88）
1. ⭐ 判定名も文中も「Just」（例: Just 判定）。「ジャスト」は非推奨
2. 判定名は「Just」、文中の口語は「ジャスト」も許す

**Q6 ステージ・ミッション・作戦**（ステージ 916 / ミッション 427 / 作戦 221 / ステージ選択 51 / ミッションセレクト 22 / ステージセレクト 15）
用語リストでは別物になっている（ステージ＝インゲームの単位、ミッション＝ステージのクリア目標、作戦画面＝ステージを選ぶ画面）。
1. ⭐ 3 語は書き分ける。画面名の「ステージ選択」「ミッションセレクト」「ステージセレクト」は非推奨にし「作戦画面」に揃える（コードの `ScreenId.StageSelect` は残す）
2. 画面名は「ステージ選択」に戻す

**Q7 ロックオン**（ロックオン 441 / ロック単独 約 70 / ターゲット 164）
1. ⭐ 動作は「ロックオン」、狙われる相手は「ターゲット」。「ロック」単独は非推奨（未解放の鍵の意味と紛れるため）
2. 「ロック」単独も許す

**Q8 グローバル（常駐）**（Persistent 166 / 常駐 89 / グローバル 20）
1. ⭐ シーン分類の名前は「グローバル」（アウトゲーム・インゲームと並ぶ）、シーン名とコードは「Persistent」。「常駐」は「常駐する」という説明の言葉だけに使う
2. 文章も「Persistent」に揃え、用語名も変える
