# 日次通知機能

- id: 3d47c2c6-cc02-8102-8c10-fb2512a3fa72
- path: Symphony Kill Chord / システム概要 / SinfoniaOperator / 日次通知機能
- last_edited: 2026-09-07T17:10:21.697Z

毎朝、Notionのタスク・スプリント情報をDiscordへ通知する機能。SinfoniaOperatorの元々の役割であり、Bot本体（Exe）を引数なしで実行したときの既定動作にあたる。

### 実行タイミング
`.github/workflows/SinfoniaOperator.yml`が毎日JST07:00（UTC 22:00）にcronで起動する。`workflow_dispatch`により手動実行も可能。GitHub Environment「Sinfonia Operator」のSecretsから`DISCORD_BOT_TOKEN`と`NOTION_TOKEN`を注入し、それ以外の設定（チャンネルIDやNotionプロパティ名）はリポジトリにコミットされた`sinfonia-operator.env.json`から読む。

### 通知内容
| 通知 | 条件 | 送信先チャンネル |
|---|---|---|
| タスクリスト | 日曜日以外、常に取得を試みる（該当タスクが無ければ送信しない） | `DISCORD_TASK_CHANNEL_ID` |
| タスクアラート | 同上 | `DISCORD_TASK_ALERT_CHANNEL_ID` |
| スプリント情報 | 月曜日のみ | `DISCORD_SPRINT_CHANNEL_ID` |
タスクリストの取得は`NotionTaskListReader`、スプリント情報の取得は`NotionSprintListReader`が担う。いずれもNotionのタスク/スプリントデータベースを`Notion.Client`経由でクエリし、Discordに収まる形式のテキストへ整形する。

### 実装上の注意点

#### 2000文字制限の分割
Discordの1メッセージは2000文字が上限のため、`DiscordBotManager.PushContextAsync`が改行位置を基準に自動分割して複数メッセージへ送信する。分割ロジックは`DiscordMessageUtility`（Core）に共通化されており、Webhook経由の送信（`DiscordWebhookClient`）とBotトークン経由の送信（`DiscordBotRestClient`）の両方から使われる。新しい通知機能を追加する場合も、長文送信にはこのユーティリティを再利用する。

#### 送信経路の切り替え
`DiscordNotifier`（Core）が、`DISCORD_BOT_TOKEN`が設定されていればBotトークンでのREST送信を、無ければ`DISCORD_WEBHOOK_URL`でのWebhook送信を選ぶ。Unity Editorから作業ログを送る場合など、Bot常駐が不要な文脈ではWebhookのほうが手軽なため、この二択を残している。

#### `send`サブコマンドとの関係
`send --channel <種別> --message <本文>`は、Notionを読まずに単発でメッセージを送るための軽量コマンドである。日次通知のロジック（`PushTaskList`・`PushSprint`）とは独立しており、外部プロセスからBotの1メッセージ送信機能だけを借りたい場合に使う。

### 既知の制約
- 日曜日はタスクリストを送信しない、スプリントは月曜日のみという曜日判定は`DateTimeUtility.IsTodayByDayOfWeek`がJST基準で行う。サーバーのタイムゾーン設定に依存しないよう、UTCから明示的に変換している。
- タスク・タスクアラートともに「送信する内容が無い」場合は送信自体をスキップする（空メッセージを送らない）。この判定は`NotionTaskListReader.GetTaskContent`が返す`HasTaskContent`/`HasTaskAlertContent`で行う。
