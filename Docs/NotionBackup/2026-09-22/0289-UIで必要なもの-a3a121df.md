    - 解禁されていない場所を視覚的にわかりやすくするためのUI
    - スキルスロット

      [image: image.png] attachment:23337f3d-95d5-4fe3-bff4-171d8e02fe1a:image.png

    - 決定ボタン

      - 選択肢がある設定変更時に使う
