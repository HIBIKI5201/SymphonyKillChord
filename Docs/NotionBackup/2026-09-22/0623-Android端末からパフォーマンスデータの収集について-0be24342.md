#### 事前準備
  [header_4] Androidデバイスの開発者モードを有効化
    　デバイスの設定画面から、「システム」⇒「端末情報」⇒「ソフトウェア情報」⇒「ビルド番号」を探す。※機種によってメニュー構成が異なる
　ビルド番号を7回タップして、画面に「開発者向け機能が有効になった」旨のメッセージが表示されたら、開発者モードの有効化が完了。
    　開発者モードが有効になると、設定メニューに「開発者向けオプション」が表示される。そこで、「USB経由デバッグ」関連のオプションをオンにする。

#### ビルド ⇒ プロファイリングまでの手順
  [header_4] デバイスをPCに接続する
    開発者モードが有効、USBデバッグ可能であることを確認しておく。
  [header_4] UnityでBuild Profileを作成する
    Add Build Profileをクリックして、Androidを選択する。
    [image: image.png] attachment:a40e28da-f70f-4bab-955c-ff70c227fde8:image.png
    [image: image.png] attachment:0ae655b7-6914-4102-84a0-1c90a88d3d8f:image.png
  [header_4] プロファイリングに必要な設定を行う
    最低限必要な設定は下記通り：
・Run Device：接続しているAndroid端末を選択する
・Development Build：チェックする。開発向けのビルドであることを示す
・Autoconnect Profiler：チェックする。ゲーム起動時、Profilerが自動的に接続する
    [image: image.png] attachment:da4d80b2-e2ae-44d5-a032-a20af3564593:image.png
    設定後、Build And Runをクリックする。
  [header_4] プロファイリング開始
    　Build And Runをクリックして、ビルド完了後に、Android端末で自動的にゲームが起動する。その同時に、Unityにてプロファイリングが始まる。
    [image: image.png] attachment:78c1b389-5ae7-462d-ba40-0b8680f8b9e2:image.png

#### トラブルシューティング
  [header_4] 接続したAndroidデバイスが表示されない場合
    　UnityにAndroidデバイスが表示されない場合、adb(Android Debug Bridge)が機能していない可能性が高い。下記手順に従って、adbを有効にしたり、adbの状態を確認する。
    - ▶ **AndroidデバイスのUSB接続モードを切り替えてみる**
      　機種によって、adbが機能するモードが異なる。ファイル転送モードで機能する場合もあれば、充電のみモードで機能する場合もある。
　モードを切り替えてしばらく待って、「USBデバッグを許可しますか」旨の確認画面が表示されたら、adbが機能していることを示す。
      [image: image.png] attachment:eec0eb3d-a481-425f-aa99-914764d83eed:image.png
      [image: image.png] attachment:ca6d65cc-9e5d-4aa0-acd6-547da79b12d2:image.png
    - ▶ **adbを手動設定する**
      　Windowsのコマンドプロンプト（CMD）、またはPowerShellを起動して、下記コマンドを入力する：
　adb forward tcp:34999 localabstract:Unity-[ゲームのBoudleIdentifier]
      　※UnityのProfilerはTCPポート番号34999を使用する
　※[ゲームのBoudleIdentifier]は、PlayerSettingsで確認できる。Player Settings ⇒ Other Settings ⇒ Identification ⇒ Package Nameの内容。この項目が見つからない場合、Androidの設定タブを見ているかどうか確認しよう。
　※コマンドを入力して、adbがコマンドとして認識されない場合、sdk platform-toolsが見つからないことが原因。後述の「sdk platform-toolsの導入」を参照してください。
    - ▶ **sdk platform-toolsの導入**
      　sdk platform-toolsの導入には環境変数の設定も必要です。
