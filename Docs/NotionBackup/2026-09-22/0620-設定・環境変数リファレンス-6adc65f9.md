すべての設定キーは`SinfoniaOperator.Core/OperatorConfigKeys.cs`に定数として定義されている。新しいキーを追加するときは、まずここに定数を足してから使う。

### 設定の読み込み優先順位
`OperatorConfig`が次の順で値を解決する。
1. JSON設定ファイル（`sinfonia-operator.env.json`が公開設定、`sinfonia-operator.secrets.json`がGit除外の秘匿設定）
2. 環境変数
CLIの第一引数以降にJSON設定ファイルのパスを渡した場合は、そのファイルのみを読み込む（`index`/`serve`サブコマンドの2番目の引数がこれにあたる）。引数を省略した場合は、カレントディレクトリと実行ファイル位置の祖先ディレクトリから既定のファイル名を探索する。

### Discord関連
| キー | 用途 |
|---|---|
| `DISCORD_BOT_TOKEN` | Botトークン。Gateway接続とREST送信の両方に使う |
| `DISCORD_TASK_CHANNEL_ID` | タスクリストの送信先チャンネルID |
| `DISCORD_TASK_ALERT_CHANNEL_ID` | タスクアラートの送信先チャンネルID |
| `DISCORD_SPRINT_CHANNEL_ID` | スプリント情報の送信先チャンネルID |
| `DISCORD_WORK_LOG_CHANNEL_ID` | Unity Editorの作業ログ送信先（Unity専用） |
| `DISCORD_WEBHOOK_URL` | Botトークン未設定時のフォールバック送信先 |
| `DISCORD_LOG_CHANNEL_IDS` | ログ取得対象のチャンネルID配列（`DiscordLogExporter`が使用） |

### Notion関連
| キー | 用途 |
|---|---|
| `NOTION_TOKEN` | Notion Integrationトークン |
| `NOTION_TASK_DATABASE_ID` | タスク管理データベースのID |
| `NOTION_SPRINT_DATABASE_ID` | スプリント管理データベースのID |
| `NOTION_DATABASE_DATE_PROPERTY` | タスクの日付プロパティ名（例：「日付」） |
| `NOTION_DATABASE_NAME_PROPERTY` | タスク名プロパティ名（例：「名前」） |
| `NOTION_DATABASE_STATUS_PROPERTY` | ステータスプロパティ名（例：「ステータス」） |
| `NOTION_DATABASE_STATUS_TASK_DONE_PROPERTY` | 完了扱いにするステータス値（カンマ区切り、例：「完了,却下」） |
| `NOTION_EXPORT_ROOT_PAGE` | `NotionMarkdownExporter`がミラー出力する起点ページ |
| `NOTION_EXPORT_OUTPUT` | ミラー出力先ディレクトリ（`Docs/NotionSpecifications`） |
| `NOTION_WRITE_ALLOWED_ROOTS` | `NotionMarkdownWriter`が書き込みを許可するページIDの配列 |

### 仕様検索Bot関連
| キー | 用途 | 既定値 |
|---|---|---|
| `SPEC_SEARCH_INDEX_PATH` | 検索インデックスファイルの保存・読込先パス | 必須（既定無し） |
| `SPEC_SEARCH_EMBEDDING_MODEL_PATH` | ONNX埋め込みモデルファイルのパス | 必須（既定無し） |
| `SPEC_SEARCH_DISCORD_GUILD_ID` | `/spec`をGuild限定登録する場合のGuild ID | 未設定ならグローバル登録 |
| `SPEC_SEARCH_TOP_K` | 検索結果の返却件数（1〜10） | 3 |
`SPEC_SEARCH_EMBEDDING_MODEL_PATH`で指定したONNXファイルと同じディレクトリに、`sentencepiece.bpe.model`という名前でトークナイザファイルを置く必要がある（パスはコード側で自動的に導出される）。

### 秘匿情報の扱い
`DISCORD_BOT_TOKEN`と`NOTION_TOKEN`は秘匿情報であり、リポジトリにコミットしない。ローカル開発では`sinfonia-operator.secrets.json`（Git除外）、GitHub Actionsでは`Secrets`、Oracle Cloud VMではVM上にのみ置く設定ファイル（`sinfonia-specsearch.env.json`など）で管理する。VMへ転送する際は、ターミナル出力や差分表示に値そのものを露出させないよう注意する（`jq`などでトークンだけを抽出してファイル間コピーする方法が安全）。
