## 結論

## 仕様概要
  スキルの全体の共通すること

## 仕様意図
  スキルの改造で書くべきことと戦闘で書くべき場所が共通している部分がありそれなら全体であるべきだと考えた。

## 仕様詳細

## スキル

### 装備
  - スキルは一度の3つまで装備可能。

#### スキル装備時の条件
  - コマンドの最後のノーツが共通しているスキルは同時に装備できない。
  例えば
スキルαのコマンドは A A B B
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できない。

スキルαのコマンドは A C C
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できる。

#### スキルのレベル
  - レベルの最大値は10である。
  - スキルはレベルが存在しており装備のレベル上げにはポイントを使用する。
    - スキルのレベルで攻撃％やバフなどの数値が上がって行く。
