### 結論
ゲーム内の時間（タイムスケール）を、**オブジェクト単位**かつ**カテゴリ単位（Player / Enemy / Map）**で個別に制御できる仕組みを実装した。各オブジェクトは `ITimeScalable` を実装し、自身のスケール値を `TimeScaleData` 経由で取得して `Tick()` 内の更新量に乗算する。
「ポーズ」と「スケール変更」を別のものにして、ポーズ中にもタイムスケールを変更できるようにした
- **ポーズ** — 複数箇所から多重にかかる前提（メニュー＋ダイアログ等）。`PauseToken`（`IDisposable`）を返し、`Dispose()` で解除。内部はカウンタ方式で、全解除されるまでポーズが継続する
- **スケール変更** — ただの上書き（setter）。トークン管理は不要
これにより「解除忘れ」を構造的に防ぎつつ、スロー演出などの速度変更も同じ基盤で扱える。

### 注意事項
- **スケール値の実体は **`**TimeScaleHandler**`** が保持し、**`**TimeScaleData**`** はそのビュー（委譲）として機能する**。`Register` 時に Handler と Data を生成し、Data に Handler を渡して紐付けている。両者が分離するとポーズが反映されないため、この紐付けは必須
- `TimeScaleSystem` は常駐シーンに**1つだけ**置く想定。`Awake()` で重複インスタンスを `Destroy` するシングルトン構成。`TimeScaleManager` は `static` プロパティとして全体で共有する
- Additiveシーンのオブジェクトを扱う場合、アンロード時に破棄されたオブジェクトが辞書に残らないよう、`OnDestroy()` で必ず `Unregister()` を呼ぶこと
- ポーズ中のオブジェクトは `CurrentScale` が `0` を返すため、`ApplyScale(deltaTime)` の結果も `0` になり、更新が止まる

### 機能の概要
タイムスケール制御の抽象基盤と、それを操作するManager / Controllerを新規実装。主な特徴は以下の通り：
- **オブジェクト単位のスケール管理** — `ITimeScalable` を実装したオブジェクトごとに `TimeScaleHandler` を生成し、個別にスケールを保持
- **カテゴリ別フラグ** — `TimeScaleType`（`[Flags]` enum）で Player / Enemy / Map を区別。`HasFlag` 判定により複合カテゴリにも対応
- **多重ポーズ対応** — `TimeScaleHandler` 内のカウンタ方式。複数箇所からポーズをかけても、全 `PauseToken` が `Dispose` されるまで解除されない
- **3つのスコープ** — タイプ指定（ByType）/ ID指定（ById）/ 全体（All）の3つで、ポーズとスケール変更を提供
- **トークンによる解除** — ポーズ系メソッドは `PauseToken` を返し、`Dispose()` で解除。`TimeScaleController`**(仮実装)** がトークンを保持し、対になる解除メソッドを提供

### 変更ファイル一覧

#### 新規作成（Core）
| ファイル | 役割 |
|---|---|
| `TimeScaleType.cs` | タイムスケール対象の種別フラグ（`[Flags]` enum: None / Player / Enemy / Map） |
| `ITimeScalable.cs` | タイムスケール対象オブジェクトのインターフェース（InstanceId / TimeScaleType / Inject / Tick） |
| `TimeScaleData.cs` | オブジェクトに注入されるスケールのビュー。`TimeScaleHandler` に委譲してスケール値を返す |
| `TimeScaleHandler.cs` | オブジェクト一つ分のスケール管理。baseScaleとポーズカウンタを保持 |
| `PauseToken.cs` | ポーズの解除ハンドル（`IDisposable`）。二重Disposeを無視する |

#### 新規作成（Manager / System）
| ファイル | 役割 |
|---|---|
| `TimeScaleManager.cs` | 全オブジェクトの登録・スケール操作の窓口。ByType / ById / All の各操作を提供 |
| `TimeScaleSystem.cs` | `MonoBehaviour`。常駐シーンに1つ置くシングルトン。`Update()` で全オブジェクトの `Tick()` を回す。`TimeScaleManager` を `static` で公開 |
| `TimeScaleController.cs` | UI等から呼ぶ操作API。発行した `PauseToken` を保持し、対になる解除メソッドを提供 |

### 実装されたコンポーネント説明

#### 全体アーキテクチャ
```Plain Text
TimeScaleSystem (MonoBehaviour, 常駐シーンに1つ, static Manager)
  └─ Update() で TimeScaleManager.GetAll() の全 Tick() を実行

TimeScaleManager
  └─ Dictionary<ITimeScalable, TimeScaleHandler> で全オブジェクトを管理
       ├─ ByType  : HasFlag で該当タイプを一括操作
       ├─ ById    : InstanceId で個別操作
       └─ All     : 全体を一括操作

ITimeScalable (各オブジェクトが実装)
  ├─ InstanceId / TimeScaleType
  ├─ Inject(TimeScaleData)  ← 登録時に Manager から注入される
  └─ Tick()                 ← ApplyScale(deltaTime) で更新

TimeScaleData (ビュー) ──委譲──▶ TimeScaleHandler (スケールの実体)
                                    ├─ baseScale（通常の速度, setterで上書き）
                                    └─ pauseCount（ポーズ多重カウンタ）
                                       CurrentScale = pauseCount>0 ? 0 : baseScale

PauseToken (IDisposable) ── Dispose() ──▶ pauseCount-- （ポーズ解除）
```
---

#### TimeScaleHandler
オブジェクト一つ分のスケールを管理する中核クラス。「通常の速度（baseScale）」と「ポーズ（pauseCount）」を別フィールドで保持する。
- `CurrentScale` — `pauseCount > 0` の間は `0`、それ以外は `_baseScale` を返す
- `Pause()` — `pauseCount` をインクリメントし、`Dispose()` で `pauseCount` をデクリメントする `PauseToken` を返す（多重ポーズ対応）
- `SetScale(scale)` — `_baseScale` を上書きする
```C#
public float CurrentScale => _pauseCount > 0 ? 0f : _baseScale;

public PauseToken Pause()
{
    _pauseCount++;
    return new PauseToken(() => _pauseCount--);
}
```
ポーズと速度を分離しているため、ポーズを解除すると直前の `baseScale` に正しく復帰する。
---

#### TimeScaleData
`ITimeScalable` を実装したオブジェクトに注入される、スケールの**読み取り用ビュー**。値の実体は持たず、コンストラクタで受け取った `TimeScaleHandler` に委譲する。
- `Scale` — `_handler.CurrentScale` を返す
- `ApplyScale(delta)` — `_handler.CurrentScale * delta` を返す。`Tick()` 内で `deltaTime` に乗算して使う
---

#### PauseToken
ポーズの解除ハンドル。`IDisposable` を実装し、`Dispose()` で生成時に渡された解除処理（`Action`）を呼ぶ。`using` 構文でスコープ抜けに自動解除でき、解除忘れを防げる。`_disposed` フラグにより**二重Disposeは無視**される（カウンタが過剰に減るのを防止）。
---

#### TimeScaleManager
全 `ITimeScalable` を `Dictionary<ITimeScalable, TimeScaleHandler>` で管理し、操作の窓口となる。
- `Register(obj, defaultScale)` — Handler と Data を生成して紐付け、`obj.Inject(data)` で注入
- `Unregister(obj)` — 辞書から削除
- **ByType** — `PauseByType(type)`（`PauseToken` を返す） / `SetScaleByType(type, scale)`
- **ById** — `PauseById(instanceId)`（`PauseToken` を返す） / `SetScaleById(instanceId, scale)`
- **All** — `PauseAll()`（`PauseToken` を返す） / `SelectScaleAll(scale)`
ポーズ系は対象オブジェクト全員のトークンをまとめた合成 `PauseToken` を返し、一括解除できる。
---

#### TimeScaleSystem
`MonoBehaviour`。常駐シーンに1つだけ置くシングルトン（`Awake()` で重複を `Destroy`）。`TimeScaleManager` を `static` プロパティで全体公開し、`Update()` で登録済み全オブジェクトの `Tick()` を呼ぶ。
---

#### TimeScaleController
UIボタンなどから呼ぶ操作API。発行した `PauseToken` をスコープ別（All / Type / Id）に保持し、対になる解除メソッドを提供する。`OnDestroy()` で保持中の全トークンを `Dispose` する。
---

### 使用例

#### ITimeScalable を実装したオブジェクト
```C#
public class PlayerTest : MonoBehaviour, ITimeScalable
{
    public int InstanceId => GetInstanceID();
    public TimeScaleType TimeScaleType => TimeScaleType.Player;

    private TimeScaleData _timeScaleData;

    private void Start()
        => TimeScaleSystem.TimeScaleManager.Register(this, defaultScale: 1f);

    public void Inject(TimeScaleData data) => _timeScaleData = data;

    public void Tick()
    {
        float scaledDelta = _timeScaleData.ApplyScale(Time.deltaTime);
        // scaledDelta を使って移動・アニメーション等を更新
    }

    private void OnDestroy()
        => TimeScaleSystem.TimeScaleManager.Unregister(this);
}
```

#### ポーズと解除
```Plain Text
1. controller.PauseByType(TimeScaleType.Enemy)  → 敵をポーズ（PauseTokenを内部保持）
2. controller.ResumeScaleByType(TimeScaleType.Enemy)  → トークンをDisposeして解除
```
