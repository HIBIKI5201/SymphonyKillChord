# [対処済み]シーン開始時に揺れ物ボーンが暴れる

- id: 3207c2c6-cc02-8076-9df3-e0da4c37d971
- path: Symphony Kill Chord / システム概要 / SpringBone仕様概要 / [対処済み]シーン開始時に揺れ物ボーンが暴れる
- last_edited: 2026-04-06T03:07:01.069Z

・シーン開始時にTポーズやAポーズからすぐにアイドルモーションを再生すると1フレームでとんでもない速度で動いたことになるので髪の毛などのボーンが暴れる問題に対する対処
Updateの自動呼出しを切り、手動で呼び出すようにすることで初期化時に一定ステップすでに揺れ物ボーンをシミュレートさせることですでにあばれが落ち着いた状態からスタートさせることができた。
ただし、初期化順の都合上StartやAwakeでそのまま呼ぶとエラーが出るので`DefaultExecutionOrder` を利用して初期化を遅らせる必要があった。
