## 仕様説明

### 画面の機能構成
  - スキル一覧
    - 取得してるスキルのみを表記
    - ~~解禁されていない場所を視覚的に分かるように~~
  - スキル解除
    - セットしてる装備を全部外す
  - スキルフィルター
    - バフ・デバフ・攻撃
  - 所持ポイントの表記
  - おすすめスキル編成(なくてもいい)
    - 所持してるスキルからおすすめの編成をいくつか提案してくれる。

#### 画面レイアウト
  - ▶ 崩壊スターレイル:銀河シグナルローミング
    [image: image.png] attachment:5e5f65a6-5962-4645-b6ba-547855a70c6c:image.png
  - 編成の覧にスキルをセットできるようにする。
  - 説明覧
    - スロットレベルアップをスキルレベルアップにする
    - スキルの発動方法
    - 詳細ステータスか出撃スロットあたりに仕様映像の記載(仮)
  - 下のキャラクターが書いてある覧に所持スキルのみを表記
    - スキルレベルの表記
  - バフ、デバフ、攻撃でフィルターをできるようにする。
  - 所持ポイントの表記

#### 演出
  - スキルをセットした時、「カチッ」みたいな音
  - スキルのレベルアップ時にねじ？とかパーツを付け加えるみたいな音を流す
  - スキルを一定レベルまで上げたらフレームを変える(レベル上限しだい)
    - 銅→銀→金

#### スキルの仕様から移した方が良い

### スキル装備時の条件
  - コマンドの最後のノーツが共通しているスキルは同時に装備できない。
  例えば
スキルαのコマンドは A A B B
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できない。

スキルαのコマンドは A C C
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できる。
  

#### スキルか改造の仕様書に欲しい点
  スキルが何個つけらるか
  スキルの最大レベルの追加
