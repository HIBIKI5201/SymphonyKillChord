## 結論

### 仕様意図
  複数種類のスキルを任意に装備できるシステムでは、装備したスキルのコマンドの内容が被って、同時に発動してしまう事が有り得るので、その対策として絶対に同時には発動しないような仕組みにする。

### 内容
  コマンドの最後のノーツが共通しているスキルは同時に装備できない。
  例えば
  スキルαのコマンドは A A B B
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できない。
  スキルαのコマンドは A C C
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できる。
  こうすると、発動するタイミングである最後のコマンドで、必ず一つに定まるため、コマンドの内容が被って同時に発動してしまう事は無くなる。

## ログ

#### 経緯
  複数種類のスキルを任意に装備できるシステムでは、装備したスキルのコマンドの内容が被って、同時に発動してしまう事が有り得る。
  こうなるとスキルの効果やアニメーションによっては問題が発生する。

#### 提案
  - ▶ 初期案
    コマンドの最後のノーツが共通しているスキルは同時に装備できない。
    例えば
    スキルαのコマンドは A A B B
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できない。
    スキルαのコマンドは A C C
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できる。
    こうすると、発動するタイミングである最後のコマンドで、必ず一つに定まるため、コマンドの内容が被って同時に発動してしまう事は無くなる。
    **コマンドの発動について**
    - コマンドの内容が敵に攻撃を与えるものの場合
コマンドの最後のノーツでの攻撃を発動せずスキルを発動へと変更する
    - コマンド内容が自身に対するバフや回復の場合
コマンドの最後のノーツでの攻撃を発動し、スキル効果も発動する
