## ドライブ
ドライブは以下のリンクからアクセス。

#### ルール
入れる際のルールは以下の通り。
- フォルダを作る
  - フォルダ名は `モデル名_[日付]` にする。
- フォルダの中に以下のフォルダを作る
  - Model
    - FBXなどのモデルのファイルを入れる。
  - Texture
    - pngなどの画像ファイルを入れる。
    - BaseColorやNormalMapなど区分がある時は更にファイル分けする。

### Symphony
Symphonyのモデルは以下のフォルダに入れる。
```C#
3D/キャラクター/Symphony
```
‣

### 14号
14号のモデルは以下のフォルダに入れる。
```C#
3D/キャラクター/Soldier14
```
‣

### 武器
武器のモデルは以下のフォルダに入れる。
```C#
3D/キャラクター/Weapons
```
