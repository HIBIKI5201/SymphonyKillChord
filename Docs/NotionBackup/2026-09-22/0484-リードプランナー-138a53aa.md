## 仕様検討
[[仕様検討フォーラム]] の使用方法に従って仕様案の査定を行う。
```Mermaid
flowchart TD

A[1. 検討中の仕様案を確認する]
B[2-1. 改善点のコメントを付けて「作業中」に変更する]
C[2-2. 承認のコメントを付ける]

D[3. 「採用」に変更する]
E[4. 結論にまとめた内容を記述する]

A -->|修正が必要| B
A --> |採用| C
C --> |全ての承認が揃う| D
D --> E
```

## タスク管理
毎日行われるタスク調整の報告を確認する。
もし報告がない人がいれば確認作業を取る。
