## 仕様概要
  アルファ版期間である2026/4/30までの大まかなスケジュールを決める。
  それぞれのカテゴリーごとにスケジュールを記載する。
  カテゴリーは以下の通り
  - キャラモデラ―
  - 背景モデラー
  - 2Dデザイナー
  - UIデザイナー

## 仕様意図
  アルファ版で要求されるレベルは以下の通り
  - ゲームループが完成しており、ビルドして実機で確認が可能
  - コアメカニクスが実装されていて、コアの面白さを確認できる
  - 制作予定のアセットの仮置きがされている
  - アセットの量産に向けた実装上の課題確認ができる（画面比やパフォーマンスの問題などを確認できる）
  
  以上のことから、アルファ版期間の終盤に、仮置き向けのアセットが納品されている事が理想と考える。
  アルファ版の終盤は、バンタンの授業が始まる4/20から、四月終わりの4/30までとする。
これは
・アルファ版開発期限の一週間前の月曜日であること
・授業による稼働可能時間の減少が見込まれるため、10日間という長めの期間だが実質的には5日ほどの稼働時間になること
を加味している。

## 仕様詳細

### キャラモデラー
  キャラクターはSymphonyを重点的に制作する。
敵キャラクターなどはアセットを使用する事を前提とし、余裕があれば制作する方針。

#### Symphonyモデル
  Symphony（主人公）の3Dキャラモデル。
| 工程 | 理想期間 | 詳細説明 |
|---|---|---|
| 揺れものボーン、 SpringBoneの仮設定 | 3/30 ～ 4/4 | 揺れものやボーンの構造をSpringBoneなどとの兼ね合いを考えながら設計する。 またSpringBoneの仮設定を済ませたモデルを実装する。 |
| 武器ラフモデル制作 | 4/6 ～ 4/11 | 武器のだいたいの大きさや形のモデルを制作する。 これをSymphonyに持たせる実装をし、配置などを確認する。 |
| 仮モーション | 4/13 ～ 4/18 | 制作する攻撃モーションなどを仮のもので作る。 Unityで再生できるようにする。 |
| 武器の仮エフェクト | 4/20 ～ 4/23 | 武器のマズルフラッシュなどの仮エフェクトを作成する。 Unityで再生できるようにする。 |

### 背景モデラー
  ステージのレイアウトなどを行うワークフローを構築する必要があるため、それを考慮して期間を決める。

#### ステージマップ
  インゲームのステージのマップ。
| 工程 | 理想期間 | 詳細説明 |
|---|---|---|
| 大型プロップのラフモデル | 3/30 ～ 4/8 | 建物や地形などの大型のプロップのラフモデルを制作。 プロップをレイアウトしたモデルも作成して納品する。 |
| ゲーム内 仮配置 | 4/9 ～ 4/11 | ラフモデルをUnity内に配置する。 広さやプレイ感から見て配置に問題ないか確認する。 |
| 地面・地形のラフモデル | 4/13 ～ 4/18 | 地面などの地形のラフモデルを作成。 大型プロップのラフモデルと合わせてレイアウトしたモデルを作成して納品する。 |
| 建物、地面 | 4/20 ～ 4/23 | ラフのテクスチャを含めて完成度40％のものを納品する。 ゲームに配置して色感を確認する。 |

### 2Dデザイナー
  まずはSymphonyの立ち絵の制作に専念し、一つの指針を作る。
その後、ベータ版期間（5月～6月）で他のキャラクターの制作を行う。
  またデザイン面は他デザイナーとの連携しながら行うため、確認作業や連絡などによる待ち時間が多く発生すると予想されるので、
立ち絵制作と同時並行で行いたい。

#### Symphonyの立ち絵制作
  ストーリーシーンの制作に使用する、Symphony（主人公）の立ち絵。
| 工程 | 理想期間 | 詳細説明 |
|---|---|---|
| ラフ | 3/30 ～ 4/8 | Symphonyのキャラモデルや三面図を確認しながら、ラフ画を制作する。 目標はポーズや画風などを確定すること。 |
| 色ラフ | 4/9 ～ 4/10 | ラフに簡易的な色塗りを行い、質感がイメージと合っているか確認する。 |
| 表情差分ラフ | 4/11 ～ 4/12 | 簡単な表情差分を制作し、プランナー部門やシナリオ部門のメンバー向けにイメージ共有を行う。 |
| 線画 | 4/13 ～ 4/18 | 線画を制作する。アルファ版で仮置きするため納品する。 |
| 下塗り | 4/20 ～ 4/23 | 線画に下塗りを行う。途中確認のために納品する。 |
| 描き込み | 4/24 ～ 4/28 | ディティールを書き込んだものを制作する。 完全に完成させる必要はなく、目的はアルファ版の仮置きイメージと、他職種の士気向上や広報向けであるため、ベータ版期間中に修正が可能であることに留意する。 |

#### ZeroDivide組織章
  キャラモデルのテクスチャやUIのアイコンなどで使用するZeroDivide（主人公が所属する傭兵部隊）の章。
| 工程 | 理想期間 | 詳細説明 |
|---|---|---|
| 仕様決定 | 3/30 ～ 4/3 | プランナー主体でデザインの要項や仕様（どこに使用するか等）を決める |
| ラフ / 色ラフ | 4/3 ～ 4/11 | 幾つかの案を出して、デザイナー、プランナー、シナリオと協議して決定する。 決定したら色ラフを制作し、納品する。 |
| 線画 / 下塗り | 4/13 ～ 4/18 | 線画を行い下塗りをする。途中確認のため納品する。 |
| 書き込み | 4/20 ～ 4/25 | ディティールを書き込んだものを制作する。 完全に完成させる必要はなく、目的はキャラクターモデルなどに仮配置してルックを確かめることであるため、ベータ版期間中に修正が可能であることに留意する。 |
