## SymphonyKillChordプロジェクトの場合

### ディレクトリ
開発者はプロダクトごとにディレクトリを作成する。
研究班のディレクトリのパスは
```C#
Assets/DevelopProducts/Research/
```
設計班のディレクトリのパスは
```C#
Assets/DevelopProducts/Design/
```
これらのディレクトリの下にプロダクトのフォルダを作成し、その中で作業する。

#### 便利機能
クリエイトメニューの
```C#
Create/DevelopProducts/ProductsTemplate
```
を使えば、自動でフォルダを生成できる。

### スクリプティング
各プロダクトのディレクトリにはasmdef（アセンブリ）を設定する。
アセンブリ名は `DevelopProducts-[プロダクト名]`  とする。
名前空間を必ず設定する。
名前空間名は `DevelopProducts.[プロダクト名].[カテゴリー]`  とする。

### GitHub運用規定
基本的な命名や運用規則は [[GitHub 運用規定]] に従う。
ただし、ブランチ命名の際は `feature/research/[プロダクト名]/[個人名]` とする。
プロダクトの更新時は、 `feature/research/[プロダクト名]/master`  に対してPRを行う。
リードがこれを確認する。承認されれば作業者はmasterブランチにマージする。
最終的に作業が完了すれば、masterをdevelopにマージする。

### 制約
1. 担当プロダクトのディレクトリ以外は編集しない
もしくは編集してもプッシュしない
2. グローバル設定を変えたい際はリードに連絡して、マスターのブランチがまず編集を適用し、次に個人ブランチがプルして適用する
