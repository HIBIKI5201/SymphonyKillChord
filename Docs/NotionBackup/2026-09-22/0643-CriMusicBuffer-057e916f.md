## 概要
拍子などのBGM関連情報を管理するクラス。

## 内部実装

### メンバー変数
インスタンス_CriAtomSource（CRIプラグインのクラス）
BPM
最初小節開始時間
1拍の長さ
現在拍目
BGM固有拍子
現在小節目

### 処理

#### 初期化
- 入力項目：
　**BGM情報
　　**CriAtomSource
　　BPM
　　固有拍子
　　最初小節の開始時間
- 戻り値：
　なし
- 処理詳細：
　メンバー変数の値を設定する：
　　インスタンス_CriAtomSource：入力項目のCriAtomSource
　　BPM：入力項目のBPM
　　BGM固有拍子：入力項目の固有拍子

#### 小節タイミング情報変換
- 入力項目：
　小節タイミング構造体
- 戻り値：
　BGM開始からの拍数
- 処理詳細：
　下記通り戻り値を算出する：
　　戻り値 = ((現在小節 + 小節フラグ) * 1小節の長さ) + 1小節の長さ / 拍子スケール * (拍数 - 1)

#### メンバー変数更新処理(Updateにて呼び出す)
- 入力項目：
　なし
- 戻り値：
　なし
- 処理詳細：
　下記通りメンバー変数を更新する：
　　現在拍目 = (BGM再生時間 - 最初小節開始時間) / 1000 / 1拍の長さ
　　現在小節目 = 現在拍目 / BGM固有拍子　※小数以降切り捨て
