## UnityHubの設定
Unityのバージョンは以下を使用する。
```JavaScript
6000.3.10f1
```
またモジュールは以下を使用する。
```JavaScript
Android Build Support
```

## Unityプロジェクト起動後

### 手順１ AssetStoreToolsを入れる
GoogleDriveのプログラマーフォルダにあるunitypackageをダウンロードし、プロジェクトにインポートする。
[bookmark] https://drive.google.com/drive/u/0/folders/1cg6JIc8MItej0zc0A0D2IRaNospAAjvJ
unitypackageの名前は以下の通り。
```JavaScript
Export_AssetStoreToolsPackage_[日時]
```
基本的には日時が最も新しいものを入れる。
