# ⑤ 目標ステップ進入時アクションの実行フロー

目標ステップの達成条件とは別に、そのステップへ入った瞬間に一度だけ起こす副作用を`ObjectiveSequenceStepAsset`へ設定できる。デコレータ条件による副作用（ポップアップ・Wave・バフ）と違い、条件の判定には関与しない。
```Mermaid
sequenceDiagram
    autonumber
    participant Runtime as MissionRuntimeService
    participant EntryCtrl as MissionStepEntryActionController
    participant Voice as PlayVoiceStepEntryActionExecutor
    participant Skill as SetSkillExecutionEnabledStepEntryActionExecutor
    participant Enemy as ToggleEnemyBattleAiStepEntryActionExecutor

    Runtime -->> EntryCtrl: 目標ステップ開始（stepIndex）
    Note over EntryCtrl: 実行済みIndexと比較し、同じステップでは二度実行しない
    EntryCtrl ->> EntryCtrl: ステップのEntryActionsを型で振り分け
    EntryCtrl ->> Voice: PlayVoiceStepEntryAction を実行
    EntryCtrl ->> Skill: SetSkillExecutionEnabledStepEntryAction を実行
    EntryCtrl ->> Enemy: ToggleEnemyBattleAIStepEntryAction を実行
    Skill ->> Skill: PlayerActionRestrictionState を更新
    Enemy ->> Enemy: EnemyBattleAIRegistry の全敵AIを一括切替
```
