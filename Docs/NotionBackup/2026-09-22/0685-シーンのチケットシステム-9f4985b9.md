- 概要: シーン編集権限に関するチケットシステムです
- カテゴリー: 開発用


## 説明
このツールは、Unity上のシーン編集状況をチームで共有し、「誰がどのシーンを作業中か」を管理するためのものです。

## 詳細

### 1. 初めて使うとき（初期設定）
**[ Edit > Project Settings > KillChord > Ticket System >Editor ] **の項目に
gasURL
```C#
[REDACTED: 秘密情報のため伏せた（2026-09-22 バックアップ時）]
```
apiKey
```C#
1234
```
userNam
```Plain Text
任意のユーザー名
```
上記三つの内容を入力してください。

### 2. チームの状況を確認する（一覧表示）
他の人がどのシーンを作業しているか確認したい場合に使用します。
1. **[ Window > Master Ticket Window ] **からウィンドウを開きます。
2. 一覧に現在の全チケットが表示されます。それぞれのチケット色に意味があり、
  - **🟥赤: **誰かが作業中のシーンです。
  - **🟩緑: **誰も触っていないシーンです。**「使用する」**ボタンから直接チケット発行を行うことも可能です。
  - **🟦青: **現在あなたが作業中のシーンです。**「解放する」**ボタンからチケットの解放することが可能です。
[image: スクリーンショット 2026-04-24 203916.png] attachment:ea8132b5-79d1-460a-b93c-56ac6479a06d:スクリーンショット_2026-04-24_203916.png

### 3. 作業が終わったとき（ステータス更新）
作業を終えて他の人にシーンを譲れるようになったら、必ずステータスを更新してください。
1. 自分の作業している行（項目が🟦青）を探します。
2. **「解放する」**ボタンを押します。
3. 項目が🟩緑になれば解放が完了です。これにより、チーム全員に「空き状態」であることが伝わります。

### 4. 新しくシーンを追加する（チケットの新規発行）
一覧にないシーンを追加する場合は以下の手順に従ってください。
1. **「Edit > Project Settings > Ticket System > Management ] **を開きます。
2. ウィンドウ上部のタブから**「チケットの発行」**を選択します。
3. 今開いているシーン名やパス、ユーザー名が自動で表示されているのを確認します。
  [image: スクリーンショット 2026-04-24 165125.png] attachment:52e579c2-5f83-4438-90a7-b197e96305cc:26285cf3-0349-411f-9e43-e2771ff70ff9.png
4. **「チケットを発行して使用開始」**ボタンを押します。
  - これで、チケット一覧にあなたの名前、使うシーン名と「使用中」という情報が登録されます。

### 5. 既存のチケットを削除する（チケットの破棄）
必要なくなったチケットや、間違って追加してしまったときの最終手段です。
**（注：権限が他操作より強力、すなわち他者が使用中のチケットも破棄できてしまうため、くれぐれも悪用・濫用しないでください。あくまで最終手段であることを忘れずに。）**
1. **「Edit > Project Settings > Ticket System > Management ] **を開きます。
2. ウィンドウ上部のタブから**「チケットの破棄」**を選択します。
3. 破棄したいチケットを探し、**「破棄する」**ボタンを押します。
4. 警告ダイアログが出るので、そのまま続行してください。

#### ⚠️注意事項
- **ネット環境:** スプレッドシートと通信するため、インターネットに接続された状態で使用してください。
- **手動更新:** このツールはAPIの制限都合上、**「ボタンを押したとき」**に情報を送ります。作業が終わったら忘れずに**「解放する」**ボタンを押すよう協力をお願いします。
