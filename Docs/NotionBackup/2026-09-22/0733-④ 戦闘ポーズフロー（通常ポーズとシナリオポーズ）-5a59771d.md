# ④ 戦闘ポーズフロー（通常ポーズとシナリオポーズ）

戦闘ポーズには、プレイヤーの入力による通常ポーズと、シナリオ再生に伴うポーズの2系統がある。両者は同じ`BattlePauseController`が扱うが、通常ポーズ中にシナリオが始まった場合、シナリオ終了時に通常ポーズを解除してはならないため、状態を区別して保持する。
```Mermaid
sequenceDiagram
    autonumber
    actor Player as プレイヤー
    participant Input as PlayerInputView
    participant Init as SequenceInitializationModule
    participant Ctrl as BattlePauseController
    participant Module as BattlePauseModule
    participant Music as MusicPlayer

    Player ->> Input: ポーズ入力
    Input -->> Init: OnBattlePauseInput
    Init ->> Ctrl: Toggle()
    Ctrl ->> Module: TryPause()
    Module ->> Module: 入力マップを切替
    Module ->> Music: BGMを停止
    Module -->> Ctrl: true
    Ctrl -->> Ctrl: OnPaused を発火

    Note over Ctrl: シナリオ再生時はMissionモジュールが IScenarioBattlePauseController として呼ぶ
    Ctrl ->> Ctrl: シナリオ用ポーズを開始（通常ポーズ中かを記録）
    Ctrl -->> Ctrl: OnScenarioPauseStarted を発火
    Ctrl ->> Ctrl: シナリオ終了時、通常ポーズ中だった場合はポーズを維持する
```
