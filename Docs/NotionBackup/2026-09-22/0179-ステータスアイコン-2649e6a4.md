### ゲーム内機能の概要
ステータス画面でキャラクターの各能力値を一目で判別できるようにするアイコンである。同じデザインをスキルツリーのノードアイコン（解放済み時に中央へ表示するアイコン）としても共用する。

#### UIの詳細
| ステータス | モチーフ |
|---|---|
| 体力 | ハート |
| 攻撃力 | 弾丸＋上向き矢印 |
| 防御力 | 盾 |
| クリティカル率 | 稲妻＋弾丸 |
| クリティカルダメージ | 稲妻＋弾丸＋上向き矢印 |
| 射程範囲 | クロスヘア |
弾丸・クロスヘアを軸にした遠距離攻撃寄りのモチーフ言語で統一している。
- サイズ：縦×横 1×1（解像度：100×100px、各ステータス共通）
