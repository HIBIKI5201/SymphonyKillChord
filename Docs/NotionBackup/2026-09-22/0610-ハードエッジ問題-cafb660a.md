### 詳細
アウトラインの基本的な実装は、
法線方向にメッシュを拡張することで、通常モデルを包むようにしています。
ですが、立方体など角が鋭利なモデルでは頂点ごとに法線方向が大きく異なるため、アウトラインに隙間ができてしまいます。

## 方法
アウトライン専用のスムーズノーマルを用意することで解決できます。
スムーズノーマルとは、隣接するポリゴンの法線を平均化したもので、ハードエッジ部分でも連続したアウトラインが引けるようになります。

### 立方体の理想の法線
[image: スクリーンショット 2026-02-26 153219.png] attachment:a5ca9fad-9dc1-4f85-a623-4d023cb14185:スクリーンショット_2026-02-26_153219.png
ただし、シェーダー内では隣接ポリゴンの情報を取得できないため、
C#スクリプト側で事前にスムーズノーマルを計算してモデルに書き込む必要があります。

## スムーズノーマルの計算
同じ座標にある頂点の法線を平均化することでスムーズノーマルを計算します。
`Dictionary<Vector3, Vector3>`を使い、頂点座標をキー、法線の合計をバリューとして集計します。
同じ座標の頂点が見つかるたびに法線を加算し、最後に正規化することでスムーズノーマルが得られます。

### 実装例：
```C#
private static void CalcSmoothNormals(Mesh mesh, out Vector3[] smoothNormals)
{
	//頂点情報を取得
	var vertices = mesh.vertices;
	var posToNormals = new Dictionary<Vector3, Vector3>();
	smoothNormals = new Vector3[vertices.Length];

	//同じ座標の頂点を探し、法線を加算
	for (int i = 0; i < vertices.Length; i++)
	{
	    var v = vertices[i];
	    if (!posToNormals.ContainsKey(v))
	        posToNormals[v] = Vector3.zero;
	    posToNormals[v] += normals[i];
	}

	//加算した法線の標準化
	for (int i = 0; i < vertices.Length; i++)
	{
	    smoothNormals[i] = posToNormals[vertices[i]].normalized;
	}
}
```

## スムーズノーマルの保存
計算したスムーズノーマルはUVチャンネルに書き込んで保存します。
ただし、そのまま書き込むとボーンアニメーションで法線がずれてしまうため、タンジェント空間に変換してから保存します。
タンジェント空間に変換することで、ボーンの動きに追従した法線として扱えるようになります。
また、スムーズノーマルは正規化されているため、XYの2成分だけ保存すれば、シェーダー側でZを復元できます。（Z = sqrt(1 - X² - Y²)）

### 実装例：
```C#
private static void CalcVectorToTangetToUV(Mesh mesh, in Vector3[] smoothNormals, out Vector2[] result)
{
    var normals = mesh.normals;
    var tangents = mesh.tangents;
    result = new Vector2[normals.Length];

    for (int i = 0; i < normals.Length; i++)
    {
        var N = normals[i];
        var T = (Vector3)tangents[i];
        var B = Vector3.Cross(N, T) * tangents[i].w;

        // タンジェント空間に変換
        var sn = smoothNormals[i];
        var snTS = new Vector3(
            Vector3.Dot(sn, T),
            Vector3.Dot(sn, B),
            Vector3.Dot(sn, N)
        );
        snTS = snTS.normalized;

        // XYだけ格納（Zはシェーダーで復元）
        result[i] = new Vector2(snTS.x, snTS.y);
    }
}
```

## 結果
あとはシェーダー側で、
NormalVectorからUVに格納されているスムーズノーマルに変更するだけで実装完了です。
