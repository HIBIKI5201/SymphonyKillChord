## 仕様概要
特定の条件を満たした際に発動する。
強力な攻撃や強化状態を付与する効果のこと。
ゲーム内では”キルコード”と呼称する。

## **仕様意図**
ボタンが少なくタップすることが多いゲームのため、
単調な動作になり飽きが来やすい。
そのため、単調な動作に意味を持たせ飽きを来させないようにするため。

## 詳細説明

#### **スキルの発動条件**
各種スキルには発動するための条件が存在する。
スキルの条件はリズムパターンと入力の種類から成る。
スキルの条件は特定のコマンドを入力すること。
コマンドには、リズム判定（[[リズム判定]] ）とアクション種類の判定がある。
リズム判定は、特定の順番でリズムを刻むこと。
アクション種類は攻撃や回避などのアクションの種類を入れる事。
例：
”4 → 4 → 8 → 8”というリズムのコマンドなら、四拍子を二回押したのちに八拍子を二回押すと
リズム判定に成功し発動できる。
”最後は回避”というコマンドなら、コマンドの最後に回避を使用するとアクション種類に成功し発動できる。
また一部のスキルには、以下の条件が必要になる。
- 自身のHPが〇〇％以下になった際（一度のみ）
- 敵を○○体討伐したとき（繰り返し使用可能）

#### **スキルの種類**
スキルの効果はジャンルがあり、そのジャンルは3種類ある。
- **攻撃**
敵に直接、ダメージを与えるジャンル
  - 敵一体に攻撃力○○％の強力な一撃攻撃
  - 敵一体に攻撃力○○％の強力な〇撃攻撃
  - 着弾後半径〇メートルに攻撃力○○％の強力な一撃攻撃
- **バフ**
PC（プレイヤーキャラ）にプラスの状態を付与するジャンル
  - ｎ秒間、攻撃力を〇％上昇
  - ｎ秒間、クリティカル率〇％上昇
  - ｍ秒間、クリティカルダメージ○○％上昇
- **デバフ**
敵にマイナスの状態を付与するジャンル
  - ｎ秒間、攻撃対象の攻撃力を減少
  - ｍ秒間、攻撃対象の受けるダメージを1.〇倍上昇

### スキル装備時の条件
- コマンドの最後のノーツが共通しているスキルは同時に装備できない。
例えば
スキルαのコマンドは A A B B
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できない。

スキルαのコマンドは A C C
スキルβのコマンドは A C B
この場合はこの二つを同時に装備できる。
