# ⑥ インゲーム中のシナリオ再生フロー

`ScenarioPlaybackClearCondition`を持つステップでは、戦闘を止めてシナリオを再生し、再生完了をもってステップを達成させる。シナリオ再生そのものはScenarioモジュールの実装を流用し、Mission側は起動と復帰だけを担う。
```Mermaid
sequenceDiagram
    autonumber
    participant Runtime as MissionRuntimeService
    participant ScenarioCtrl as MissionScenarioController
    participant Pause as IScenarioBattlePauseController
    participant InputMode as IScenarioInputModeController
    participant Usecase as ScenarioUsecase
    participant Condition as ScenarioPlaybackClearCondition

    Runtime -->> ScenarioCtrl: 目標ステップ開始（stepIndex）
    ScenarioCtrl ->> ScenarioCtrl: ステップ条件がScenarioPlaybackClearConditionかを判定
    ScenarioCtrl ->> Pause: 戦闘を停止
    ScenarioCtrl ->> InputMode: シナリオ操作用の入力マップへ切替
    ScenarioCtrl ->> Usecase: シナリオIDを指定して再生
    Usecase -->> ScenarioCtrl: 再生完了
    ScenarioCtrl ->> InputMode: InGame操作用の入力マップへ復帰
    ScenarioCtrl ->> Pause: 戦闘を再開
    ScenarioCtrl ->> Condition: CompletePlayback（ステップ達成）
```
