### 結論
ポーズメニューの各種設定項目（グラフィック・ボリューム・感度・UIサイズ・キーバインド等）を、`[SerializeReference]` + Subclass Selector によるポリモーフィックな構成で実装した。
新しい設定項目を追加する際は、用途に応じた中間基底クラス（選択式 / スライダー式 / トグル式 × カテゴリ）を継承したクラスを1つ追加し、Inspector上の配列に登録するだけでよい設計とした。
**グラフィック設定に関してはスクリーンモードを****ExclusiveFullScreen****にすることによって引き延ばしせざるを得なかった**

### 注意事項
- 解像度の項目でEditor上でデバッグをしようとしても比率は変わらないので一度ビルドする必要がある
- `LookSensitivitySetting` / `MasterVolume` の `ApplyValue` は未実装（TODOコメントのみ）。感度・マスターボリュームの変更はUI上のラベル更新のみで、実際の値には反映されない
- キーバインドの再割り当て（`KeyRebindSetting`）は `InputActionAsset` 本体にオーバーライドとして書き込まれるため、Play Modeを終了してもエディタ上に残ってしまう。デバッグ段階の対策として `KeyBindingPlayModeResetter`（Editor専用）を実装し、Play Mode開始時に全 `InputActionAsset` のオーバーライドを自動リセットしている
- 解像度変更（`ResolutionSetting`）はOSのディスプレイモードを直接変更する `Screen.SetResolution` 方式。`Screen.fullScreenMode`（ExclusiveFullScreen想定）を維持したまま解像度のみ変更する

### 機能の概要
設定項目共通の抽象基盤と、ドメイン別の中間基底クラスによってカテゴリ分けされた**設定項目システム**を新規実装。
主な特徴は以下の通り：
- **3種類の設定項目基盤** — 選択式（←項目→）/ スライダー式 / トグル式の3つの抽象基底クラスが、`Load()` / `Apply()` / `ResetToDefault()` / `Initialize()` の共通フローを提供
- **カテゴリ別の中間基底クラス** — Graphic / Volume / Sensitivity / OtherSetting / Binding の各カテゴリごとに中間基底クラスを用意し、Subclass Selectorのドロップダウンを分類
- **パネル切り替えUI** — `PauseMenuPanelView` が `ButtonPanelSet`（Button + SettingPanelView）の配列を保持し、ボタン押下で対応パネルを表示・他パネルを非表示に切り替える。初期表示は配列先頭のパネル
- **解像度・画面モード設定** — `Screen.resolutions` から選択肢を構築し、代表的なアスペクト比（16:9 / 16:10 / 4:3 / 21:9 / 5:4 / 3:2）に近似したラベルを表示
- **デバッグ用キーバインドリセッター** — Play Mode開始時に `InputActionAsset` の全バインドオーバーライドを自動リセット

#### SettingPanelView / PauseMenuPanelView
`SettingPanelView` は `[SubclassSelector, SerializeReference] ISettingItem[] _settings` を保持し、`Initialize()` で各項目を初期化・非表示化した上で `ApplyAll()` を実行する。`LoadAll()` / `ResetAllToDefault()` / `SetPanelActive(bool)` も提供する。
`PauseMenuPanelView` は `ButtonPanelSet[] _settingPanels`（Button + SettingPanelViewのペア配列）を `Awake()` で走査し、各パネルを `Initialize()`、各ボタンに `SwitchPanel` をバインドする。
```C#
Awake():
  foreach panel in _settingPanels:
    panel.PanelView.Initialize(this)
    panel.Button.onClick += () => SwitchPanel(panel.PanelView)
  SwitchPanel(_settingPanels[0].PanelView)  // 初期表示は先頭パネル

SwitchPanel(panel):
  _currentSettingPanel?.SetPanelActive(false)
  panel.SetPanelActive(true)
  _currentSettingPanel = panel
```
---

#### ResolutionSetting
- `Screen.resolutions` から選択肢を構築
- `GetCurrentIndex()` は `Screen.currentResolution` と width/height が一致する解像度のインデックスを返す
- `GetLabel()` は `GetClosestAspectRatio()` で代表的なアスペクト比（16:9 / 16:10 / 4:3 / 21:9 / 5:4 / 3:2）の中から最も近いものを選び、`"1920 x 1080 (16:9)"` のように表示
- `ApplyValue()` は現在の `Screen.fullScreenMode` を維持したまま `Screen.SetResolution(width, height, fullScreenMode)` で解像度のみ変更する
---

#### ScreenModeSelectSetting
- `FullScreenMode` のenum値（`Enum.GetValues`）を選択肢として列挙
- `ApplyValue()` は `Screen.currentResolution` のサイズを維持したまま `Screen.SetResolution` でモードのみ変更する
---

#### PostProcessToggleSetting
`_postProcessVolume`（GameObject）の `SetActive(value)` を切り替えるのみの単純な実装。
---

#### Volume系（VolumeSettingBase / BgmVolume / SeVolume / MasterVolume）
- `VolumeSettingBase` は `CriAtomExAsr.SetBusVolume(BusName, value)` を呼ぶ共通実装を提供する抽象クラス
- `BgmVolume` / `SeVolume` はそれぞれ `BusName` に `"BGM"` / `"SE"` を返すのみ
- `MasterVolume` は `VolumeSettingBase` を継承せず `SliderSettingItemBase` を直接継承しており、`ApplyValue` は未実装（TODO）。`_atom`（CriAtomSource）フィールドも現状未使用
---

#### Sensitivity系（SensitivityData / LookSensitivitySetting）
- `SensitivityData`: `[CreateAssetMenu]` のScriptableObject。`_sensitivityMultiplier`（`Range(0.1f, 3f)`、デフォルト1）を保持
- `LookSensitivitySetting`: `SensitivityData` をInspectorで参照するが、`ApplyValue` は未実装（TODO）。実際のカメラコントローラーへの適用処理が必要
---

#### UiSizeSetting
"小・中・大" の3段階（`Scales = {0.8f, 1f, 1.2f}`）を `_targetScalers`（`CanvasScaler[]`）の `scaleFactor` に適用する。
---

#### KeyRebindSetting
- `InputActionReference _actionReference` + `_bindingIndex` で1つのバインディングを対象にする
- `StartRebind()` で `PerformInteractiveRebinding` を開始（Keyboard / Mouseのみ、`<Keyboard>/escape` でキャンセル）
- `ResetToDefault()` で `Action.RemoveBindingOverride(_bindingIndex)`
- `RefreshText()` で `InputControlPath.ToHumanReadableString` を使い現在の割り当てをUIに表示
---

#### KeyBindingPlayModeResetter（Editor専用）
`[InitializeOnLoad]` のstaticクラス。`EditorApplication.playModeStateChanged` を監視し、`EnteredPlayMode` 時に `AssetDatabase.FindAssets("t:InputActionAsset")` で見つかる全 `InputActionAsset` の `RemoveAllBindingOverrides()` を呼ぶ。
> デバッグ段階でキーバインドのオーバーライドがPlay Mode終了後もエディタ上に残ってしまう問題への対処。`#if UNITY_EDITOR` でビルドには含まれない。
---

### 使用例

#### 新しい設定項目の追加方法
```Plain Text
1. 用途に応じた中間基底クラス（例: GraphicSelectSettingBase）を継承した [Serializable] クラスを作成
2. GetItems() / GetLabel() / ApplyValue(int)
   （Sliderなら ApplyValue(float)、Toggleなら ApplyValue(bool)）をoverride
3. SettingPanelView._settings 配列にInspector上でSubclass Selectorから追加
```

#### パネル切り替えの設定
`PauseMenuPanelView._settingPanels` に Button と SettingPanelView のペアを登録するだけで、ボタン押下時のパネル切り替えと初期パネル表示（先頭要素）が自動的に行われる。
