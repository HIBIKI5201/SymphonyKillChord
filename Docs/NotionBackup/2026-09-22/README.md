## 含まれないもの

- 画像・動画・添付ファイルの実体（本文には URL だけが残る）
- 埋め込み・リンクドデータベースビューの中身
- タスクリスト・時間割・休暇日・スプリントの DB の行ページ（件数が多く、仕様ではないため取得していない。DB の一覧行とプロパティは親ページに残る）
- Notion のページ履歴（版）

完全な復元が必要なときは、Notion 自体のページ履歴（有料プランでは 30 日以上）かワークスペースのエクスポートを使う。このバックアップは、**本文とプロパティの文字情報を比べる・戻すため**のものである。

## 秘密情報の扱い

このリポジトリは公開されている。そのため、Notion の本文にあった秘密情報は `[REDACTED: …]` に置き換えてから入れた（Google API キー 1 件、Google Apps Script の URL 1 件）。対象は `_REDACTIONS.json` を参照。
元のキーは Notion の公開ページにも載っているので、失効・再発行が必要である（Issue #2026）。

## 形式について

- Markdown への変換は取得スクリプトによる簡易なものである。見出しは Notion の段より 1 段下がっている（Notion の H1 が `##`）。
- 本文の書式（色・トグルの開閉など）は完全には残らない。
