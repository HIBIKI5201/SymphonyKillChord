## 仕様検討
[[仕様検討フォーラム]] の使用方法に従って仕様案の査定を行う。
```Mermaid
flowchart TD

A[0. 作成中の仕様案を作成する]
B[1. 作成中の仕様案の内容を記述する]
C[2. 作成が完了したら「検討中」に変更する]
D[3. 仕様概要に結論を適用して「適用済」に変更する]

A --> B
B --> C

C -->|差し戻されたら| B

C -->|採用されたら| D

```

### 0. 作成中の仕様案を作成する
仕様検討フォーラムのテンプレを使用して案を制作する。
- タイトル
仕様案のタイトル。
- 経緯
“ログ”の中にある”経緯”の下に内容を書く。
この仕様案が検討される経緯を書く。

### 1. 作成中の仕様案の内容を記述する
“ログ”の中にある”初期案”のトグルの中に書く。

#### 結論とは
書いた仕様を仕様書に書き込む文体で記述する。

#### 記述指針とは
仕様書の「どこに」記載し「どのように」書き込むかを記述する。

#### 仕様概要とは
以下で書く仕様詳細の簡単なまとめを書く。

#### 仕様意図とは
仕様を可決した理由や意図などを書く。

#### 仕様詳細とは
仕様概要の内容をより詳細に細かく書き込む。

#### 差し戻されたら
差し戻しの際に来るコメントをもとに、改善した案を制作する。
制作の際は”初期案”のトグルの下に新しく”第二案”、”第三案”や”○○改善案”などのタイトルで次案を制作する。

### 2. 作成が完了したら「検討中」に変更する
仕様案のステータスを変更する。
検討中の仕様案はリードプランナーとディレクターが確認するまで待機する。
差し戻されたら1に戻る。

### 3. 仕様概要に結論を適用して「適用済」に変更する
仕様概要ページに採用案の内容を適用する。
内容は”結論”によってまとめられた内容を使用する。
適用が完了したらステータスを”適用済”に変更する。
