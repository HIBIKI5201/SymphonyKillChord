## API

### メソッド

#### Initialize
- 引数情報
  -  [[CameraConfigs]] `configs`
  -  [[ILockOnTargetContainer]] `lockOnContainer`
初期化を行う。
入力バッファは自由回転モードの時に使用される。
敵のコンテナはロックオンモードの時に使用される。

#### LockOnTarget（ターゲットロックオン）
- 引数情報
  - Transform `target`
    - ロックオン対象の参照
カメラのロックオンターゲットにターゲットを指定し
カメラの焦点がターゲットに合うようになる。

#### UnlockTarget（ロックオン解除）
ロックオンモードを解除し、自由回転モードに移行する。

#### アップデートモード切り替え
- 引数情報
  -  [[CameraUpdateModeEnum]] `mode`
カメラの更新タイミングをアップデートモードの種類に変更する。
追従ターゲットや注視ターゲットの更新タイミングによっては振動バグが起こるため
適宜変更して対処する。


## 内部実装

### 追従対象の取得
追従対象はCinemaChineのFollowプロパティから取得する

### 操作登録
[[InputBuffer]]  の
[[LookAction]]  に [[カメラ回転操作]] 
[[LockOnSelectAction]] に [[ロックオンセレクト操作]] 
を登録する。

### カメラ回転操作
自由回転モードの場合、Lookの入力イベントを受けて回転する。
x軸入力はプレイヤーを中心として、ヨー軸に座標の移動を行う。
y軸入力はプレイヤーを中心として、ピッチ軸に座標の移動を行う。

### ロックオンセレクト操作
ロックオン対象を新たに選定してセットする。
まず全ての敵の位置を取得する。
入力の左右を受けて、カメラの正面ベクトルから外積で左右判定を行い
入力方向ではない敵を除外する。
敵の中で最も角度が近い敵をロックオンする。
