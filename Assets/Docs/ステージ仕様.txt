# 仕様詳細

### フェーズの移り変わりのタイミング

- ステージ開始時
- 現状存在している敵が殲滅されたとき
- 前回の出現から一定時間経過したとき

の三種類の条件のうち一つでも満たした場合フェーズが移行する。

### フェーズ移行時の挙動

#### 必ず発生する挙動

- 敵が出現する
    - フェーズごとに出現する敵の数は変化する

#### 追加で発生する可能性がある挙動

- 背景の演出
    - ステージ演出 ←に記載されている演出の発生のタイミング
- 障害物の発生
    - 炎上などの演出でマップ上に移動不可や遮蔽になる箇所が発生

# 仕様概要

「クリアしたかどうか」というメインミッションと、
その「質（スコア）」を評価するサブミッションを完全に独立した項目として定義する。
これにより、一つのステージに対して多様な評価軸を持たせることが可能になる。

これらのミッションはステージ開始時にプレイヤーに与えるもの。

# 仕様意図

複雑なルールや複数の条件を詰め込むのではなく、基本条件（クリア）とスコア条件（ランク）に構造を分けることで、プレイヤーが直感的にルールを理解しやすくするようにするため。

プレイヤーに単なるクリア体験のみでなく、それ以外にも達成感を感じられる要素を入れるため。
サブミッションを複数にした理由はプレイヤーが初めてプレイした際に、必ずどれか一つのランク条件は達成できるようにさせるため。プレイヤーに成功体験を提供するため。

# 詳細説明

### ミッションの発令タイミング

- ステージ開始時

## メインミッション

### **成功条件**

- 敵をn体討伐せよ
- n秒間生存せよ
- ボスを討伐せよ

など上記のうち一つをメインミッションとしてプレイヤーに課す。

### 条件達成時

- ステージクリア

### 失敗条件

- n秒以内にステージをクリアせよ
- 死亡する

### 条件達成時

- ステージ失敗

## サブミッション

### **条件**

- nダメージ以内の被弾でクリアしろ
- n種類以上の銃を使いクリアしろ
- n分以内にメイン条件を達成する
- n回分コンボを達成する

などの上記のうち重複有りで三つをサブミッションとしてプレイヤーに課す。

### 条件達成時

- 達成するごとにリザルトでのランクが１上昇する

**リザルト例）**

- メイン条件のみ達成＝Cランク
- メイン条件＋ランク条件１つ＝Bランク
- メイン条件＋ランク条件２つ＝Aランク
- メイン条件＋ランク条件３つ＝Sランク

## ミッションの多様性

これらのステージの成功条件および失敗条件を「ミッション」と呼ぶ。

ミッションはステージごとに設定される。

# 仕様概要

プレイヤーが戦闘を行う舞台について。

### 戦闘場所

- グロズヌイの市街地
- 屋外戦闘のみ

### ステージの形

- 正方形

また、ステージには通路を設けない。

# 仕様意図

ステージに通路を設けない理由は、制作コスト削減と
プレイヤーに移動時間という退屈な時間を発生させないようにするため。

コマンドによるバフを持ったまま最強の状態で戦闘スタートという
小技ありきのゲームにならないようにするため、一つの戦闘のみにしている。
